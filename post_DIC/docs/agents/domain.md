# Domain Docs

This repository is configured as a single-context codebase.

## Read order

- Read `CONTEXT.md` at the repository root when it exists.
- Read `docs/adr/` for architecture decisions when it exists.

If these files do not exist, proceed silently.

## Layout

Single-context repos keep one root-level `CONTEXT.md` and one shared `docs/adr/` directory.
