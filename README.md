# DIC 位移与二维模量反演

**查看当前结果：双击根目录 [打开结果.html](打开结果.html)。** 页面直接进入当前实验，列出四步保存位置、云图、位移误差、模量对照及数值文件。每个步骤结束时也会打印绝对路径。

本项目的主线是：**独立材料标定 → 分区正演与 DIC 对照；DIC → 自由二维 E(x,y) 反演 → 与独立标定对照；识别场回代及留出载荷预测。** 反演不绑定不同 y 行，也不以五区模量作为强先验。默认 180N 识别、280N 留出预测，不用留出平台调参。

主线比较的参考约定见 [DIC—有限元坐标、位移基准与边界一致性](docs/dic_reference_consistency.md)：区分物理坐标配准、有限元三个刚体约束、残差刚体拟合与绘图居中，说明真实伸长为何保留、DIC 与 FEM 两套网格怎样连接，并列出当前代码入口和核对数值。

## 四个独立步骤

安装 `requirements.txt`。默认配置采用 DIC 范围计算域及原始 Tikhonov + L-curve，结果目录为 `results/dic/`；真实 DIC 四步计算已完成，L-curve选得γ≈3.1623×10⁻¹⁰。当前结果和数值停止条件见 [实际反演记录](docs/l_curve_dic_inversion_20261020.md)。新实验在项目根目录依次执行：

```powershell
python -m script.step1_prepare_dic
python -m script.step2_forward_calibrated
python -m script.step3_inverse_dic
python -m script.step4_compare_results
```

换一批数据时，修改 [dic_case_config.py](dic_case_config.py) 中的输入、载荷配对、坐标与物理定义，将 `CASE_OUTPUT` 改为新目录，然后去掉 `--plot-only` 依次运行四个脚本。每一步计算后自动生成对应云图；后续计算读取第一步冻结的数据。已有数值输出拒绝覆盖。参数及逐项文件说明见 [分步骤流程](docs/dic_stepwise_workflow.md)。

| 步骤 | 保存目录（均在 CASE_OUTPUT 下） | 主要文件 |
| --- | --- | --- |
| DIC 准备 | `01_prepared/` | `云图.html`、DIC 位移云图、冻结输入与核查记录 |
| 独立正演 | `02_forward/` | `云图.html`、标定模量、各 ν 的 DIC／正演／相对误差对照、数值场 |
| DIC 反演 | `03_inverse/` | `云图.html`、二维模量、E(x)、DIC／回代／相对误差对照、识别与预测记录 |
| 比较出图 | `04_comparison/` | `打开查看结果.html`、CSV、各 ν/平台的 PNG/SVG |

浏览入口现指向已完成的DIC范围计算域四步结果，含L-curve、自由二维模量、独立标定正演/DIC/反演回代对照及280N预测；辅助诊断内另有ν=0.33固定γ敏感性结果。历史 `results/dic/history/` 保留旧 70×20 mm 域、旧目标及空间验证选参结果，不能与新域混用。每步自动更新同组 `结果总览.html` 的四个卡片。数值结果与当前内核一致时，`--plot-only` 可重复刷新图表，不重算正反问题；内核变化后需重新准备。

误差云图统一采用百分比：位移误差以对应平台 DIC 去除三个刚体分量后的分量 RMS 归一化，避免逐点除以过零位移；原始残差仍以 mm 保存。第 2 步直接展示正演与 DIC 的并排对照，无需等到第 4 步。

反演目标为 `0.5*r.T@W_area@r + 0.5*gamma*integral(|grad E|^2)`，不设置参考模量，不作模量或人为噪声尺度归一化。gamma 仅用识别平台的 L-curve 拐点选择，扫描范数、曲率、停止信息和 PNG/SVG 保存于第 3 步；无可辨识拐点时停止并保留诊断。求解容差来自第 1 步冻结配置，源配置修改后，需重新准备输入才能生效。

## 模型与当前结论范围

**2026-10-20 几何更正：** 两条横线距各自外端最新报告约 73/85 mm，原各 75 mm 的描述不符本次测量。按名义总长 220 mm、从相对外端测量，标线间距约 62 mm，中点偏离试样中心约 6 mm；方向及 DIC 边缘位置仍待确认。既有结果沿用旧居中配准，须重新评价材料位置、独立正演和分区统计，不能据旧残差直接归因于材料或 DIC。此次仅更新说明，未改配置或重算。详见 [标线尺寸更正与影响](docs/dic_roi_geometry.md#2026-10-20-标线尺寸更正)。

制造试样名义总长 220 mm、平行段 150×20 mm、厚 3.2 mm，制造七区。当前计算域以识别平台 DIC 初始坐标范围为准，约 61.3664×18.5257 mm；20 mm 保留为真实承载宽度，不用内部观测范围替代截面宽度。五区位置只平移、不缩放；6.6832/22.6832/38.6832/54.6832 mm 为旧居中界面，尚未按本次实物测量修正。定义与限制见 [DIC 计算域及载荷截面](docs/dic_roi_geometry.md)。

当前新版 DIC 点距约 0.2894643 mm，有效覆盖约 61.3664×18.5257 mm；坐标和位移均为 mm，不缩放跨度。坐标及位移共用 rot90 变换，点云居中和材料区位置仍是显式假设。独立标定沿用 `independent` 口径，保留跨批来源、样本数和标准差。

正反问题共用 70×20 个 Q4 单元，约 0.876663×0.926286 mm，1491 个独立节点模量；DIC 不重采样。单位 mm/N/MPa，平面应力；牵引按真实截面计算，内部横向截面暂按自由边界近似，三个约束仅固定有限元刚体规范。模型与 DIC 在测点空间统一处理两平移和一微小转动。实际力约 119.77618/219.73545 N；60.1 N 偏置扣除已与初始未加载 DIC 参考确认一致。泊松比允许范围为0.24—0.33，具体值尚未确定；现有ν=0.26仅为历史基线。最新 [模量尺度与ν联合诊断](docs/joint_modulus_poisson_diagnosis_20261019.md) 仅用180N选参，ν在范围上端取得最优，仍未解决全部响应差异。

**现有结果属于条件性比较。** 优化收敛与位移拟合改善不代表物理验证完成；材料区定位、完整狗骨与矩形域边界等效、跨批标定转移及误差预算仍需独立核验。数值比较见 [当前结果记录](docs/dic_shared_mesh_nu_comparison_20261019.md)。
