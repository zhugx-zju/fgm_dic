# 实验DIC的精确TV对照

## 目的与比较条件

将合成验证过的不平滑TV应用于实际分区试样DIC，检验二维模量分布及独立标定一致性是否改善。精确TV倾向较小总变差，但不预设材料呈分层、界面方向、层数或模量取值。合成阶梯恢复改善不等于真实实验有效；平滑真值下精确TV可能逊于梯度平方正则，见`exact_tv_mesh_refinement_20261021.md`。

本轮统一配置为`dic_case_config.py`，`RUN_NAME='exact_tv_coarse_pd_20261021'`、`DATA_MODE='dic'`、`MESH_SOURCE='configured_grid'`、`CONFIGURED_ELEMENTS=(121,19)`、`REGULARIZATION_MODE='exact_tv'`、`EXACT_TV_SOLVER='primal_dual'`。保存于`results/dic_full/exact_tv_coarse_pd_20261021/`；原H1粗网格结果`results/dic_full/coarse/`保留。先行ADMM尝试及数值诊断另存`exact_tv_coarse_20261021/`，不与新求解器的正式扫描拼接。

保留105.99508453657×18.48415643522 mm计算域、厚3.2 mm、23920个DIC测点、Q4观测插值、2440个独立节点杨氏模量、等位移分量权重及三刚体规范。所有y行参数独立。180N平台识别，280N平台留出；两平台校正力分别119.77617870327234 N与219.7354506515086 N。端部牵引按真实20 mm承载宽度计算。主ν=0.26，0.24/0.28/0.33仅作固定γ敏感性分析。

分区界面和独立标定仅用于独立正演及反演后统计，不进入反演目标、初始化或γ选择。沿用既定`independent`标定及跨批转移限制；边段实际覆盖15.747275/10.247810 mm，不能称七段都完整覆盖16 mm。物理配准及截取域边界等效尚未独立验证。

## 离散目标与停止条件

原方案为

\[
J_{H1}(E)=\tfrac12 r^T W_A r+\tfrac\gamma2\int_\Omega|\nabla E|^2\,dA.
\]

本轮采用

\[
J_{TV}(E)=\tfrac12 r^T W_A r+\gamma\int_\Omega\sqrt{E_x^2+E_y^2}\,dA,\qquad
E_h=\sum_iN_iE_i,\quad E_i=\exp(m_i).
\]

积分使用同网格2×2 Gauss点，不含Huber阈值、平滑ε、参考模量或噪声归一化。位移的试函数、测试函数仍为原Q4形函数；这不是SUPG或单元常数模量方案。L-curve横坐标为`√(rᵀW_A r)`，纵坐标为`TV(E)`本身，代价中直接乘γ，不对TV再次开平方。不同正则的γ单位不同。

正式求解采用非线性原始—对偶迭代，复用原有限元和伴随数据梯度。每个γ/ν严格最多12000次FE函数计算和12000步；模量直接在正E上更新，不引入材料下限先验，若候选非正则减半数值步长。给定外推`E_bar`，更新为

\[
p^{k+1}=\operatorname{proj}_{|p_q|\le\gamma}(p^k+\sigma GE_{bar}^k),\qquad
E^{k+1}=E^k-\tau(\nabla f(E^k)+G^TAp^{k+1}),\qquad
E_{bar}^{k+1}=2E^{k+1}-E^k.
\]

初始τ=2e8 MPa²/mm⁴，仅为数值步长；σ由`τσ λ_max(GᵀAG)=0.9`确定，谱计算使用固定起始随机向量种子173。无目标函数或模量归一化。原ADMM仍可通过`EXACT_TV_SOLVER='admm'`选择，但本轮最终扫描不混用两种求解轨迹。停止证据保持相同定义：

- 对log(E)的驻点残差∞范数≤`1e-9+1e-3*max(||E∇f||∞,||EGᵀAp||∞)`。
- 原始—对偶法直接取`z=GE`，面积加权`GE-z` RMS恒为零；它不再是独立ADMM约束收敛证据。保留该列用于统一保存格式。
- Fenchel间隙绝对值≤`1e-9+1e-4*gamma*TV(E)`。
- 对偶幅值超界≤`1e-12*gamma`，对应`|p_q|≤gamma`。

原H1的GTOL不能替代这些条件。驻点残差仍用对log(E)的导数度量，以与既有TV证据一致；这不代表模量更新采用log(E)梯度。上述是非线性问题的近似局部一阶条件，不证明全局最优。

强正则区间从仅180N数据拟合的均匀初值出发，可求解离散Poisson势构造满足驻点条件的对偶场；若同时满足对偶幅值约束，直接保存同一组证据，避免反复迭代。该构造只提供充分条件，不声称求得最小可行γ。均匀场零TV及梯度低于约束数值分辨阈值的场不参与对数曲率。

50个γ预设为1e-10—1e-2，按递减顺序扫描，只从上一已通过证据的场及对偶场延续。仅180N、ν=0.26确定L-curve；保持原有正曲率、邻点支撑、非单调和端点排除规则。无有效拐点时保存诊断并停止，不借助独立标定或280N调参。若选参成功，各ν从同一所选模量场出发，固定γ后预测280N。

## 核验与结果记录

先行尝试的`checks/real_data_oracle.json`记录真实测点上的数据梯度方向有限差分相对误差1.04e-7与2.07e-7；单次函数计算约0.0171 s，仅用于计算量预估。`checks/certificate.json`记录梯度算子转置检验绝对误差2.84e-14及均匀场独立驻点核验1.77e-14。正式新目录`checks/solver_verification.json`记录旧ADMM默认路径相对既有提交逐位一致、新原始—对偶法小网格独立核验（5112次FE计算，重新正演后驻点残差5.86e-9、间隙5.18e-13，均通过保存阈值）。新增算法为显式选项，不回写旧合成结果。

先行真实规模ADMM扫描完成26/50点：24个强γ均匀场通过证据，但TV为零，不能参与对数曲率；γ=1.20679264064e-6与8.28642772855e-7分别在12008/12003次计算后仍未通过。原L-BFGS的`maxfun`会在当前线搜索结束时少量超出名义12000预算。扫描在第27点中断并保留，未选γ、未产生有效最终反演结论。数值诊断只使用180N求解残差，不读取标定或280N误差。

同一首个非均匀γ上，原始—对偶原型3978次FE计算通过同定义的驻点及间隙条件；单纯调整ADMM罚参数、缩短内迭代或进行余弦预条件均未在各自小预算内通过，相关记录保留于先行目录`checks/`。这些原型是求解效率诊断，不作为独立实验验证或调γ依据。

准备数组与原H1粗网格逐项核对，四个ν的独立标定正演也单独核对；记录分别为`checks/input_identity.json`及`checks/forward_identity.json`。本轮重新生成冻结输入并核对当前内核身份，未绕过旧准备文件的源码哈希检查。

第3步逐γ保存完整场、对偶场、分裂梯度、`tv_history.csv`、停止证据及`selection.csv`。最终比较应同时考察180N分量残差、280N固定参数预测、二维E场、宽度平均E(x)、横向空间离散和独立标定区域差异。独立标定比较是事后评价，不反过来决定γ；位移拟合改善不能单独认定实验成功。

## 已完成的真实DIC结果

四步状态均已完成。50点中35点通过一阶证据：24点为均匀场、11点具有可分辨非零TV。15个弱γ（1e-10—1.93069772888e-8）耗尽12000次FE预算，原样保存并排除选参；不能把`computed`解释为全部50点收敛。有效正曲率峰选定γ=1.2648552168552957e-7，曲率约1.253002，所需相邻支撑均有效；没有使用280N或材料标定补选γ。四个最终ν均通过，更新步数分别为173/1/177/1382。ν=0.26从已通过的所选场及其对偶场出发，仅一次核验即可再次通过，这不等于从均匀初值一步完成识别。

主ν=0.26下的同条件评价为：

| 指标 | 原节点Q4＋梯度平方 | 本次节点Q4＋梯度幅值TV |
| --- | ---: | ---: |
| 七区均值相对独立标定差异的平均绝对值 | 14.9966% | 14.8600% |
| 最大区域有符号差异 | +32.0746% | +38.9964% |
| 横向空间SD沿长度的RMS | 21.6091 MPa | 36.9129 MPa |
| 180N识别：轴向RMSE | 0.872983 μm | 1.007871 μm |
| 180N识别：横向RMSE | 1.456106 μm | 1.473295 μm |

TV场形成更明显的平台，但没有恢复独立标定对应的七个模量水平：100%/90%/80%三个统计区的反演均值分别约2563.8/2563.8/2560.4 MPa，而独立标定分别为2399.6/2120.1/1842.1 MPa。前三个区被合成近似同一平台；80%区的偏高从32.07%增至39.00%。因此“图上更像阶梯”不能作为识别更准确的证据。这里的七区只用于事后统计，没有进入反演。

本轮未显示精确TV在真实实验上的实质优势：平均材料差异仅减小0.1366个百分点，最差区域差异、横向空间变化和四项分量位移RMSE均增大。其他ν下的七区平均绝对差异仍约14.85%—14.87%，没有消除整体不一致；ν敏感性不是联合识别，不能依据280N改选ν。原H1仍作为实验主线基线，本次TV保留为辅助对照。

这与小网格合成阶梯恢复改善并不矛盾：合成试验同时去除了实验噪声与材料/边界不一致。当前结果说明仅替换正则不足以解决本组实验的识别问题，尚不能由此唯一定位为DIC、材料标定转移或截取域边界的某一项错误。

正式TV扫描共252488次FE函数计算，原H1粗网格为24074次；本轮计算量约10.49倍，但两种停止条件不同，不能将该比值当作严格耗时或相同精度的效率排名。15个失败候选的成本也计入总量，未隐去失败代价。

`lib/dic_exact_tv_report.py`仅做已有结果审计与对照。50个扫描场和4个最终场均独立重算数据正演/伴随并核对驻点、间隙、约束及对偶证据；39个通过、15个不通过，与保存标记全部相符。两种方法的主ν位移误差及区域均值也经独立回代复核。解析仿射场验证宽度均值和横向SD积分；真实数据新种子371的两方向梯度有限差分相对误差为3.16e-7/4.90e-6，转置检验绝对误差2.31e-14。另核验原始—对偶法严格遵守两次FE小预算、正值步长回退及返回场/状态一致性。
