# 统一梯度／分层材料：算法原型与小规模测试

2026-10-22。分支：`unified-gradient-layered-tests`。本实现对应
`plan/unified_gradient_layered_inverse_plan.tex` 的 P0/P1，已完成材料映射、
一致积分、伴随及单参数区内正则的导数核验，并保存小规模无噪声反演诊断。
当前证据支持实现一致性，**不支持未知界面已稳定恢复**。正式 P2 含噪对照、
独立生成网格的最终测试、尖锐移动界面及真实 DIC 识别仍未完成。

## 代码与配置

- `fgm_asm/unified_material.py`：区域权重乘区内自由二维 Q4 场；各分支保留全部
  独立节点，先取正节点系数 `exp(m)`，再插值。没有绑定不同 y 行，没有先合成
  连续节点 E 场来替代积分点材料值。另支持连续 Q4、分区常值两个诊断基线。
- `fgm_asm/integration.py`：在原矩形网格的副本上生成复合 Gauss 积分；固定直线
  尖锐界面按实际交点切分子区域。平滑移动界面使用固定积分点，其位置导数
  由材料映射给出。未实现移动尖锐界面的形状导数，接口明确拒绝该组合。
- `fgm_asm/unified_inverse.py`：复用现有 `fem_assemble`、`forward_solver`、
  `lambda_distance`、`evaluate_observation`，通过材料 Jacobian 转置将积分点
  灵敏度传回材料及几何参数。L-BFGS-B 保存最后接受场、逐次评价记录、实际
  正演／伴随次数、求解器状态与单独的一阶证据。硬预算耗尽不将试探场作为结果。
- `lib/unified_gradient_layered_study.py`：准备、正演、反演、比较四个独立阶段；
  不增加 `script/` 入口，不接管原 DIC 四步流程。参数入口为
  `unified_gradient_layered_config.py`，主实验仍使用 `dic_case_config.py`。

统一映射支持有序的 `x=s_j(y)` 几何，包含直线及 clamped B-spline 控制曲线。
多界面移动优化要求互不重叠的控制量可行区间；这些区间是显式结构限制。
全分支平滑模型保留弱支撑参数，尚未加入活动集裁剪或域外延拓策略。

平滑区内正则定义为

\[
J=f+\frac{\gamma}{2}R,\qquad
R=\sum_i\int_\Omega\chi_i\lvert\nabla E_i\rvert^2\,dA.
\]

它是尖锐区内积分的有限平滑近似，不是对最终混合场计算全域 H1。
实现包含 `d chi_i / d g` 对正则积分的贡献。正则材料／几何梯度已核验，
但默认 `GAMMA=0` 仅作 P1 数据项诊断；尚未通过无真值选参证明此候选可稳定几何。
未引入材料参考场、真值初始化、界面位置惩罚或额外正则权重。

## 运行与存储

从项目根目录运行，各阶段分别执行；一个反演命令只计算一个小算例：

```powershell
python -X utf8 -B -m lib.unified_gradient_layered_study prepare
python -X utf8 -B -m lib.unified_gradient_layered_study forward
python -X utf8 -B -m lib.unified_gradient_layered_study inverse --case mixed_2d --method unified_q4 --geometry fixed
python -X utf8 -B -m lib.unified_gradient_layered_study inverse --case mixed_2d --method unified_q4 --geometry unknown --start 0.35
python -X utf8 -B -m lib.unified_gradient_layered_study inverse --case mixed_2d --method unified_q4 --geometry unknown --start 0.65
python -X utf8 -B -m lib.unified_gradient_layered_study compare
```

当前编号已计算，重复求解会拒绝覆盖。新试验修改 `RUN_NAME` 并重新准备；
旧结果重绘在对应命令后增加 `--plot-only`，例如：

```powershell
python -X utf8 -B -m lib.unified_gradient_layered_study inverse --case mixed_2d --geometry unknown --start 0.35 --plot-only
python -X utf8 -B -m lib.unified_gradient_layered_study compare --plot-only
```

`--input` 可显式指定旧运行根目录并读取其冻结配置；默认检查当前配置指纹。
后续计算核验内核源码哈希、准备数组身份及正演观测身份。更改算法源码后应
新设运行编号；不将更改后的算法接到旧冻结运行。保留旧环境可重绘原结果。

## 冻结的小算例协议

诊断域为 6×2 mm，6×3 个 Q4 单元、28 个背景节点，采用 mm/N/MPa、平面应力、
ν=0.26、厚 3.2 mm、真实承载宽 20 mm 与合成净力 96 N。ROI 每端力为 9.6 N，
单位厚度牵引为 1.5 MPa，沿用三个刚体规范和面积加权残差配准。
这不是实际实验 ROI 或某个平台的新识别。

设 `xi=x/6, eta=y/2`。三类真值均在准备阶段冻结：

- 连续二维：两分支相同，`E=1400+650xi+200eta+100xi*eta` MPa。
- 分层基准：两分支分别为 1300、2300 MPa。
- 混合二维：左分支 `1100+450xi+180eta+80xi*eta`，右分支
  `2100+250xi-140eta+60xi*eta` MPa。

界面位置为 2.82 mm，平滑宽度 ε=0.3 mm，采用每方向二分子单元上的 3×3 Gauss
积分。分层和混合例是有限平滑近似，不称为尖锐分层恢复。连续和混合分支均有
真实非零横向变化。观测为相同 FE 表示／积分生成的全节点位移，属于同表示
实现诊断；不能替代独立参考网格及不可精确表示真值的正式测试。

已知界面协议显式使用 2.82 mm；未知协议仅给出 `[0.6,5.4]` mm 可行区间，
初值分别为 2.1、3.9 mm。初始模量只由本组位移的均匀柔度拟合取得，各分支从
相同的该模量开始；几何初始数据梯度为零是零对比性质，没有使用真值打破对称。
模量界限为 100—6000 MPa，每次最多 500 次迭代／800 次正演评价，
`FTOL=1e-16`、`GTOL=1e-11`，目标不作模量或噪声尺度归一化。

本次 17 次识别包括：三真值的三方法已知界面诊断共 9 次；统一模型在三真值的
两种未知界面初值共 6 次；分层常值模型在分层真值的两初值共 2 次。
这不是一个完成选参及最终评价分离的 P2 比较矩阵。

## 实际核验与结果

可随代码保存的精简证据在 [unified_gradient_layered_test_evidence.json](unified_gradient_layered_test_evidence.json)。
完整数值、图片及日志保留于上述运行目录。实现核验使用的临时算例源码未保留。

P0 核验采用种子 20261022：

- 直界面两分支、二次样条三分支及分区常值的材料／几何方向导数均通过；
  包含 `gamma=0` 和 `gamma=1e-9` 完整目标。各项三种差分步长中最佳相对误差
  最大约 `1.24e-8`，保留每个步长的原始误差，未只保存最优值。
- 独立检查正则项材料／几何方向导数，相对误差约 `4.74e-10`、`6.90e-11`。
  连续二维双线性场表示最大误差 `9.09e-13` MPa。
- 相同分支的几何梯度为零，移动界面引起的位移变化约 `3.47e-18` mm；
  均匀材料解析位移最大误差 `2.52e-17` mm；刚体不变性误差 `8.40e-18` mm。
- 与本次修改前内核在同一小网格直接对照，刚度、位移和节点梯度差均为零。
  原默认 2×2 积分路径保持一致。
- 单位方域两侧 1000/2000 MPa，固定尖锐界面从 0.3 移至 0.6 mm 时，
  子区域积分分别为 1700、1400，等于解析值；旧固定两点采样均为 1500。
- 固定网格上 ε=0.3/0.15/0.075 mm 的阶数／细分检查显示，减小 ε 需同步提高
  积分分辨率。3×3、每方向四分的刚度相对参考误差约为
  `5.16e-8 / 8.66e-6 / 3.41e-5`；参考为 6×6、每方向八分。
- 单次正演硬预算检查确认：预算耗尽时保存初始接受场，明确标记未成功。

17 次识别均满足本配置的绝对投影梯度阈值，没有参数触及声明界限；这只是
预定目标的一阶停止证据，不能代替材料精度或可辨识性。采用同一 121×41
物理评价网格的梯形积分计算 `sqrt(int(E-Etrue)^2/int(Etrue^2))`：

| 真值 | 连续 Q4，固定协议 | 分层常值，已知界面 | 统一 Q4，已知界面 | 统一 Q4，未知界面两初值 |
|---|---:|---:|---:|---:|
| 连续二维 | 0.3724% | 6.0731% | 1.1639% | 1.1349% / 1.2889% |
| 分层 | 9.0605% | 0.0000113% | 2.4414% | 9.2710% / 4.4027% |
| 混合二维 | 7.1159% | 3.4905% | 1.6548% | 6.5802% / 3.5235% |

混合二维未知界面的两次识别位置为约 2.0877、3.8450 mm，距真值分别
0.7323、1.0250 mm；两场相对 RMS 差异约 6.4461%，但分量位移 RMSE
仅约 `7.86e-8`—`2.17e-7` mm。分层统一模型两初值的界面相差约 1.5265 mm，
场间差异约 8.0064%。这些结果暴露了分支梯度／界面位置补偿和弱支撑问题，
不能据位移拟合宣布几何恢复成功。

混合真值统一模型的加权、刚体投影后位移 Jacobian，在 `log E` 和无量纲 `s/L`
坐标下，以最大奇异值的 `1e-7` 为截断比例，已知／两未知初值的局部数值秩为
39/41/40，对应参数数为 56/57/57。每种协议有 4 个材料系数的积分支撑小于
最大支撑的 `1e-8`。诊断另用 340 次正演，不混入各次反演的识别预算。
该局部、有限差分及给定截断比例的结果不证明全局非唯一，但与多初值差异
共同提示当前信息和参数化不足以稳定确定全部自由度。

17 次识别合计 845 次正演，包含每次初始化的单独一次正演；局部灵敏度诊断
另计 340 次。重绘路径通过禁止调用正演求解器的检查，103 个数值／配置／日志
文件哈希均未变化；当前配置与冻结配置不符时的拒绝行为亦已检查。运行环境为
Python 3.13.2、NumPy 2.4.0、SciPy 1.17.1、Matplotlib 3.10.9，完整版本见证据快照。

正演二倍网格诊断的轴向／横向位移差为约 3.2e-6—7.9e-6 mm，大于上述同表示
回代残差；尚未做完整网格收敛序列。因此当前误差不能解释为真实物理恢复精度。

下一阶段应先检查单参数区内稳定化能否缓解已观察到的补偿，并在识别数据上
规定兼容的选参／停止协议。随后才进入独立生成网格、不可精确表示二维真值、
噪声扰动与正式三方法比较；不通过真值补选 gamma 或缩窄界面可行窗。
