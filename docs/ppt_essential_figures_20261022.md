# 核心结果比较图集：5张正文图

本图集以H1等权重、主ν=0.26为共同口径，覆盖二维模量、沿轴向分布、实测位移与两种正演的对照，以及网格变化。筛选依据是证据类型的互补性，180N、280N、380N均保留，不根据某个平台拟合更好而排除其他平台。

## 正文图序

| 图号与PNG文件名 | 比较内容 | 说明 |
| --- | --- | --- |
| 01_三平台二维模量对比.png | 独立标定与三平台各自识别的二维E | 同一121×19粗网格、共同颜色范围，展示完整空间结构。 |
| 02_三平台E_x与独立标定.png | 三平台E(x)、独立标定与横向空间离散 | 核心定量模量对比；横向空间标准差不是标定不确定度。 |
| 03_180N_280N位移对比.png | DIC、独立标定正演、本平台反演模量回代 | 同时保留轴向与横向，按同一分量的共同颜色范围比较。 |
| 04_380N位移对比.png | 380N的同类三个位移场 | 380N使用假定力319.9N，缺少同步实测力，不改写为实测载荷。 |

输出位于`results/dic_full/independent_platforms_20261022/PPT精选/`。该目录直接提供5张按序编号的PNG；SVG放在`SVG/`子目录。`index.html`为精选预览，`图片说明.md`给出图意与可点击路径。完整汇总页及原61组图片清单增加精选入口，原图集保留。

L-curve、其余ν、横向加权及TV方案用于方法细节或附录，正文不逐一重复同类图。流程示意图仍在完整图集中，方法页需要时可另行引用。

## 来源与核验

精选图均直接复制既有PNG/SVG，没有重新求解或修改图内数值。`selection.json`保存每张图的源路径、目标路径和SHA256；`verification.json`记录5张PNG、5张SVG的逐文件哈希一致及16个本地页面链接核验。新增精选入口没有删除原结果或改变原反演状态。
