# 分层正问题位移的自由二维模量恢复

本项对照区分两件事：当前自由二维反演在无噪声、同模型条件下的恢复误差，以及真实DIC反演中额外出现的定量偏差。合成恢复不替代实验物理验证，也不能将实验偏差唯一归因于DIC精度。

## 固定条件与两个真值

继承`results/dic_full/tv/delta10/01_prepared/`中与粗网格基线逐值一致的几何、材料位置、载荷及观测位置；该准备文件使用当前有限元内核。计算域105.995084537×18.484156435 mm，厚3.2 mm，121×19单元、2440个独立节点模量、23920个观测位置。全部y行独立。正反问题固定已知ν=0.26，等权重、同一H与三个刚体配准模式。

沿FEM x的100/90/80/70/60/50/40%区模量为2399.5733/2120.0569/1842.0790/1708.3381/1638.6619/1396.4108/1231.8683 MPa，取原独立标定均值，仅作为本项合成真值。界面、载荷与实验主线一致。

- `dic_synthetic_config.py`，结果`results/dic_full/synthetic/layered/`：原分层正问题在高斯点直接评估突变模量。生成U与已有粗网格独立正演的U逐值相同。反演仍是连续Q4节点模量，因此包含界面表示误差。
- `dic_synthetic_nodal_config.py`，结果`results/dic_full/synthetic/nodal/`：将相同分区均值赋到节点，再用Q4插值到高斯点生成位移。真值在反演空间内，用于检查同表示恢复能力。

合成观测为`H @ U_truth`，不加入噪声或刚体运动；不使用实验位移。准备文件只保留坐标、点面积、网格ID及新生成位移，原始DIC位移数组不复制。`truth/fields.npz`保存真实节点、高斯模量、U及观测。几何和测点仍来自DIC，物理配准未核验状态保留，不改称实验已验证。

## 反演协议

目标及求解器不变：`0.5*r.T@W_area@r + 0.5*gamma*integral(|grad(E)|²)`，每个节点`log(E)`独立。初值只从180N合成位移拟合均匀模量，分别约1736.22、1737.31 MPa，不用真值初始化或绑定分区。180N识别和选参，280N固定后预测；比例线性合成载荷的预测仅检验尺度一致性，不提供新的独立加载模式。

两组各扫描原50个γ（1e-12—1e-4），相同延续与曲率规则、1500次迭代/12000次函数预算、FTOL=1e-30、GTOL=1e-12。无有效拐点时保留失败状态，不用真值或固定γ诊断补选。

在完整扫描之前，另外声明两项固定γ诊断，均从各自的同一均匀初值独立出发：真实DIC基线已经选出的γ=3.906939937054621e-9，以及弱正则γ=1e-12。后者用于检查正则偏差，不作为真值误差最优参数或合成L-curve结果。配置冻结于`RECOVERY_DIAGNOSTIC_GAMMAS`。

## 固定γ诊断结果

两组四步及各自50点L-curve均已完成，都选出γ=9.102981779915228e-11。分层组49/50点按求解器条件停止，节点组50/50点停止；分层γ=1.2067926406393291e-8在线搜索异常后排除，未手动改选或用失败场延续。最终两组按函数下降停止，梯度∞范数分别为8.05e-12和3.57e-12，未达到GTOL=1e-12。不能将`computed`解释成严格梯度条件已满足。

| 真值表示 | 自动选γ后模量全场相对RMS | 七区均值平均绝对偏差 | 180N轴向RMSE (μm) | 180N横向RMSE (μm) |
| --- | ---: | ---: | ---: | ---: |
| 节点Q4 | 2.751% | 0.691% | 0.06148 | 0.01483 |
| 突变分层 | 2.916% | 0.787% | 0.06165 | 0.01476 |

这两项使用原算法自动选参；下述固定γ诊断单独保留，不与自动选择混用。无噪声合成的最合适正则强度无需等同实验带误差数据的强度，不能据此将实验γ直接改小。

全场模量相对误差为`100*sqrt(integral((E_inverse-E_truth)²)/integral(E_truth²))`，使用相同高斯点及面积积分，包含界面。分区误差为七区真值与恢复均值的平均绝对相对误差，不能与全场指标混用。位移RMSE单位μm，均只配准三个刚体模式。

真实DIC的等权重粗网格H1基线在主ν=0.26下，180N轴向/横向RMSE为0.873/1.456 μm，七区均值相对独立标定平均绝对偏差约15.00%。与相同γ合成恢复的3.62%区均值误差相比，真实实验存在额外偏差；两种误差不作直接相减或按方差分解。弱γ的合成精度不证明真实DIC也应使用同一弱γ。

## 复现与核验

四个原入口分别执行，每组指定对应配置；以下为分层组，节点组将配置名替换为`dic_synthetic_nodal_config`：

```powershell
python -m script.step1_prepare_dic --config dic_synthetic_config
python -m script.step2_forward_calibrated --config dic_synthetic_config
python -m script.step3_inverse_dic --config dic_synthetic_config
python -m script.step4_compare_results --config dic_synthetic_config
```

合成第1步会生成FE真值位移，与实验第1步只准备数据的行为不同。实验配置缺省路径保持不变。节点组第2步仍是原独立分层标定正演，因此它与节点真值之间的差异是材料表示差异；准确恢复误差以本项`truth/`和专用汇总为准。

固定γ诊断及专用报告为独立调用，不自动串行代替四步：

```powershell
python -c "from lib.synthetic_recovery import run_recovery_diagnostics; run_recovery_diagnostics('results/dic_full/synthetic/layered/01_prepared', 'results/dic_full/synthetic/layered/diagnostics')"
python -c "from lib.synthetic_recovery import run_recovery_diagnostics; run_recovery_diagnostics('results/dic_full/synthetic/nodal/01_prepared', 'results/dic_full/synthetic/nodal/diagnostics')"
python -c "from lib.synthetic_recovery import write_recovery_report; write_recovery_report('results/dic_full/synthetic')"
```

既有数值目录拒绝覆盖；重算须先修改配置的独立输出位置。专用汇总只读取已保存恢复场并复核预测，重新生成图表，不重新优化。

`input_checks.json`已验证两组6个几何/面积/ID数组与原准备逐值相同、23920点/2440参数、无原始DIC位移数组；分层两载荷U与已有独立正演逐值相同；节点真值重新正演在观测空间闭合到零残差。固定γ报告独立重算每个恢复场的预测并与保存数组核对，所有数值及环境/命令/源码哈希在对应目录保留。

`scan_checks.json`重新正演并核对全部100个扫描场的ρ/η，最大绝对差分别不超过9.9e-17与1.2e-13，重新计算曲率得到相同γ；所有扫描场为有限正值。`report_provenance.json`记录报告依赖的冻结数组及源码哈希。两组4步完成状态与保存的源文件身份分别核对，不覆盖真实DIC主线数值结果。

最终交付核对11个HTML页面、488个本地链接无缺失，并检查模量趋势和合成/回代双分量图的渲染。节点同表示真值的积分误差为零，整体乘1.01的模量偏差按同一指标为1%，用于独立核验评价量纲与归一化。

## 解释范围

本项已证明当前自由二维算法可从该分层模型的无噪声响应中近似恢复区域均值和阶梯趋势，也量化了正则平滑偏差。该结论仅针对当前真值、初值、网格、观测、已知ν及加载；不证明一般唯一性、抗噪稳健性或实验模型正确。

真实DIC替换为FE位移同时消除了测量误差、未知泊松比、实际材料响应及边界近似与真实试样之间的不一致。因此合成恢复优于实验，支持“真实实验输入与所用模型之间存在额外不一致”，不能单独证明“DIC精度是主要原因”。区分这些因素还需要独立实验误差与模型证据。
