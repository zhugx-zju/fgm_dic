# 380N DIC：统一材料模型的区内正则反演

本次直接对380N实验DIC开展诊断计算；此前三类仿真的L-curve进入条件仍为未通过，
不改写原记录。实验曲线可以与合成曲线不同，但实验计算本身不替代仿真验证。

配置入口为 `unified_380n_config.py`，独立输出为
`results/unified_gradient_layered/380n_coarse_lcurve_20261023/`。
只运行380N，不启动180N或280N的新反演，不覆盖原380N各正则方案。

## 冻结输入与目标

从 `results/dic_full/load380_20261022/h1/01_prepared/` 读取已准备的380N坐标、
面积和位移。该输入来自 `380N_2/all_region` 的618—632帧，保留全部23,920点。
沿用其毫米坐标、制造位置、105.995084537×18.484156435 mm域、厚3.2 mm及
真实承载宽20 mm，不重新居中、缩放或补齐缺失端。

净力沿用已有探索假设319.9 N，即380−60.1 N；同步实测平台力缺失，不能称为
实测载荷。端牵引为F/(20t)，截取域端力为FH/20，保留三个刚体规范和残差刚体
消除，内部横向自由仍为显式近似。物理坐标尚未完全独立核验的状态保留。

位移网格121×19单元、2,440节点。六个物理界面固定，七个区内Q4分支各保留
完整二维节点，共17,080材料系数，不绑定y行。ν=0.26，ε=0.3 mm，模量边界
100—6,000 MPa。该已知界面协议有显式几何先验，不是未知界面盲识别。

目标保持原始面积加权失配加单一γ区内梯度项：

`J = 0.5*r.T@W_area@r + 0.5*gamma*sum_i integral chi_i*|grad E_i|^2`。

两个分量残差平方系数均为1，不引入E_REF或噪声/模量归一化。仅用380N位移
拟合均匀值，再优化区域常值初始子空间，之后释放全部二维系数。
独立标定不进入初值、目标或γ选择；它仅用于独立正演和识别后比较。

## 选参与计算预算

复用本分支已有统一反演、伴随和扫描实现，不另写求解器。50个γ为1e-12—1e-4
对数等距点，递减扫描，只由通过一阶条件的点延续。每点最多1,500迭代、3,000次
正演，FTOL=1e-30、GTOL=1e-9；初始化预算另存。失败点保留接受场并排除。

L-curve横纵坐标为ρ=√(rᵀW_A r)、η=√R_intra，不把γ放入纵坐标。沿用原内部
最大正曲率和两侧各两个有效相邻点规则，不按标定误差调γ、不补人工γ、不跨失败点。
无有效拐点时，只展示预定扫描编号00/24/49的未选定诊断场，不形成正式识别场。
若取得有效γ，则展示该场的本平台回代、二维E、宽度平均与横向空间离散；仍属于
假设载荷及当前边界模型下的条件性实验结果。

## 分步运行与保存

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -X utf8 -B -m lib.unified_380n_workflow prepare
python -X utf8 -B -m lib.unified_380n_workflow forward
python -X utf8 -B -m lib.unified_380n_workflow inverse
python -X utf8 -B -m lib.unified_380n_workflow compare
```

四个命令分别执行，不新增总batch。第1步保存原输入身份、配置和内核摘要；后续
核对摘要。第2步用独立标定均值和物理界面切分积分产生正演，不调标定模量。
第3步逐点保存参数、位移、残差、梯度、停止状态和预算。第4步生成本平台DIC、
标定正演与所选场或未选定诊断场的同色标位移图、残差及模量图，PNG/SVG同时保存。
残差云图为有符号绝对差，单位μm；原始数组保持mm。显示使用共同DIC均值平移，
不改变残差或伸长。

已有图可在对应命令后加`--plot-only`重绘。新输出拒绝覆盖，完整扫描拒绝重复运行；
中断扫描从保存点继续，既有点不重复消耗预算。默认主实验配置不变。
