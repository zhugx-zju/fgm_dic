# 380N局部支撑与均值／起伏预条件：受控试验结果

固定尖锐界面的局部支撑表示已实现，实际粗网格材料系数从17,080减为2,680，仍保留
独立二维Q4变化。单纯消去无支撑系数没有显示明显收敛优势；本轮明确收益来自
均值／起伏预条件：在同一局部表示、目标、投影L-BFGS步骤和原坐标一阶判据下，
中等γ求解正演由404次减至25次，两者得到相同目标和近乎相同的物理场。
但最弱γ的预条件表现较差，不能直接作为整个γ范围的通用求解器。

浏览入口：`results/unified_gradient_layered/support_precondition_pilot_20261023/结果总览.html`。
定义见[协议](unified_support_pilot_protocol_20261023.md)，数据与复核见
[证据快照](unified_support_pilot_results_20261023.json)。本轮是固定点数值试验，

## 固定条件与比较设计

使用既有380N冻结输入和数据拟合的区域常值初始系数，全部23,920点、121×19位移
单元、ν=0.26，真实截面及刚体配准保持原定义；净力319.9 N仍是假设值。
原初始化未通过一阶条件，作为初值的事实保留，不用独立标定构造初值。

三个实际冻结γ为1e-4、8.28642772854686e-9、1e-12；每点400次迭代、600次正演。
全部方法使用同一按界面切分的3×3 Gauss、每方向二分积分，只去掉全零权重填充行。
原log系数盒约束为log(100)—log(6000)，最终一阶判据为原坐标投影梯度∞范数≤1e-9。
目标仍为原始面积加权失配加`gamma/2*R_intra`，不增加正则项或改变γ的含义。

| 方法 | 表示与求解器 | 参数数 |
|---|---|---:|
| smooth_full | 原tanh七分支，原SciPy L-BFGS-B | 17080 |
| sharp_full | 固定尖锐七分支，原SciPy L-BFGS-B | 17080 |
| sharp_local | 尖锐真实支撑消元，原SciPy L-BFGS-B | 2680 |
| local_projected | 同一局部表示，投影L-BFGS，无均值／起伏预条件 | 2680 |
| local_metric | 同一局部表示及投影L-BFGS，加均值／起伏预条件 | 2680 |

第一、二项比较包含界面模型变化，不是纯消元。第二、三项保留相同尖锐物理可行场
及原背景节点系数盒约束；没有截断tanh尾部，也没有把相同盒约束直接施加到新插入
的界面节点。2,680在本次实际几何上按正面积支撑重新计数，不由先导样条计数替代。
局部实现仍保留完整父映射用于采样／核验，未测量峰值内存，不能宣称内存同比下降。

## 原15点结果

以下为求解正演次数；括号“通过”表示原坐标一阶通过，其他点均未通过：

| 方法 | γ=1e-4 | γ=8.28642772854686e-9 | γ=1e-12 |
|---|---:|---:|---:|
| smooth_full | 414 | 408 | 418 |
| sharp_full | 411 | 358（通过） | 417 |
| sharp_local | 415 | 413 | 418 |
| local_projected | 417 | 404（通过） | 455 |
| local_metric | 16（通过） | 25（通过） | 600 |

原15点累计求解5,589次正演。预条件准备另用14次正演及伴随，三个γ共用；
这些开销不能隐藏。强γ无预条件组到400迭代仍未通过，不能把417/16直接称为
“达到同一精度的加速比”。中等γ两组都通过，404/25约16.2是求解FE次数比；
即使把全部14次准备都计入这一个点，404/(25+14)约10.4。并行条件下的单次墙钟
不用于效率排名，FE次数也不等于精确CPU时间。

中等γ下，local_projected/local_metric最终目标分别为
0.015522793460622575/0.015522793460620384；共同735×129物理网格下，二维场
相对RMS差3.30e-7。两者轴向／横向RMSE均约1.913／3.427 μm。
这支持“更快求到同一个解”，不支持“模量真实性已提高”。

同一中等γ下，sharp_full与sharp_local最终场相对RMS差4.87e-7；前者347迭代
通过，后者400迭代时投影梯度为1.284e-9，略高于阈值。表示等价并不要求浮点
L-BFGS轨迹完全相同。该结果没有显示仅减参即可解决停止困难，也不足以评价局部
支撑在其他网格、界面或实现上的全部成本收益。

初版协议文字误把中间点标为原降序编号24、1.206792640639329e-8；运行前冻结
配置实际写入升序索引24，即原降序编号25、8.28642772854686e-9。原15点、配置
摘要和数组均保留，没有后验换点。另按补算前保存的协议，在原拟测试的降序编号24
处确认同一有／无预条件对照，预算和初值不变：

| 方法 | 求解FE | 原坐标投影梯度∞范数 | 状态 |
|---|---:|---:|---|
| local_projected | 407 | 2.274e-9 | 400迭代未通过 |
| local_metric | 23 | 8.014e-10 | 通过 |

这两个确认点另计430次正演，复用相同初始状态下已保存的均值曲率，不重复消耗14次

支撑，也不回填为原15点。全部17点求解6,019次正演，曲率准备14次另计。

## 为什么有效，以及为什么弱γ失败

预条件在物理模量系数c=exp(m)中使用区域面积均值与零均值起伏。梯度型矩阵L
控制起伏；七个区域常值响应的观测Gauss-Newton矩阵控制均值，随后映回log坐标
方向。均值曲率的特征值约2.72e-9—9.80e-7，条件数约360.8；这不是全Hessian
条件数。原目标与全部二维未知量均保留，不把不同y行绑定。
分解用于辅助搜索度量，没有另加一套“均值＋节点”优化变量，因此不引入重复表示。

该辅助度量处理了区域常值与区内起伏尺度不同的问题；逆度量不需要改变原盒约束。
强、中γ的原坐标一阶证据说明收益不是把新坐标梯度缩小造成的假收敛。

但当前度量仅在七个均值方向使用数据曲率，起伏方向主要由正则控制，其逆作用
含1/γ。γ极小时，数据对起伏的曲率被忽略，当前设计可能给出过大的试探方向。
弱γ中预条件组600次FE仅接受51步，548次试探被拒绝；无预条件组455次FE接受
400步，54次试探被拒绝。预条件组最终目标约0.0130005、投影梯度6.79e-5，
均逊于无预条件组约0.00698484、1.37e-5；两者都未通过。

因此不能把预条件收益外推到弱γ，更不能用两点成功自动确定求解器切换阈值。
后续应检验数据对起伏的近似曲率或可验证的步长保护；这是辅助求解度量的设计，
不等于在反演目标中叠加新的正则权重。

## 核验及当前边界

前置小算例中，完整／局部尖锐目标相对差1.33e-15、梯度相对差1.17e-15，
方向差分相对误差约4.75e-11；均匀解析解恢复7次FE通过。触界二次目标、硬预算
最后接受场亦通过。全零积分填充行由144减至54时，实际网格均匀材料刚度和位移
差为零。详情见[前置检查](unified_support_checks_20261023.json)。

正式17个保存场均用未编译完整分支映射重新正演和伴随，原坐标通过／失败标记
全部复现；原15点节点位移最大差1.81e-14 mm、梯度最大绝对差1.73e-13、目标最大
相对差3.07e-14。额外复核另用17次正演及伴随，不计入求解预算。

禁止FE装配、求解和优化后重绘通过，36个NPZ/CSV数值文件哈希不变。重要图共21组
PNG/SVG，模量图在同一γ内共享色标；收敛图保留全部试探，包括拒绝点。已检查
中等γ的收敛、二维模量以及弱γ的回溯图；汇总页本地链接均存在。

旧380N和合成扫描的冻结保护仍保持。本轮未增加独立材料网格、未知曲界面、
完整γ扫描、独立噪声／初值稳定性或物理边界验证，也不改变假设载荷和原材料标定
转移限制。区内正则的常值零空间及L-curve拐点存在性，不会被预条件自动解决。
