# 算法架构与数据接口

二维 Q4 平面应力模型用于识别试样的等效模量 E(x,y)，实际制造分布沿拉伸方向变化。独立材料标定正演、实验 DIC 反演和识别场回代共用力学内核。

## 力学和参数

单位为 mm、N、MPa，厚度为 3.2 mm。当前计算域约105.995085×18.484156 mm，真实承载宽20 mm，两端施加等大反向牵引 ±F/(w·t)，侧边自由，仅去除三个刚体自由度。有限元刚度采用单位厚度约定，载荷按厚度换算。

当前细网格正反问题共用367×64个Q4单元、23,920个独立节点模量，间距约0.288815 mm；粗网格为121×19单元、2440个独立节点模量。两者均保留全部DIC测点，E_a=exp(m_a)，各y行未知量独立。沿FEM x递减的100/90/80/70/60/50/40%七区位置用于独立材料正演和后处理，不绑定反演参数。采用原始一阶Tikhonov正则`gamma/2 * integral(|grad E|^2)`，不设置参考模量或尺度归一化。比较ν=0.24/0.26/0.28/0.33，主值0.26仅为预设基线，不根据跨载荷误差更换主ν。

分区标定正演在 Gauss 点计算阶梯 E(x)，界面为x=15.747275/31.747275/47.747275/63.747275/79.747275/95.747275 mm，基础网格不强制对齐界面。反演使用连续 Q4 节点场；二者的界面表示不同，比较中应同时报告全场和界面附近误差。

## 观测与伴随

`ObservationCase` 包含载荷边界、真实测点双分量位移、权重和来源。当前实验只用测点面积权重 W_area，不除以人为噪声尺度平方。对每个载荷，令 r=d−Hu−Rc，其中 R 包含两平移和一微小转动，c 在测点空间加权最小二乘求得。

数据项为 `0.5*r.T@W@r`，伴随方程 `K*lambda=H.T@W@r`。模量梯度为各载荷的 `lambda.T*(dK/dE)*u` 之和，对 log(E) 乘以 E。刚体系数满足最优性条件，无需再求其导数。历史合成研究使用的完整节点质量矩阵目标为独立验证接口。

第3步在预设主ν下，仅对当前识别平台扫描gamma，构造`rho=sqrt(r.T@W_area@r)`、`eta=sqrt(integral(|grad E|^2))`。按最大有效正三点曲率识别有两侧支撑的内部拐点；失败点排除，无法选参时停止。扫描从大gamma到小gamma，首点仅由本平台观测拟合均匀模量，后续只继承本平台已收敛场。180N与280N分别执行上述过程；各ν从本平台所选场出发，另一平台不参与该次识别。

## 数据与结果

当前主入口依次为 `step1_prepare_dic.py`、`step2_forward_calibrated.py`、`step3_inverse_dic.py`、`step4_compare_results.py`。第一步冻结单组配置与测点数据，第二、三步分别读取同一准备结果，第四步汇合保存的正反演结果且不重新求解。具体运行与换数据方式见 [分步骤流程](dic_stepwise_workflow.md)。

all_region按既定原始/制造坐标锚点连续裁剪[−56,56] mm与可用数据的交集，保留实际DIC坐标、位移及网格ID；DIC参考点经网格ID恢复为节点行列，保留实际毫米坐标；H按节点对应顺序置换两个位移分量。非DIC网格算例继续采用Q4插值。平台CSV通过网格ID对齐，恢复初始参考坐标，检查重复点与跨帧/跨平台一致性。物理配准由显式 A/b 确定，所有载荷共用；坐标及位移同步变换。细节见 [坐标配准](dic_coordinate_registration.md)。

独立标定保留填充率、批次、样本数、均值和标准差。标定正演在真实DIC点比较两分量；180N与280N分别独立识别E，再比较本平台回代与跨载荷响应。两平台均使用后，不将当前跨载荷响应称为未使用数据的独立验证。成比例载荷不提供新的独立空间激励。

每次运行创建独立输出目录，保存配置、输入/代码哈希、版本、命令和 Git 状态。数值数组与绘图分离，图保存为 PNG/SVG。未收敛运行保存诊断并返回退出码 2。验证协议见 [验证方案](../plan/validation_plan.md)。
