# 旧居中几何的50点L-curve扫描与反演

本记录对应修正前的_3数据、居中材料位置及−Y轴向。四步结果和scan50_audit已归档于 `results/dic/history/pre_marks/`，不代表当前已确认几何。当前修正见[新记录](mark_geometry_correction_20261020.md)。

## 结果与比较条件

γ在10⁻¹²到10⁻⁴之间取50个对数等距点，含两端点。log10间距为8/49，相邻倍率约1.45635。实际完成全部50次求解，49个点按求解器规则成功；γ=10⁻¹²达到1500次迭代上限，被排除。最大正离散曲率选得 **γ=5.96362331659e-10**，曲率约0.417762，两侧各有两个有效扫描点。

只用180N及预设ν=0.26选γ，独立标定和280N不参与初值、目标或选参。冻结γ后，ν=0.24/0.26/0.28分别从同一个所选场重新求解；每个ν保留1491个独立节点E，不绑定y行。

与17点基线保持相同的DIC参考态、观测数组、坐标变换、几何、载荷、标定、网格、目标、初值方法、容差和逐点预算。新准备数组及独立正演数组与基线逐值一致；配置差异只有γ列表及此前合并的保存路径。

## 与17点基线的差异

17点选得γ≈3.1623×10⁻¹⁰，50点选得γ≈5.9636×10⁻¹⁰。这是加密后离散拐点位置的变化，不直接证明实验模型更准确。主ν=0.26的E范围为1625.9—2465.1 MPa，节点均值为2146.3 MPa；与17点场的节点等权RMS差为18.225 MPa，最大节点绝对差为38.639 MPa。这些空间差异不是参数不确定度。

主ν=0.26的位移RMSE单位为μm：

| 平台 | 17点轴向 | 50点轴向 | 17点横向 | 50点横向 |
| --- | ---: | ---: | ---: | ---: |
| 180N | 0.639 | 0.650 | 1.271 | 1.274 |
| 280N | 1.545 | 1.509 | 3.262 | 3.267 |

两平台轴向误差仍明显低于独立标定正演，横向误差仍大于同ν的独立正演。不能用280N误差选择17点或50点协议；50点协议在运行前已固定。

## 数值停止与核验

原目标保持面积加权位移失配加一阶Tikhonov正则，不设E_REF，不做模量或噪声尺度归一化。FTOL=10⁻³⁰、GTOL=10⁻¹²，每点最多1500次迭代和12000次函数评价。近驻点ABNORMAL重启规则与17点基线相同，累计预算不增加，本轮扫描共记录2次重启。

所选扫描点梯度∞范数约7.5796×10⁻¹¹，未达到GTOL。最后三个ν均按函数下降条件停止，也未达到GTOL：

| ν | 最终梯度∞范数 | 满足GTOL |
| --- | ---: | --- |
| 0.24 | 1.44544e-10 | False |
| 0.26 | 7.99343e-11 | False |
| 0.28 | 6.8161e-11 | False |

全部50点均用保存E重新正演核算ρ，并由Q4梯度积分核算η；与扫描表一致。曲率和选中γ重算一致，逐点预算、历史长度、初值延续和正模量检查通过。三个ν、两个平台共六组最终预测用保存E重算，与保存数组一致。17点归档的136个数值及配置文件未变。

数值复现不等于实验物理验证。材料区居中假设、内部横向自由边界近似和误差预算仍按既有记录保留。原ν=0.33敏感性使用17点所选γ，本轮未重算，不能当作50点主结果。
