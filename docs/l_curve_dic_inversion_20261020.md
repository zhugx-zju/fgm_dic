# 真实DIC的L-curve自由二维模量反演

## 结果

实际执行现有第三、四步入口，已完成180N识别、280N预测与同条件对照。保留1491个独立节点模量，没有绑定不同y行；标定五区仅用于独立正演与反演后统计，不进入目标、初值或γ选择。

主L-curve在历史参考ν=0.26下，17个γ点中16个按求解器规则成功，选取最大正离散曲率的内部点 **γ=3.1622776602×10⁻¹⁰**，两侧各有两个有效点。γ=10⁻¹²达到1500次迭代上限，被排除。ν=0.24/0.26/0.28从同一个选中场重新求解；ν=0.33另作相同γ的上界敏感性计算，不用于重新选γ，也不解释为已识别真实ν。

主ν=0.26的节点E范围约 **1588—2470 MPa**；宽度平均场主要随x上升，横向空间SD约1.4—21.1 MPa，后者不是参数置信区间。当前正演与DIC不完全一致，场值不能当作已验证材料真值。

## 初始化与数值停止

原0.501 MPa冷启动的6个已完成强正则点均达到1500次迭代上限。仅用180N做均匀材料位移最小二乘，得到E₀≈2147.9082 MPa；它只提供初始数组，不作为E_REF、目标归一化或材料先验。所有节点随后独立优化。合成双载荷、独立刚体运动与不等面积权重检查恢复已知1800 MPa，误差约10⁻¹² MPa。

原均匀1 MPa响应的两个正常位移分量，与每个平台自己的两平移和一微小转动一起拟合尺度。识别初值只调用FIT_CASES，不使用独立材料标定或280N。

一次扫描因γ=3.1623×10⁻¹¹线搜索ABNORMAL，曲率峰值缺少支撑而正确停止。对同一γ、同一场、相同容差，在剩余预算内重启L-BFGS，仅一次迭代便按原函数下降条件结束，目标和梯度保持在原数值精度；没有直接修改失败标记。当前流程仅对ABNORMAL且梯度∞范数≤10×GTOL的情况允许最多两次这样的重启，累计预算不增加；该10倍系数仅控制是否重试，不作为收敛判据。最终扫描仅一个γ点触发一次重启，原停止及重启信息均保留。

目标、γ范围和预算保持：原面积加权失配加γ/2∫|∇E|²，γ=10⁻¹²—10⁻⁴共17点，FTOL=10⁻³⁰、GTOL=10⁻¹²、最多1500次迭代/12000次函数计算。

**成功标记是SciPy的函数下降停止，不代表GTOL达标。** 所选扫描点梯度∞范数约4.52×10⁻¹¹；最后ν=0.26场约1.73×10⁻¹¹；ν=0.33场约2.27×10⁻¹¹，均未达到10⁻¹²。现有L-curve规则依照求解器成功标记筛选，报告同时保留未满足GTOL的事实，不将其写成严格驻点或唯一解证明。
