# 分区试样 DIC、独立标定正演与自由二维反演对照

## 科学问题与当前结论

本研究检验两个问题：均匀填充试样独立标定的模量能否预测分区试样实测位移；自由二维节点模量反演能否恢复与独立标定一致的轴向分布。当前完成了真实 DIC 的条件性数值对照，但尚未完成物理配准、完整狗骨与截取域边界等效验证及正式误差预算，不能据此宣称实验验证通过。

研究定义依据 `plan/dogbone_parallel_section_adjoint_plan.tex` 与 `plan/validation_plan.md`。材料数据口径依据 `post_tensile_test/README.md`、混合批次报告 `analysis_results/mixed_infill_20261017/linearity_report.md` 及其 `group_summary_and_residuals.csv`。梯度试样加载与 DIC 来自 `1016/sample_2/`，不混入均匀试样标定组。

## 独立标定、试样与载荷

制造试样总长 220 mm、平行段 150×20 mm、厚 3.2 mm，制造时为七区。中央 70×20 mm 观测域覆盖五区，长度为 11/16/16/16/11 mm。计算使用平面应力、双端均布牵引、三个刚体约束；自由二维反演为 35×10 单元、396 个独立节点模量，不绑定不同 y 行。

采用混合批次的 `independent` 主结果，即各批同填充率优先共同窗口；该标签不表示每根试样独立选段。`individual_optimal` 为另一个敏感性口径，本轮不混用。正演直接使用五区均值，不用填充率回归直线替代实测值，不将标定值作为主反演强先验。

## DIC 工作坐标与结果复用

主输入为 `180N_3`、`280N_3`，有效点云长度 61.3664 mm、宽度 18.5257 mm。按维护的 `lib/dic_grid_orientation.py` 执行 `rot90`，参考构形为 X−DX、Y−DY，得到

```text
x = -Y_ref + 13.41423355307 mm
y =  X_ref +  7.60158150392 mm
ux = -DY
uy =  DX
```

单位尺度保持为 1。点云中心暂放置于物理域中心，所有载荷共用同一变换；有效点云角点并不直接视为物理标线。原始坐标/位移的联合旋转与结构化数组旋转已逐点核对。

`rot90` 在本轮是统一工作约定，材料方向及中心位置尚无独立标记核验，`coordinates_verified=false`。本轮主反演场由前次已收敛场作精确 x 镜像，重新正演后与原保存预测的相应坐标变换逐点一致；没有再次优化或根据新图形调参。保留原 180N 训练内选择的 gamma=10000，280N 不参与主模型选参。

## 三个位移场的同条件比较

独立正演用 70×20 单元，五区标定模量在 Gauss 点赋值；反演回代使用自由二维识别场。两者均在真实 DIC 测点比较两个位移分量，只消去三种刚体模式。共同常数面积/噪声权重下，表中双分量 RMS 等于双分量点等权 RMS；单位为 mm。

| 平台 | 模型 | 双分量 RMS | 轴向 RMSE | 横向 RMSE |
| --- | --- | ---: | ---: | ---: |
| 180N：识别 | 独立标定正演 | 0.0029209 | 0.0040511 | 0.0008072 |
| 180N：识别 | 二维反演回代 | 0.0008966 | 0.0006373 | 0.0010963 |
| 280N：留出预测 | 独立标定正演 | 0.0050994 | 0.0068164 | 0.0023548 |
| 280N：留出预测 | 二维反演回代 | 0.0023475 | 0.0015655 | 0.0029276 |

反演主要改善了轴向拟合；两个平台的横向失配均未改善，不能以双分量总 RMS 下降概括为全部响应符合。反演区域均值随工作 x 增加，但中间和高填充率区明显高于标定均值。空间 SD 为宽度或区域内空间变化，不是置信区间。

图和数组见 `results/dic_rot90_20261019_02/`：`180N_forward_inverse.png/svg`、`280N_forward_inverse.png/svg`、`modulus_comparison.png/svg`、`x_profile.png/svg`、`regional_modulus_comparison.csv`、`fields.npz`。前两图各并列 DIC、独立标定正演、反演回代及相同色标的两组残差。

## 辅助诊断与未完成的验证

逐帧使用原试验机工作簿及既有时间映射重新配力，窗口均值与原配对表数值一致。280N 反演逐帧残差能量中约 99.3% 为窗口持续存在的平均失配。全部 225 个跨平台帧组合的力归一化比例检验 RMS 为 0.001192—0.001405 mm，差异未集中在单帧。

另存的增量诊断使用 `u_280−u_180`、`F_280−F_180=99.95927 N`，消去共同加性参考位移项，79 次迭代收敛；反演双分量 RMS 为 0.001406 mm、横向 RMSE 为 0.001788 mm。它同时消耗两个平台，不属于新的留出预测证据，未用于改变主模型。该结果不支持将全部失配仅归为共同加性参考误差，但不能区分真实材料响应、状态相关光学误差与模型近似。

按照验证方案，仍需完成：物理标线与分区配准；标定变异、力、尺寸及边界组成的误差预算；完整狗骨夹持模型与中央矩形域的配对计算。当前计算是五区截取矩形模型的对照，不是完整狗骨边界等效已通过的证据。独立模量的拟合应变/应力范围与本次低载荷状态的可迁移性也需纳入解释。

## 执行与复现

当前工作区 52 项测试通过，涵盖既有解析解、伴随有限差分及本次新增的联合旋转、逐帧配力、残差能量分解和投影与共用观测内核的一致性检查。原始数据与前次输出未覆盖。

```powershell
python -m script.analyze_rot90_dic --source results/dic_revision_20261019_02 --output results/dic_rot90_replication_01
```

该入口检查前次有限元源码哈希、输入 DIC 哈希、几何参数和变换后的保存预测，再复用反演场。若没有前次结果，先按照 `docs/revised_dic_20261019.md` 复现原识别，再指定相应 source。所有输出必须使用新目录。模型、载荷、输入与代码版本记录在结果元数据中；未收敛状态不能作为实验通过结论。
