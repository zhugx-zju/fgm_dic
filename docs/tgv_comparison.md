# 二维 Huber TGV2 正则化比较

## 数学模型和实现

反演保持每个节点独立的二维模量 `E(x,y)`，正问题、双端均布牵引、
位移质量矩阵及伴随方程均复用原实现。只将正则项替换为下式，并增加局部斜率场。

定义无量纲坐标 `ξ = (x,y)/ℓ`、`z=E/E_ref`，求解

\[
\min_{m,v}\ \frac12\|u^{obs}-u(e^m)\|_M^2+
\frac\gamma2\int_{\Omega/\ell}
\left[\rho_\delta(|\nabla_\xi z-v|)
+r\rho_\delta(|\operatorname{sym}\nabla_\xi v|_F)\right]d\xi.
\]

其中 `ρδ(s)=s²/(2δ)`（`s≤δ`），否则 `s−δ/2`。预先固定
`ℓ=20 mm`、`E_ref=1 MPa`、`r=2`、`δ=0.02`，本次只测试 `z=E/E_ref`。
优化变量使用 `m=log E` 保证正值，但正则项作用于 **E**，并不作用于 log E。
积分换元必须包含 `dξ=dA/ℓ²`；两个微分算子均按 `∇ξ=ℓ∇x` 计算。

模量和辅助向量场均用连续双线性 Q1 插值，使用 2×2 Gauss 积分。
`|sym ∇v|_F² = (∂x vx)² + (∂y vy)² + (∂y vx+∂x vy)²/2`，
因此实现中的剪切分量带 `1/√2`。连续节点模量在一个单元内表示陡变，
并不能表示元素内部的精确不连续。这是 Huber 平滑、有限维的 TGV 型近似。

对 `a=∇z−v`、`b=sym ∇v`，Huber 通量为
`p=a/max(δ,|a|)` 和 `q=b/max(δ,|b|_F)`。
正则项的方向导数为

\[
DR[\eta,w]=\int\left[p\cdot(\nabla_\xi\eta/E_{ref}-w)
+r q:\operatorname{sym}\nabla_\xi w\right]d\xi.
\]

代码通过稀疏离散算子的转置计算节点梯度，不显式施加额外模量边界条件。
对 m 的梯度再逐点乘 E。该公式包括边界节点；没有丢弃边界项。

TGV 的结构先验是允许局部斜率变化，并对大变化施加近似线性代价。
它不是本构定律，仍偏好分段仿射 E。对于未知分布，不能宣称它没有先验偏好。

## 受控实验协议

- 正式网格：55×10 个单元，616 个独立节点模量；TGV 另有 1232 个辅助斜率变量。
- 几何：110×20 mm，厚度 3.2 mm，两端各 0.01 N，ν=0.3。
- 真值：线性 1→2 MPa；指数 1→2 MPa；等宽七段模量
  `[1,1.4,1.2,1.8,1.5,2,1.7] MPa`。最后一类仍是矩形模型，尚非真实狗骨七区几何。
- 同一正反有限元模型；位移采用现有逐分量相对独立 Gaussian 噪声模型，噪声幅度 1%。
- 比较：原梯度 Tikhonov、仿射去趋势二次项、Huber TGV2；统一初值 0.501 MPa。
- 各方法扫描同一候选集合 γ∈{1e−7,1e−6,1e−5}，分别选择自身的 γ。
  不将相同数值 γ 理解为相同惩罚强度。
- 校准噪声种子 40；独立重复观测种子 1040。用后者的质量矩阵加权位移误差选 γ。
  不使用模量真值选参；相同场上的独立重复位移是一种理想化实验校准条件。
- 固定所选 γ，重新从相同初值拟合测试噪声种子 42、43、44，最后才统计 E 的误差。
- 每次上限：2000 次迭代、约 2400 次目标计算；`ftol=1e−30,gtol=1e−12,maxcor=10`。
  记录是否耗尽预算、最终梯度、运行时间。目标次数的上限由 SciPy 迭代结束时检查，
  因而可能因一次线搜索超出少量次数。TGV 与基线的每次计算成本并不相同。
- 每一类场展示预先指定的测试种子 42，所有方法共用模量及误差色标；
  横向平均曲线的阴影为三个测试种子的范围，不表示置信区间。

该设计检验同一场的重复测量噪声变化，不检验新几何、新分布或系统误差上的泛化。
三个测试种子也不足以建立统计显著性。位移预测最优不等价于模量误差最优。
候选参数范围有限，边缘候选获选时不能称为全局最优参数。

## 运行及输出

在 ASM-Python 仓库根目录运行：

```powershell
python -m unittest discover -s tests -v
python -m script.benchmark_tgv_regularization --phase calibrate --output-dir results/tgv_comparison_20261015
python -m script.benchmark_tgv_regularization --phase evaluate --output-dir results/tgv_comparison_20261015
```

`--phase plot` 只读取保存结果重画，不重跑反演。已有运行在完整协议一致时自动复用；
变更协议必须换输出目录。原有结果不覆盖。

`protocol.json` 保存协议和环境；每类场的 `selection.json` 保存候选评分和选参结果；
每次运行保存 NPZ 数组、JSON 元数据及日志。总表为 `summary.json`；
二维场图、误差图及剖面图均保存 PNG/PDF。正式运行时使用的源码副本及 SHA256
保存在结果目录的 `source/`。源码更改在当前分支中可审阅，结果目录由 Git 忽略。

## 正式结果

下表为测试种子 42、43、44 的全场节点绝对相对误差均值，括号给出三个种子的范围，单位 %。
这是预设参数范围及计算预算内的初步比较，不是各方法全局最优性能的比较。

| 真值 | 原梯度 Tikhonov | 仿射去趋势 | Huber TGV2 |
| --- | ---: | ---: | ---: |
| 线性 1→2 MPa | 1.221 (1.205–1.251) | 0.473 (0.362–0.581) | 0.281 (0.234–0.372) |
| 指数 1→2 MPa | 1.312 (1.285–1.362) | 0.571 (0.498–0.713) | 0.659 (0.420–0.874) |
| 七段升降跳变 | 5.168 (4.755–5.517) | 5.173 (4.767–5.523) | 3.305 (2.867–3.571) |

各方法独立选出的 γ：线性/指数场依次为 `(1e−6,1e−5,1e−5)`，
七段场为 `(1e−7,1e−7,1e−6)`，顺序同上表。线性、指数场的仿射去趋势及 TGV
选择到扫描上界，七段场的两种二次项选择到下界；尚不能判断扩大扫描范围后的排名。

左右端区间仍分别为 x≤10 mm 和 x≥100 mm。下表为三个测试种子的平均误差，单位 %。

| 真值 | 原梯度：左 / 右 | 仿射去趋势：左 / 右 | TGV：左 / 右 |
| --- | ---: | ---: | ---: |
| 线性 | 0.732 / 2.530 | 0.131 / 0.837 | 0.031 / 0.767 |
| 指数 | 0.572 / 2.825 | 0.479 / 1.291 | 0.946 / 2.432 |
| 七段 | 1.128 / 6.189 | 1.184 / 6.145 | 0.351 / 3.578 |

### 结果解释

1. **七段场出现本次最有针对性的收益。** 相对原梯度项，全场平均误差下降约 36.0%，
   三个测试种子均有改善。全场图显示区内噪声减少，剖面更接近平坦平台；但部分平台的
   幅值仍被压低或抬高，三个种子的最大节点误差仍为 17.1%–23.9%，
   不能称为精确恢复了不连续界面。
2. **线性带噪声场也改善。** 两种新项都有仿射零空间，TGV 本次表现出更强的区内去噪。
   有限扫描范围下的收益不能单独归因为 TGV 结构；原方法若采用更完整的选参范围，排名可能改变。
3. **指数场构成反例。** TGV 相对原梯度项改善，但平均全场误差高于仿射去趋势项约 15.5%，
   两端误差均更大。其对局部斜率变化的惩罚会压制真实曲率，这是与本次端部误差相符的机制解释，
   还没有通过独立消融实验定量分解其贡献。TGV 的三种子误差范围也更宽。
4. **位移选参不保证模量最优。** 指数场 TGV 两个候选 γ=1e−6、1e−5 的验证位移代价
   分别为 2.922529e−6、2.920161e−6，相差仅约 0.081%。一次重复观测对这个选择的区分很弱。
   未根据最终模量误差重新选择 γ，也未用 log E 表示将指数真值移入零空间。

### 收敛与代价

27 次最终测试运行全部获得 SciPy 成功状态。TGV 七段场迭代数为 1999、1839、1833，
已接近预算；三次最终联合梯度的二范数均小于 8.1e−12。校准阶段弱 γ=1e−7 的三个 TGV
候选均耗尽 2000 次迭代，它们没有被选中；这些失败日志保留，不将其误报为已收敛的参数路径。

| 真值 | 原梯度单次平均秒 | 仿射去趋势单次平均秒 | TGV 单次平均秒 |
| --- | ---: | ---: | ---: |
| 线性 | 5.70 | 3.33 | 12.47 |
| 指数 | 6.12 | 3.32 | 13.26 |
| 七段 | 11.47 | 11.61 | 34.12 |

上述为当前机器的墙钟时间，选参成本不计入单次时间，完整日志另有记录。

**结论：保留 TGV 作为分区材料的候选，不全面替换现有默认项。** 本次支持的结论是
TGV 在预设协议下改善了线性和七段场，但指数场端部精度及计算成本不优于仿射去趋势。
扩大参数范围、改变 r/δ、处理相关噪声与边界模型失配、测试真实七区几何仍未验证。
若后续需要决定实测数据的默认方法，应重新预先固定验证协议并使用新的测试噪声或实验数据。
