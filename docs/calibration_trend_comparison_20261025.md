# 反演模量与分层标定的连续趋势参照

当前图件入口为 [各算法趋势对比](../results/dic_full/calibration_trend_comparison/index.html)，根目录“打开结果”进入的总览也链接该页。本项只更新保存结果的绘图，不新增反演或扫描。

## 参照的含义与构造

实际试样按七区制造；连续模量反演与分层标定的比较同时保留阶梯参照、标定组内标准差和一条连续线性趋势。趋势线用于查看整体空间变化，不把分层实测值改称连续梯度真值，也不以趋势吻合代替层间突变、局部偏差或二维场评价。

输入为各运行第1步冻结的七组 `independent` 标定，保留 `infill_percent`、批次、样本数、均值与 SD。其源数据为 `post_tensile_test/analysis_results/mixed_infill_20261017/group_summary_and_residuals.csv`，沿用该目录 `linearity_report.md` 已定义的七组均值等权线性拟合，不混入 `individual_optimal`，不按反演结果重选曲线阶次。跨批桥接及标定转移的限制不由线性拟合消除。

令填充率百分数为 p（40、50、…、100），最小化七组均值对 `a+b*p` 的残差平方和。本组得到

`E_trend = 473.97089114042745 + 18.406514434781588*p` MPa。

该系数与既有混合批次线性报告一致。七组均值拟合 R²=0.974059699，RMSE=60.075345 MPa；这些是同一标定数据的拟合描述，不是连续材料真实性、试样间批次等效或反演精度的验证。

空间映射仅用于这条辅助参照：将原六个材料界面分别赋予相邻名义填充率的中值 95、85、…、45%，由既定界面得到

`p(x) = 104.84204688721255 - 0.625*x`，x 单位 mm。

相应趋势斜率为 −11.504071521738497 MPa/mm。40%—100%的有效参照范围为 x∈[7.747275019540072, 103.74727501954004] mm；两端超出标定范围的部分不外推。七个锚点是原连续16 mm目标比较窗口的名义中心，不能解释为完整制造端区（35 mm）的几何中心。实际七区界面、端部覆盖缺失、ROI尺寸和阶梯场均保持原定义；不按裁剪后的ROI两端重新居中或等分。该 p(x) 不表示实际填充率连续制造。

## 图件与计算状态

紫色点划线始终表示同一线性参照。黑色虚线／阶梯为分层标定均值，灰带为标定试样间 SD；识别曲线的色带为横向空间离散，二者均不是识别置信区间。

覆盖全域实验已保存的 H1、横向权重10的 H1、Huber-TV、精确 TV、粗细网格、180N/280N独立识别与380N探索结果，以及380N的节点／单元模量和测试函数对照。当前第3、4步的宽度曲线、TV方法／网格对照图和平台汇总图同步加入趋势。合成测试保留其已知真值，不叠加实验趋势；历史不同域结果不混入当前全域比较。

未形成有效拐点或未通过停止条件的方案保留原状态，不根据标定或趋势补选γ。统一分区Q4原型的00/24/49曲线仍是预定失败诊断，不能作正式识别精度排名。380N仍采用假定净力319.9 N，不能改称同步实测力。各算法的网格、权重、预算差异和原始求解停止证据均保留，本图不提供消除这些差异后的严格排名。

## 复现与核验

从项目根目录运行：

```powershell
python -X utf8 -B -m lib.calibration_trend_comparison --refresh-existing
```

实现位于 `lib/calibration_trend.py`（趋势定义与导出）、`lib/calibration_trend_comparison.py`（已保存实验结果的重绘与汇总），原四步绘图及已有方法报告复用同一趋势函数。趋势均为事后绘图，不进入目标、初值、γ选择或独立标定正演。

图旁保存 `calibration_trend.json`、`calibration_trend.csv` 和 `calibration_trend_anchors.csv`，包含拟合系数、映射、有效范围、七组来源和残差。汇总页另存各方法曲线、状态表和 `verification.json`。重绘前后对原数值 NPZ、运行元数据、选参表、误差表和摘要核对 SHA-256；核验清单及实际文件数以该JSON为准。

小规模核验包括独立法方程回归与生产拟合交叉核对、七个制造坐标锚点检查、平移不变性、范围外不外推、无序／缺失／非仿射界面拒绝、图件及CSV/JSON导出。实际图件另作渲染检查。物理配准、截取域边界等效、跨批标定转移和连续材料可制造性不由本项绘图核验建立。

研究分支的 `mesh.py`、`fem_forward.py` 等内核相对早期实验冻结版本已有修改，原四步 `--plot-only` 的内核身份检查会拒绝这些旧运行。本次不解除该保护，而由专用渲染器读取原保存场和物理坐标重绘；它不复算平衡方程，也不据此重新认证原求解器的收敛证据。

## 相对线性趋势的差异图

同一总览页新增5组两面板对比：180N、280N、380N的主算法，以及180N、380N的42×8材料／测试空间。上图为 `100*(E_width_mean-E_trend)/E_trend`，正值表示偏高，负值表示偏低；下图为其绝对值。所有正式对照共用纵轴，并保留分层独立标定相对同一直线的灰色参照。细网格用虚线，粗网格用实线，重合曲线不作人为错位。

分母与有效范围沿用上节冻结的趋势定义，不重新拟合。只评价 x∈[7.74727501947,103.74727501947] mm，不外推。此处“相对误差”是对辅助线性趋势的差异，不是对未知实验真值的误差；不能由差异较小认定算法恢复了真实连续梯度。原始网格、权重、载荷假设、停止状态及物理验证限制均保留。未选定γ的失败诊断不混入选参结果统计。

主算法直接读取前次导出的宽度均值 CSV；节点／单元空间读取各自已选场和冻结网格。节点Q4的宽度均值沿x分段线性，P0保持单元常值。P0相对误差在单元内部仍随趋势分母变化，图中保留界面两侧值，不将相对误差强行画成常值阶梯，也不把原P0模量平滑为节点场。

`relative_trend_error_summary.csv` 保存按同一物理长度加权的平均有符号差异、平均绝对差异和相对RMS。逐FE／材料分段并在过零点切分后采用Gauss积分，不按节点数加权，不让正负偏差抵消后冒充小绝对误差。8点与16点积分的各汇总量差异均低于1e-7个百分点。`relative_trend_error_profiles.csv` 保存绘图坐标、宽度均值、趋势分母和两种相对差异；`relative_trend_error_verification.json` 保存源文件哈希、原数值身份核对和积分检查。

只新增／重绘相对差异图，不重绘前次模量图，也不求解FE或选择γ：

```powershell
python -X utf8 -B -m lib.calibration_trend_comparison --relative-errors-only
```

实现为 `lib/calibration_trend_error.py`。已执行零差异、±10%比例场、范围外屏蔽、长度积分、独立 `scipy.integrate.quad` 对照与P0跳变保留检查，并检查渲染后的曲线、图例和符号说明。
