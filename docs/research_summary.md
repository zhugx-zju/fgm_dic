# 方法定位与已有证据

现阶段保留原自由二维H1作为主方法：目标是梯度材料空间表征，分层试样作为验证载体。选择依据是已有实验的标定一致性、受控仿真恢复能力和流程完成度；不宣称所有数据或全部条件下最优。

下列是**1016样本已有380N探索**，不是1023目录的新结果。319.9 N为假设净力、主ν=0.26、共同121×19网格；标定差异为七区均值平均绝对相对差异。

| 二维方案 | 标定差异 | 结果定位 |
|---|---:|---|
| 原H1 | 7.7266% | 主方法；按函数下降停止，未达GTOL |
| H1横向十倍权重 | 7.8564% | 权重敏感性，无明确整体收益 |
| Huber-TV δ=10 | 7.7232% | 与H1近似，无明确整体收益 |
| Huber-TV δ=1 | 未指定最终场 | 无有效L-curve拐点 |
| 精确TV粗／细网格 | 未指定最终场 | 求解／曲率支撑不足，未选γ |
| 已知界面二维区内H1原型 | 未指定最终场 | 50点均未通过原一阶条件，不是正式实验验证 |

原二维H1回代轴向位移整体相对误差约3.10%，横向约44.98%（分母均为对应DIC分量去刚体后的整体变形量）；轴向拟合较好不能代替完整物理验证。辅助趋势不是连续真值。

完全一维对照中，H1七区标定差异8.6359%，七层常值15.1187%；Huber两种表示16.3347%／17.8153%。区内自由H1仅固定γ诊断约15.0682%，尚未完成有效选参，不能作为正式排名。更好的位移拟合与更差的标定一致性可同时存在。

无噪声一维仿真：H1对突变七层／连续过渡真值的全场误差2.8940%／2.8456%；已知七层常值对突变真值接近数值精度。区内自由H1的准确恢复属于预设强γ诊断，L-curve未选参。连续过渡真值下分层常值的最大局部误差约14%，不能只看分区均值。

解释：跨区域H1平滑能稳定实测反演，但会模糊真实突变。当前证据不能区分DIC误差、材料实际差异、边界近似与标定转移各自的贡献，也不能证明试样实际为连续梯度。
