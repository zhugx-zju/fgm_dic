# 121×19 粗网格仿真 L-curve 与实验进入条件

本轮使用单一 gamma 的区内梯度正则，先在仿真上检验，再决定是否准备实验反演。
本协议在主扫描前冻结；不以真值误差选择 gamma、修改扫描范围或放宽判据。

配置入口 `unified_coarse_lcurve_config.py`，输出
`results/unified_gradient_layered/coarse_lcurve_20261022/`。
仍分别执行准备、正演、反演、比较，不增加总 batch：

```powershell
python -X utf8 -B -m lib.unified_coarse_lcurve prepare
python -X utf8 -B -m lib.unified_coarse_lcurve forward --case layered
python -X utf8 -B -m lib.unified_coarse_lcurve inverse --case layered
python -X utf8 -B -m lib.unified_coarse_lcurve compare
```

连续二维和混合二维将 `--case` 分别改为 `continuous_2d`、`mixed_2d`。
已有图用同一命令加 `--plot-only` 重绘。扫描已完成则拒绝重算；未完成扫描按
逐点保存记录续算，不增加已完成点的预算。

## 固定的数值定义

从原粗网格冻结输入读取实际几何、全部 23,920 个测点、面积权重、六个材料位置
及 180N 对应净力；不读取原识别场或独立标定作为初值。位移网格 121×19 单元，
2,440 节点；七个二维 Q4 分支各保留完整节点，共 17,080 个材料系数，不绑定 y 行。
已知界面属于本阶段显式几何先验，不称为盲识别。

目标为 `0.5*r.T@W_area@r + gamma/2*sum_i integral chi_i |grad E_i|^2`，
ν=0.26、ε=0.3 mm，3×3 Gauss、每方向二分。没有模量或噪声尺度归一化。
固定界面权重及区域刚度型正则矩阵预装配；所有分支与 tanh 非紧支撑尾部保留，
不作活动集截断。通过与原映射的目标及导数比较确认数值等价。

先由本组观测拟合均匀模量，再在七个区域常值组成的子空间内从该均匀值优化，
最后释放全部二维 Q4 系数。该初始化只用观测和声明的已知界面，不使用真值或
材料标定；其正演预算另行保存。这是避免强正则下常值方向条件数过大的数据初始化，
不是将最终模型约束为区域常值。

每个 gamma 最多 1,500 次迭代、3,000 次正演评价，FTOL=1e-30、GTOL=1e-9。
按递减 gamma 从通过一阶条件的点延续；失败点保存并排除，不由其场延续。
50 个 gamma 在 1e-12—1e-4 对数均匀分布。

L-curve 使用 `rho=sqrt(r.T W_area r)`、`eta=sqrt(R_intra)`，不将 gamma 放进纵坐标。
沿用 `fgm_asm/l_curve.py` 的最大有效正曲率、内部拐点及两侧有效支撑规则。
无有效拐点则该算例选参未完成，不自动改用其他方法或按真值补选。

## 仿真生成与独立评价

三类真值均另存，不在选参阶段读取：

- 七区分层：区域模量沿 x 为 2400、2200、2000、1800、1600、1400、1200 MPa。
- 连续二维：`2350-1000xi+140(eta-.5)+80sin(2πxi)sin(πη)` MPa。
- 混合二维：区域基值加 `180(xi-.5)+140(eta-.5)+60sin(2πxi)sin(πη)` MPa。

`xi=x/L, eta=y/H`。分层／混合真值为固定尖锐界面；反演有限平滑模型因而有表示
失配。正演采用独立的 242×38 网格，另用 363×57 作离散差异诊断；尖锐界面按
物理位置作子区域积分。连续／混合包含 Q4 不能精确表示的二维变化。

合成扰动为预设的两个分量各 0.0005 mm 独立高斯噪声，种子 20261022 加算例序号；
独立扰动种子为 20261023 加算例序号。该量级是仿真条件，不称为 DIC 纯噪声估计。
有限元离散差异另列，不混作测量噪声。真值评价采用共同 735×129 物理网格及
面积梯形积分，不用原生网格分区积分差异判断收益。

## 实验进入条件

三种算例必须全部取得有效 gamma，并首先满足：

- 全场模量相对 RMS ≤5%。
- 七区均值平均绝对相对误差 ≤3%，最差区 ≤8%。
- 各界面左右 `2 epsilon` 物理窗口的模量差，与相同真值窗口相比，误差相对于
  全域真值平均模量 ≤3%；连续真值也检验，防止只看平均误差掩盖虚假阶跃。

初步恢复通过后，在所选 gamma 固定下分别检验重新初始化、独立噪声扰动和两组
未知界面初值。命令为原 `inverse` 加 `--validate`，不重新选 gamma：

```powershell
python -X utf8 -B -m lib.unified_coarse_lcurve inverse --case layered --validate
```

场间相对 RMS 差异须 ≤3%，且相关求解均通过一阶条件。分层／混合未知界面的
最大位置误差须 ≤0.44 mm。未知界面初值为等距候选位置 ±0.2 层间距，约束为
等距中心 ±0.4 层间距；不读取真实制造位置初始化。连续真值不评价“真实界面”位置。
这是固定已知界面 gamma 后的几何敏感性检查，不冒充未知界面独立 L-curve 选参。

若任一算例不能选参或不能稳定恢复，则保留全部失败证据，实验进入条件未满足。
通过本轮仿真仅允许准备实验条件性反演，不代表坐标、狗骨截取边界、ν或材料
标定转移已获物理验证。实验仍须分别使用 180N／280N 自身位移初始化、选 gamma、
识别，并保留已知／未知几何协议区别，不以另一平台或标定误差选参。
