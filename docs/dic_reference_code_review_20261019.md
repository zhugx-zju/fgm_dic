# DIC 参考一致性的实现审查

## 范围与结论

审查对象为提交 `35430c8bd73779318cbc85110a1a3e3a4807319f` 的当前四步入口及其共用内核，依据 [坐标、位移基准和边界一致性](dic_reference_consistency.md) 核对。当前配置已采用原始面积加权 Tikhonov 目标和识别平台 L-curve 选参；本次检查不运行新方案的实验反演，不把旧选参结果作为新方案结果。

**未发现主求解删除轴向伸长、只对 DIC 做不对称基准处理、夹紧整端、缩放点云或把两套网格混为一套的错误。** 发现一个跨平台参考检查漏洞，以及两个位移基准的追溯/显示缺口。后两项不直接改变反演目标或识别模量。

物理配准仍为 `assumed_center`，是明确记录的未核验条件，不是刚体拟合已经解决的位置问题。本次保持既定均布牵引和材料模型，不重新评价这些物理近似。

## C1：无共同测点时，跨平台参考检查仍放行（P2）

位置：[lib/experiment_data.py](../lib/experiment_data.py) 的 `check_platform_reference`，143—150 行；调用入口为 `prepare_dic`。

函数只在共同网格 ID 上比较参考坐标。共同点数为零时，`max_error=None` 跳过异常判断，报告记录为 `common_grid_points=0`，流程继续。此时没有证据确认两平台来自同一初始参考，却仍能生成可供后续步骤使用的 prepared 输入。

受控复现以真实 180N 平台为基础，仅在内存中为第二平台修改所有网格 ID（加 10000），并将原始参考 X 平移 0.5 mm。两个点云仍在配置的物理域内。结果：

| 检查 | 实际结果 |
| --- | --- |
| 共同测点数 | 0 |
| 最大共享坐标差 | 未定义（null） |
| 第 1 步状态 | `prepared` |
| 域外点数 | 两平台均为 0 |

这与“完成跨平台初始参考一致性检查后再比较”的约定不一致。建议共同 ID 不足以核验时明确停止，或要求独立的参考对应证据并保留未核验状态；不能用“没有发现差异”代替“存在可比较的共同点”。

当前真实 180N/280N 数据有 13,845 个共同点，最大参考坐标差约 9.92×10⁻⁹ mm，未触发此漏洞。本复现不说明当前数据已经配错，也不要求所有合理的不同观测覆盖必须有相同网格；缺少共同点时需要另一个明确的核验途径。

## C2：计算了刚体变换，但正反演结果未保存其参数（追溯缺口）

位置：[fgm_asm/load_case.py](../fgm_asm/load_case.py) 的 `evaluate_observation` 返回 `rigid_coefficients` 和 `rigid_origin`；[lib/dic_case_workflow.py](../lib/dic_case_workflow.py) 的 `forward_calibrated`（316—318 行）和 `inverse_dic`（396—404 行）保存结果时未写入这两项。

当前结果有 FEM 规范下的 `*_U` 和 DIC 参考下的 `*_prediction`，但缺少将两者连接的平移、转角及其转动中心。数学运算正确，参数也可通过 H、U 和已配准预测重新推导；不过结果文件不能直接展示“移动了多少、绕哪里转动”，与完整可检查的基准转换链仍有距离。

建议每个平台、每个 ν 保存 `rigid_coefficients`、`rigid_origin`，并明确三维系数顺序为 cx/cy/theta、平移单位 mm、微小转角无量纲（rad）、参考位置单位 mm。该建议补充结果追溯，不改变拟合方法，也不以固定刚体系数约束不同载荷。

## C3：居中显示未在单图直接标明（显示缺口）

位置：[lib/dic_preprocessing.py](../lib/dic_preprocessing.py) 的 `save_dic_comparison`，194—206 行；第 1 步由 `plot_saved_stage` 把 DIC 均值作为 `display_origin` 传给 `plot_displacement_clouds`。

代码从所有位移场减去同一个 DIC 分量均值，逐点 CSV 保留原始值，HTML 也解释了显示规则。但 PNG/SVG 的位移标题仅写 DIC/模型、ux/uy，没有注明居中或所减均值。单独查看或导出图片时，容易把色标当成相对初始图的原始分量值，从而误以为较大的位移被求解器删除。

受控显示检查中，DIC 轴向分量均值为 0.36 mm，图中均值约为零，逐点 CSV 保留原值；图题为 `controlled, nu=0.26 / DIC: ux`。这证实数据处理本身符合约定，而单图的位移参考说明不足。

建议位移图直接标注 `u − mean(u_DIC)` 或“DIC 均值居中”，并保存/显示每个平台的两个分量均值。这样不必仅依赖 HTML 才能正确解释图片。

## 已确认一致的核心路径

| 环节 | 实际实现与检查 |
| --- | --- |
| 初始构形 | 依配置由 X−DX、Y−DY 恢复；不直接用加载后位置构造观测 |
| 位置与方向 | 一个 Q/b 用于全部平台，位移只乘 Q；当前 b 由识别平台确定，没有逐平台居中 |
| 部分观测与双网格 | 物理域保持 70×20 mm，DIC 在真实坐标通过 Q4 的 H 比较，未观测边带不填零位移 |
| 力学边界 | 两端 ±F/(wt)，侧边自由，三个规范约束未变成整端固定 |
| 数据项 | 保留原始观测，逐次材料评价中拟合 HU+Rc；相对误差归一化只服务显示/统计 |
| 刚体基准 | 同一正问题更换合法规范约束后，应变和配准残差仅有舍入差 |
| 伴随 | 使用联合残差形成伴随右端，有限差分中每次重新拟合刚体分量，梯度一致 |
| 绘图与导出 | 三个位移场共同减去同一观测均值；CSV 保留未居中位移及原始残差 |
