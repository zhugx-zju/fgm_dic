# 固定界面局部支撑与预条件：380N小规模受控对照

本轮只检验材料自由度组织与求解，不进行L-curve选参，不追加50点扫描。
配置`unified_support_pilot_config.py`；独立输出
`results/unified_gradient_layered/support_precondition_pilot_20261023/`。

## 固定条件

380N输入、坐标、23,920测点、面积权重、121×19位移单元、ν=0.26、六个制造界面
均读取上一组冻结输入；净力仍为319.9 N假设值，非同步实测力。所有方法使用同一组
已保存的380N数据拟合区域常值初始系数，不读标定作为初值。原初始化未通过一阶
条件的状态保留，不能称为已收敛七常值识别。

实际冻结配置的γ对应上一扫描的编号00/25/49，即1e-4、8.28642772854686e-9、1e-12。
每点从同一初始系数独立启动，不作延续；最多400迭代、600次正演。
原始log系数边界为log(100)—log(6000)，一阶判据仍为原坐标单位投影梯度∞范数
≤1e-9。SciPy控制组FTOL=1e-30；函数下降停止不等同一阶通过。投影L-BFGS控制
只按原坐标一阶条件、预算或线搜索失败停止。预算耗尽保留最后接受场。

全部方法使用3×3 Gauss、每方向二分，并按相同六个物理界面切分。只删除全局
全为零的填充积分行，144行缩为54行；每个非零积分点保留。该实现优化同时应用
于全部方法，不计为局部支撑或预条件独有收益；已有矩阵／位移等价核验。

## 五个控制组

| 标识 | 材料表示 | 优化方法 | 要区分的影响 |
|---|---|---|---|
| smooth_full | 原tanh七个完整Q4分支，17080参数 | 原SciPy L-BFGS-B | 原表示参考 |
| sharp_full | 固定尖锐七分支，17080参数 | 原SciPy L-BFGS-B | 与上项比较界面模型变化 |
| sharp_local | 尖锐分支，真实支撑2680参数 | 原SciPy L-BFGS-B | 与上项比较支撑消元 |
| local_projected | 同一2680参数 | 投影L-BFGS，无均值／起伏预条件 | 控制优化步骤变化 |
| local_metric | 同一2680参数 | 相同投影L-BFGS，加均值／起伏逆度量 | 与上项比较预条件 |

局部支撑按背景Q4基函数与区域正面积交集确定，保留原背景节点的系数及其盒约束，
不是给新插入界面节点直接套相同边界，也不是截断tanh尾部。完整尖锐表示与局部
尖锐表示的物理可行场、数据项和区内正则在数学上相同。小算例已核对目标、导数
及有限差分；2680在本次实际几何上重新计数。所有y行独立。

平滑和尖锐模型是不同模型：前两项不称为纯参数消元。旧50点使用不同积分与预算，
只能作历史参考，本轮五组才是统一配置下的受控比较。

## 预条件的定义及计费

保持目标`f+gamma/2*R_intra`不变。辅助度量在物理模量系数c=exp(m)中，将每区
变化写为常值模式与面积加权零均值起伏：δc=T a+z、Pz=0、PT=I。
区内梯度矩阵L仅作用于起伏；用初始场下七个区域常值响应的观测Gauss-Newton
曲率H控制均值。应用逆度量时，分别解带零均值约束的Neumann型系统与7×7均值
系统，再以diag(c)^(-1)映回原log系数方向。目标、模量边界及停止判据均未改变。

H用七个区域常值log方向的中心差分构造，步长1e-4，需14次正演及伴随；setup
单独保存并计费，在三个γ间共用，不隐藏在求解收益中。该H只描述均值子空间，
其条件数不是全Hessian条件数，也不证明完整场可辨识。

预条件矩阵仅修复浮点行和误差，数值量另存；正则目标的矩阵不改写、不加新的
正则权重。均值H不满足声明的正定条件时拒绝该预条件，不自动补岭参数。
投影L-BFGS对照共用Armijo回溯、15对曲率记忆和边界投影；有不下降方向时按相同
规则退回投影梯度，次数记录。原坐标一阶证据决定通过，不用新方向的尺度伪造成功。

## 执行、证据与后续判断

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
python -X utf8 -B -m lib.unified_support_pilot prepare
python -X utf8 -B -m lib.unified_support_pilot solve --method smooth_full
```

其余组分别替换`--method`。每个方法独立执行并保存三个γ的参数、位移、梯度、
历史、FE次数及停止状态，不新增总batch。已完成方法拒绝覆盖；中断方法可由
保存点继续，预条件setup重建的额外开销需另行保留，不能计作相同总预算。

前置检查见`unified_support_checks_20261023.json`：完整／局部尖锐目标与梯度、
局部梯度差分、均匀解析解恢复、触界二次目标、硬预算接受场，以及积分填充消元。
正式比较还须核对各点的原坐标驻点、目标下降、物理场与触界情况；较少参数、
较低残差、求解成功三者分别评价。三点不足以选择γ，不以标定差异补选。

若局部表示及预条件有效，下一阶段才独立改变材料网格分辨率并重做验证；
当前不同时引入粗材料网格、未知弯曲界面或新正则项，避免混淆改进来源。
