## 公共算法接口

- `fgm_asm.research.solve_forward`：统一厚度和双端均布牵引，支持节点模量及独立正演的分区函数。
- `fgm_asm.research.make_observation_case`：把仿真采样或实测点构造成同一种输入。
- `fgm_asm.load_case.evaluate_observation`：在测点空间加权拟合三个刚体模式，输出配准残差和伴随右端。
- `fgm_asm.inverse_solver.lbfgs_inverse_solver_scipy(observation_cases=...)`：多载荷二维节点场反演。完整节点质量矩阵入口仍供原研究使用。
- `lib.research_workflows`：调用同一个内核，组织合成、标定正演及真实反演，训练和预测载荷显式分开。

数据项是 `0.5*r.T@W@r`，其中 `r=d-Hu-Rc`。伴随方程 `K*lambda=H.T@W@r`，模量梯度为各载荷的 `lambda.T*(dK/dE)*u` 之和，再乘 log(E) 链式因子。通过消去刚体模式后的最优性条件，不需要对配准系数 c 再求导。

独立标定的阶梯模量在实际 Gauss 坐标计算，并在默认正演网格上对齐分区边界。主反演仍使用连续 Q4 节点模量，两者表示不同，区域统计和界面误差应据此解释。实验 inverse 模式中的标定比较也独立使用正演网格，不随反演网格粗化而改变标定材料表示。

补充失败记录：将端到端均匀材料测试从真实初值 1700 MPa 改为 1500 MPa 后，使用面积/0.001 mm 噪声方差权重、11×2 反演网格、gamma=1 和 500 次预算时，优化达到上限，节点模量范围约 1697.4—1702.6 MPa。此处数据项和正则的尺度导致慢收敛，不能报告为优化成功。该**均匀极限集成测试**随后显式采用 gamma=1e6，真值恰在仿射正则零空间，从错误初值恢复 1700 MPa；这仅检查接口及尺度链路，不构成真实实验的选参证据，实验配置的 gamma 未据此修改。两种 CLI 在反演未收敛时保存结果并返回退出码 2，实验元数据明确记为 `not_converged`。

运行输出位于根 `results/`，采用独立名称；不覆盖迁移前结果。真实平台检查、标定正演和最终合成烟雾结果以各自 `run_metadata.json` 为来源。测试使用当前可用 NumPy 2.3.5、SciPy 1.15.3 和 Matplotlib 3.10.3；当前机器的实际命令及运行时路径记录在计算元数据中。
