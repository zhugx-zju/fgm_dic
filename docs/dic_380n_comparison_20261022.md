# 380N全场DIC：反演方案对照（2026-10-22）

本项将第3次试验新导出的380N位移用于自由二维模量反演，检验较大位移信号是否改善识别。结果入口为 `results/dic_full/load380_20261022/index.html`。实际力缺失，本项属于载荷假设下的探索，不能代替完成力配对的实验验证。

## 输入和固定条件

- 原始目录：`post_tensile_test/1016/sample_2/3/380N_2/all_region`，阶段618—632，共15帧，含EXY。使用原CSV读取器；没有修改读取器、原始导出或旧结果。
- 380N暂取319.9N，即示值380N减去已确认的60.1N初始偏置。用户明确授权该探索假设；该值不是同步实测平台力。
- 180N、280N仍用259—273和436—450帧，对应119.77617870327234N、219.7354506515086N。
- 三个平台共同参考点26,585个；按原材料坐标窗口裁剪后均为23,920点。参考坐标的跨平台最大差约1e-8mm，未作跨度缩放或重新居中配准。
- 保留原坐标变换、毫米单位、真实承载宽20mm、厚3.2mm、截取域端力F×H/20、三个刚体规范及内部侧边自由近似。
- 仅380N确定均匀初值及γ。180N、280N为此前查看过的跨载荷诊断，不称为新独立测试。独立标定和制造分区只用于正演与事后评价，不用于识别初值、目标或选参。
- 主ν=0.26；正式方案另计算0.24/0.28/0.33固定γ敏感性，不把边界最优当作真实ν。模量始终保留独立y向自由度。

|280N|53.86586|6.06892|0.22209|0.18156|

380N横向信号约为180N的2.51倍，时间变化量接近，支持有效信号增强。但两个平台的共同最小二乘幅值比为2.85441，与假定实际力比2.67081不同；移除最佳共同幅值后仍有轴向2.76675μm、横向1.23589μm的场差。380N相对280N移除最佳共同幅值后，轴向/横向差异仍约1.61695/2.19165μm。幅值拟合只作观测诊断，不用来反推实测力或重新标定模量。差异可能包含载荷假设、时间效应、材料非线性、相关误差及模型不一致，现有证据不能把全部问题归因于随机DIC噪声。

## 方案和预算

`dic_380n_config.py`为本项独立入口；本项不修改主配置，已冻结的180N结果保留。改变METHOD后分别运行原四个步骤。正式方案均以121×19位移单元、2440个独立节点模量为基础；细网格TV为242×38单元、9477个独立节点模量。观测均为23,920点。

数据项默认 f=0.5ΣAᵢ(rₓ²+rᵧ²)。横向十倍权重方案改为 f=0.5ΣAᵢ(rₓ²+10rᵧ²)，同一权重贯穿刚体配准、伴随、初值和选参；统一报告另用共同等权重评价预测。

|METHOD|模量空间|目标中的正则项|
|---|---|---|
|h1|连续节点Q4|(γ/2)∫|∇E|²dA|
|h1_uy10|连续节点Q4，横向残差平方权重10|(γ/2)∫|∇E|²dA|
|huber1|连续节点Q4|(γ/2)∫ρδ(|∇E|)dA，δ=1MPa/mm|
|huber10|连续节点Q4|(γ/2)∫ρδ(|∇E|)dA，δ=10MPa/mm|
|exact_tv|连续节点Q4|γ∫|∇E|dA|
|exact_tv_fine|细网格连续节点Q4|γ∫|∇E|dA|

ρδ(z)=z²/(2δ)（|z|≤δ），否则为|z|−δ/2。未使用模量参考值或人为噪声归一化。正式方案γ均为50个对数等距点：梯度平方1e-12—1e-4，TV类1e-10—1e-2。仍用原三点离散正曲率和双侧各两点支撑规则，无有效拐点时不补指定γ。

原五种材料/测试空间对照另外在同一42×8网格复算，全部23920观测点保留。节点模量387个，单元独立模量336个。位移仍用Q4：

1. 节点连续模量，梯度平方正则，ψᵢ=Nᵢ。
2. 节点连续模量，δ=10的Huber-TV，ψᵢ=Nᵢ。
3. 每个单元独立Eₑ，正则为(γ/2)Σ|F|ρδF(Eₑ−Eₑ′)，δF=(10MPa/mm)dF，ψᵢ=Nᵢ。
4. 第1项的测试函数改为ψᵢ=Nᵢ+0.25hₓ(1−s²)(1−t²)∂ₓNᵢ。
5. 第3项采用第4项测试函数。

F是相邻单元的共享边，dF是单元中心的法向间距。第4、5项是已有bubble-PG，非论文SUPG。非对称正问题、转置伴随和模量导数保持一致。两种载荷的该组对照均重扫50点，避免把旧21点与新50点混为纯载荷对比；失败的ABNORMAL线搜索最多重启两次，使用原剩余预算，原状态保留。

### 精确TV的数值诊断

原始—对偶法保留驻点、分裂残差、对偶可行性和Fenchel间隙的原严格条件。函数下降停止不替代这些条件。

380N细网格原均匀初值在首个非零TV点用满12000次FE仍未通过，并出现迭代振荡。保留原场、日志和中断未保存计算量范围；同一380N、同一γ的已收敛粗网格场仅作为数值初值，不把粗γ作为细网格选参结果。后续剩余γ先做600次有界扫描，再仅为五个曲率支撑点补算至新阶段每点12000次上限；只有严格通过一阶条件的点进入最终L-curve。近似未收敛范数仅分配计算预算，不能接受γ或排名。

剩余粗网格弱γ点保持每次12000次上限，固定同一已收敛380N粗场并行计算。细网格独立参数任务的并行/顺序短程核验完全一致。上述数值初值和预算分配变化均单独记录；含中断与诊断的实际总预算不相同，不作相同成本效率排名。完整记录位于各`03_inverse/`及相关protocol.json。

## 已核验的结果

区域均值用实际制造边界精确切分并积分，避免原生高斯点分组差异混入比较。这里的标定差异为七区均值相对独立标定均值的绝对百分比差再平均，不是相对于未知真值的误差。

| 正式方案，ν=0.26 | 180N识别的标定差异(%) | 380N识别的标定差异(%) | 380N重新选定γ |
|---|---:|---:|---:|
|梯度平方|14.95303|7.72656|3.7275937203149377e-8|
|梯度平方，横向十倍权重|13.03867|7.85644|7.906043210907701e-8|
|Huber-TV，δ=10|14.95280|7.72317|2.5595479226995334e-6|

以上三组各完成50点和四个ν；最终按函数下降停止，未达原GTOL。Huber-TV的δ=1完成50点但无有效拐点，不指定正式γ。精确TV粗网格50点中27点通过一阶条件，其中9点非零TV，但缺少曲率峰支撑，状态为`l_curve_insufficient_corner_support`；细网格完成全部50点和五点补算，只有18个零TV常量解通过，状态为`l_curve_insufficient_valid_points`。两组均未指定γ、未生成正式最终模量，不能据此评价精确TV的恢复优势。

380N原梯度平方识别场对280N的轴向RMSE为3.74005μm，原180N识别对应约2.00287μm。标定均值更接近和跨载荷预测变差同时存在，不能只选有利指标宣称实验验证通过。单元独立模量和测试函数修改的380N小网格标定差异约7.68%—7.76%，没有显示明显额外收益。阶梯平台仍未完整恢复。
