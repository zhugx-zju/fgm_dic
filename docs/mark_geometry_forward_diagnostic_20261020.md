# 73/85 mm 标线定位下的独立标定正演诊断

**历史输入说明：** 本记录使用旧_3数据，对端别、方向和留边作候选扫描；冻结输入现位于 `results/dic/history/pre_marks/01_prepared/`。当前已确认的+Y方向、region数据及固定标线中点重算见[新记录](mark_geometry_correction_20261020.md)。以下数值保留其原候选条件。

## 结论

按现有73/85 mm端距建立条件性几何后，材料位置偏移会改变正演结果，但本次测试未使独立标定正演与DIC两分量同时吻合。固定ν=0.26，观测域偏向制造高填充率端约6 mm时，180N轴向RMSE由4.048降至3.460 μm，280N由6.812降至5.757 μm；预测伸长仍分别偏大17.43%和13.60%。偏向低填充率端时误差反而增大。

在两种偏心方向、两种制造轴向、三种留边分配及ν=0.24/0.26/0.28/0.33的48个新几何候选中，仅按180N面积加权失配排序的最小候选，180N/280N伸长仍偏大17.23%/13.41%。因此，**在当前毫米尺度、线弹性材料模型和载荷边界近似固定的条件下，仅修正本次标线位置不足以解释全部差异**。这不是对真实材料方向的识别，也不能据此认定DIC或材料标定错误。

## 几何候选的定义

以制造中心为零、填充率递增为正x。采用名义总长220 mm、端距来自相对外端的前提，标线间距62 mm，中点c为−6或+6 mm。现有点云假设全部位于标线内，剩余轴向留边合计`62−61.36643181366=0.63356818634 mm`。留边未知，分别考察全部留在制造正端、两端均分、全部留在制造负端。

固定DIC数值坐标ξ∈[0,L]，材料位置通过

`x_manufacture = s*(ξ−L/2) + c + δ`

设置；s=+1/−1分别代表制造填充率沿DIC x递增/递减；δ取−0.31678409317/0/+0.31678409317 mm。c和s分别扫描，不擅自确认73 mm对应哪一端。模型ID中的`c`是标线中点、`s`是方向，`m0/m1/m2`依次对应δ的负值/零/正值；`nu`为泊松比。

均分留边时，c=−6的制造覆盖为[−36.6832,24.6832] mm，各区长度为12.6832/16/16/16/0.6832 mm；c=+6时为[−24.6832,36.6832] mm，各区为0.6832/16/16/16/12.6832 mm。反向候选在DIC x中的材料顺序相反，但制造范围与串联柔度相同。

上述扫描依据近似测量值构造离散假设，不是几何置信区间；未考虑73/85 mm的测量公差，也未独立验证当前毫米尺度、点云确实在线内或横向位置。本次没有扩大DIC范围，完整七区选域仍按[后续执行方案](dic_roi_geometry.md#后续执行大小范围-dic-衔接与全分区选域)办理。

对轴向串联近似，`Δu≈F/(20t)∫dx/E(x)`。偏向高填充率端会减少低模量区覆盖、增加高模量区覆盖，因而预测伸长下降；相反方向会增大伸长。均分留边、ν=0.26时，高填充率端偏移解释约23%/27%的原伸长偏差，仍留约9.52/14.08 μm的伸长差。残差云图仍具有轴向系统趋势，横向收缩幅度也未同时匹配。

## 核验与可追溯性

- 重新计算旧ν=0.26基线，两平台测点预测与原冻结结果的最大差均为0 mm。
- 同域均匀E=1800 MPa解析解最大节点误差4.63×10⁻¹⁴ mm；两平台分别求解的节点位移满足载荷比例关系，最大差5.13×10⁻¹⁶ mm。
- 独立串联柔度与二维正演同时保存，作为轴向解释的独立检查；不替代二维横向位移检验。
- 四个偏心/方向的均分留边ν=0.26模型，以及180N目标最小候选，均在140×40、280×80网格复核。均分留边模型最后一级细化的预测差异不超过轴向0.00097 μm、横向0.00025 μm；目标最小候选对应0.01058/0.00281 μm，远小于剩余残差。基础网格中的“最小候选”不据此认定为精确几何最优。
- 正式配置、独立标定、准备数组、既有正演数组及力学/观测内核的SHA256前后一致。此次只新增独立诊断输出及说明，没有更改四步配置或重算主反演。
- 环境Python3.13.2、NumPy2.4.0、SciPy1.17.1；代码版本、临时驱动SHA256、输入哈希及全部候选参数见`protocol.json`。本项未修改梯度或反演目标，不进行无关的反演重复计算。

输出目录为`results/dic/mark_geometry_forward_20261020_01/`，可从[诊断报告](../results/dic/mark_geometry_forward_20261020_01/诊断报告.html)浏览：`comparison.csv`含52模型×2平台指标，`geometry_coverage.csv`含实际材料区覆盖，`selection_frozen_before_280N.json`保存180N排序，`mesh_refinement.csv`含细化结果，`fields.npz`含观测、预测、节点U和刚体参数，`checks.json`含独立核验与保护文件哈希。位移及残差图以PNG/SVG成对保存，所有模型共享对应平台与分量的色标；位移共同扣除同一DIC均值，仅用于显示。
