# DIC 原始数据到算法坐标的对应

## 固定的算法坐标

算法域为 `[0,70] × [0,20] mm`，x 为拉伸方向，从 50% 区指向 90% 区；区域界面 x=11/27/43/59 mm。物理试样以中心为原点时，x_FEM=x_specimen+35，y_FEM=y_specimen+10。DIC 坐标的原点、正方向、图像行列顺序不必与此一致。

Y 正向对应哪一端目前用户不能确定，导出单位也需确认。因此当前 `DIC_COORDINATES_VERIFIED=False`，不自动选取轴向符号，也不通过反演模量猜测分区方向。

## 预处理顺序

1. **核验列定义和单位。** X/Y 是测点位置，DX/DY 是相对初始未加载图的位移。必须确认这四列使用同一个长度单位；若坐标和位移单位不同，应先依据软件标定将它们分别转换到同一单位，再进行下述处理，不能直接相减。原始 CSV 始终保留。
2. **恢复初始构形。** `DIC_COORDINATE_STATE='deformed'` 时，参考坐标为 `(X-DX,Y-DY)`；若导出 X/Y 本身已属于初始构形，设为 `'reference'`，直接保留 X/Y，不能再次扣除位移。当前真实数据使用前者，并用跨帧参考位置是否一致作数值检查；该检查支持当前解释，但不能代替软件列定义与单位核验。
3. **清理并配对测点。** 排除无效数据；重复 row/col 先核对坐标及位移一致性，再去重。按固定网格 ID 对齐 15 帧，取共同有效点的位移均值并保留时间标准差。参考坐标在平台内、平台间都应一致，不给不同载荷重新平移原点。
4. **一次确定物理配准。** 根据原始照片上的标线、试样边缘和填充率方向，确定统一尺度、旋转/镜像与原点。所有平台使用同一 A、b：

   ```text
   [x,y] = A @ [X_ref,Y_ref] + b
   [ux,uy] = A @ [DX,DY]
   A = s Q，Q Qᵀ = I
   ```

   b 只平移位置，不加到位移上。轴互换、轴反号或旋转都必须同时作用于位移分量。若四列已为 mm，s=1；其他尺度必须有独立标定依据。
5. **核验位置后构造观测。** 将参考测点叠加到 70×20 mm 域与五区界线上，检查左右顺序、宽度、有效覆盖和域外点数。保留真实点云，通过 Q4 观测算子 H 计算 FE 在这些位置的位移；不先将 DIC 重采样为 FEM 节点值。
6. **在位移残差中配准刚体运动。** 数据项只拟合两平移和一微小转动。不要把左端设为零位移边界，不扣除整场仿射伸长，也不将逐列均值作为“刚体位移”删除。这样保持双端均布牵引与真实拉伸响应。

## 如何确定 A 和 b

推荐在**初始参考图**识别三个不共线的物理位置：

| 原图位置 | 对应 FEM 位置 (mm) |
| --- | --- |
| 50% 端标线与试样中线交点 pL | (0,10) |
| 90% 端标线与试样中线交点 pR | (70,10) |
| 用于确认宽度正向的边缘点，例如 pL 所在标线的一侧自由边缘 pW | (0,20) |

令 qx 为从 pL 指向 pR 的单位向量，qy 为与其垂直、指向 pW 的单位向量，则 A 的两行为 `s*qx`、`s*qy`，b=`(0,10)-A@pL`。随后检查 pR 是否映射到 (70,10)、pW 是否映射到 (0,20)，并用另一个未参与定位的已知尺寸/点检查。这些位置可位于 DIC 有效测点之外，不应拿最小/最大有效测点代替物理标线和自由边缘。

若确认 DIC +Y 从 50% 指向 90%、+X 对应算法 +y，轴对齐时可取 A=`s*[[0,1],[1,0]]`；这只是条件示例。当前方向未确认，不能直接采用。其他方向由相应符号和旋转决定。

当前测点跨度约为 X=37.07、Y=122.79。它们是有效测点的跨度，不一定是完整标线间距或自由边缘间距。**不能仅据此判定标定错误，也不能分别缩放两轴强行匹配 20/70 mm。** 若独立标定与多个物理控制点不能同时吻合，应回查软件导出单位、初始/当前构形、ROI 边界、透视及标定设置，而不把误差吸收到模量中。

## 实际代码与检查输出

在 `experiment_config.py` 记录 `DIC_COORDINATE_STATE`、`DIC_TO_FEM_MATRIX`、`DIC_TO_FEM_OFFSET` 和配准依据 `DIC_REGISTRATION_NOTE`；完成以上核验后才设置 `DIC_COORDINATES_VERIFIED=True`。

```powershell
python -m script.run_experiment --mode inspect
```

输出包括：

- `run_metadata.json`：原始参考坐标规则、平台间坐标差、配准状态；已核验时包含 A/b、映射后范围、域内/域外点数、每区测点数。
- `fields.npz`：原参考坐标及平台位移；已核验时另存算法坐标、位移与标量噪声尺度，明确使用 mm。
- `180N_registration.png/svg`、`280N_registration.png/svg`：原始参考坐标与物理五区域；未核验时目标域明确显示待配准，不叠加假定位置。

`grid_row/grid_col` 只是测点身份，不等于物理 x/y；矩阵转置或数组翻转不能单独定义物理坐标。旧的绘图网格方向工具仍保留用于显示，当前主反演通过显式 A/b 和真实点坐标定位，不自动将坐标最小值移到零。
