# DIC 坐标、参考态与物理定位

算法域为 `[0,70]×[0,20] mm`，x 为拉伸方向、y 为宽度方向。五区为 50/60/70/80/90%，界面 x=11/27/43/59 mm。坐标和位移均按 mm 处理，不用有效点云跨度缩放模型。

## 当前数据与变换

当前输入是 `post_tensile_test/1016/sample_2/3/180N_3` 与 `280N_3`。180N 取 259—273 帧，280N 取 436—450 帧，每个平台 15 帧。按网格 ID 去除一致重复记录、对齐有效测点并取位移均值；核对平台内和平台间共享初始参考构形。

原始 X/Y 属于变形后位置，DX/DY 相对初始未加载图，故：

```text
X_ref = X - DX
Y_ref = Y - DY
x = -Y_ref + 13.41423355307
y =  X_ref +  7.60158150392
ux = -DY
uy =  DX
```

这是原有 rot90 联合变换约定，位置和位移共用正交矩阵；平移只作用于位置。两个平台使用同一变换，不分别移动原点。实现位于 `lib/dic_case_workflow.py` 的 `registration_transform` 与 `prepare_dic`；参考构形恢复位于 `lib/experiment_data.py`。

新版 `_3` 点距约 0.289464301 mm，213×65 个共同有效测点，轴向覆盖约 61.3664 mm、宽度覆盖约 18.5257 mm。当前居中后观测范围约 x=4.3168—65.6832、y=0.7371—19.2629 mm。它是 70×20 mm 物理模型内的有效观测，不代表重新定义试样尺寸。旧版更大跨度的导出不是当前输入。

**点云中心位于 FEM (35,10) 及其材料分区对应仍是位置假设。** `REGISTRATION.mode='assumed_center'` 的结果保持 `coordinates_verified=false`。从代码确定了变换方式，并不等于从实验独立确认了标线和填充率端的对应。

## 物理配准的独立核验

在初始参考图定位至少三个不共线的物理位置：50% 端标线与中线交点、90% 端标线与中线交点、用于确认宽度正向的一侧边缘点，分别对应 FEM (0,10)、(70,10)、(0,20) mm。控制点可位于有效点云之外，不能用最小/最大有效测点替代。

在 `dic_case_config.py` 的 `REGISTRATION` 中填写 `landmarks` 模式的 `dic_points_mm/fem_points_mm`、误差容限和依据。程序只拟合单位尺度的正交变换与平移；不能用各向异性缩放或位移拟合改善来确定配准。其他明确模式见 [分步骤流程](dic_stepwise_workflow.md)。

## 刚体运动与真实测点比较

有限元双端均布牵引仅用三个约束固定数值刚体规范，不要求真实 DIC 在这些位置为零。比较时对位移残差统一拟合两平移和一微小转动，保留轴向伸长、横向收缩及应变；不扣除整场仿射变形或强制固定一端。

DIC 保持真实测点位置，通过 Q4 观测算子取有限元预测，不先重采样至 FEM 节点。缺失测点不补位移；域外点默认报错，裁剪必须显式配置。云图重建网格只服务显示，不改变反演观测或几何。

## 运行与保存

```powershell
python -m script.step1_prepare_dic
```

`CASE_OUTPUT/01_prepared` 保存参考坐标、位移均值、网格 ID、变换、覆盖范围、力配对、配置及输入哈希。`input_audit.csv` 列出采样与覆盖；`run_metadata.json` 记录配准依据及核验状态。后续步骤读取这些冻结文件，保存位置从根目录 [打开结果.html](../打开结果.html) 查看。
