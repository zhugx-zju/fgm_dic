# DIC 坐标、参考态与材料定位

当前计算域约61.497354×19.435484 mm，输入为`180N_2/region`与`280N_2/region`。180N采用259—273帧，280N采用436—450帧，每个平台15帧、14,484个测点。完整约定见[DIC与有限元参考一致性](dic_reference_consistency.md)。

导出位置为变形后坐标，先恢复初始位置`X₀=X−DX、Y₀=Y−DY`。全部平台共用：

```text
x  =  Y₀ + 52.25617444626 mm
y  = -X₀ + 12.10055744897 mm
ux =  DY
uy = -DX
```

坐标和位移采用同一正交变换，平移只作用于位置。保留独立毫米标定，不按名义标线间距缩放坐标或位移。

制造坐标ξ沿填充率递增；当前`ξ=36.748676795−x`。沿固定FEM x（原始+Y），材料为90/80/70/60/50%，界面12.748677/28.748677/44.748677/60.748677 mm。73 mm对应高填充率端，85 mm对应低填充率端，region边界对应标线。物理定位精度和当前采用方向的独立验证状态见[材料坐标](dic_roi_geometry.md)。

双端均布牵引以三个约束固定数值刚体规范；观测残差只拟合两平移和一微小转动，保留伸长和收缩。DIC参考点直接作为Q4节点，H置换矩阵直接读取对应节点位移，云图重建网格只服务显示，不改变观测。

当前配置入口为`dic_case_config.py`，准备结果保存在`results/dic_mesh/01_prepared/`。完整四步及`--plot-only`命令见[分步流程](dic_stepwise_workflow.md)，结果从根目录[打开结果.html](../打开结果.html)进入。旧70×20 mm、_3及不同轴向约定仅属于[历史记录](results_history.md)。
