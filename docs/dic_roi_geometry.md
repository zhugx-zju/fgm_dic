# DIC 计算域、真实截面与材料坐标

## 2026-10-20 标线尺寸更正

当前已确认：高填充率端的横线距外端约73 mm，低填充率端约85 mm；region两端对应横线，填充率沿原始+Y递增；软件采用独立毫米标定，应保留导出的坐标和位移尺度。原“各距75 mm、居中70 mm”及旧−Y递增约定均不再作为主计算输入。

以名义总长220 mm、制造中心为零，标线坐标为−110+85=−25 mm和110−73=37 mm，中点为+6 mm，推算间距约62 mm。上述端距为近似测量，总长仍为制造名义值。

### 独立毫米尺度与中点配准

当前识别数据为`180N_2/region`、阶段259—273；预测数据为`280N_2/region`、阶段436—450。各15帧，保留14,484个共同点。恢复初始坐标X−DX、Y−DY后，region轴向跨度为61.497353591 mm、横向19.435484393 mm。

标线间距推算值62 mm与独立导出跨度相差0.502646409 mm。配置采用标线中点+6 mm定位，保留独立尺度，不强迫两端同时吻合近似名义位置。得到制造覆盖[−24.748676795,36.748676795] mm，两端差分别约+0.251323/−0.251323 mm。该残差及名义总长、横向位置限制保留在冻结元数据中，不能称为精确完成所有物理配准。

当前方向为`x=+Y₀+bₓ、y=−X₀+bᵧ、ux=DY、uy=−DX`，Q为正交旋转，平移仅用于位置。制造坐标为`x_manufacture=x_FEM−24.748676795`。材料方向和横线位置来自几何确认，不能以位移拟合反推。

## 后续执行：大小范围 DIC 衔接与全分区选域

`180N_2/all_region`、`280N_2/all_region`现已取得相同阶段导出，各26,585点，跨度约117.836497×18.484156 mm。它与region采样网格不同，点距约0.288814944 mm；相同行列ID不能直接当作相同材料点。最近空间测点也只是邻近采样，不能当作严格共同点或据其差异估计相机标定误差。

本轮主计算限定为已确认对应横线的region；all_region用于覆盖和邻近样本诊断，记录在`results/dic/geometry_fix/region_all_region_audit.json`。尚未通过独立共同标线/材料点建立大区的精确制造位置，未将其裁成新的主计算域。

完整中间五区的制造范围为[−40,40] mm、长80 mm；完整平行段七区为[−75,75] mm、长150 mm。当前region仅约61.5 mm，不能称为完整五区。all_region跨度117.84 mm也不足以覆盖完整150 mm七区；能否连续覆盖目标80 mm五区还需确定位置、有效点及横向覆盖。

进一步扩域时，先核对参考图、阶段、毫米尺度和独立材料点对应，再传递标线配准并按制造范围裁剪；不自动拉伸点云、不外推缺测。物理域和观测域分开记录，重新核验端部及内部侧边近似；若覆盖40%/100%，应读取相应独立标定而非沿用五区数组。反演仍保留自由二维节点模量。
