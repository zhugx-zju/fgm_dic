# 横向位移十倍权重对照

本组检验：增强横向位移约束后，自由二维模量场及两个位移分量的拟合如何变化。横向位移同时受E与ν影响，轴向位移也包含模量信息；该对照不能单独证明横向位移是唯一有效的识别信号。

## 固定条件与权重定义

配置为`dic_uy10_config.py`，结果独立保存在`results/dic_full/uy10/`；等权重基线仍为`dic_coarse_config.py`及`results/dic_full/coarse/`。两组同用连续七区105.995085×18.484156 mm域、121×19单元、2440个独立节点E、23920个原始DIC测点、相同载荷及材料定位。

FEM x为拉伸方向，y为横向，故权重配置为`DISPLACEMENT_COMPONENT_WEIGHTS=(1.,10.)`。加权的是FEM uy=−DX，不是原始DY（对应轴向ux）。数据目标为

\[
J_{\rm data}=\frac12\sum_i a_i\bigl(r_{x,i}^2+10r_{y,i}^2\bigr).
\]

系数乘残差平方；不将位移乘10，不将横向残差乘10后再平方，不作分量幅值归一化。面积权重a_i保留。对应W用于同一残差配准、均匀初值拟合、目标函数、伴随梯度及L-curve范数；原始坐标、DIC位移、观测H与有限元边界均不改变。物理正演U应与等权重基线一致，配准后的HU+Rc可能因旋转拟合权重不同而改变。

未设置该配置项的既有实验默认为(1,1)，不修改冻结结果。系数必须为两个有限正数。

## 求解与评价协议

重新执行50点γ对数扫描，范围1e-12—1e-4，不沿用等权重γ或识别场。仅180N、预设ν=0.26选γ，再在ν=0.24/0.26/0.28/0.33下分别自由反演、固定后预测280N。目标正则仍为一阶Tikhonov，不设材料标定先验。优化预算和容差与基线一致。

四步分别运行：

```powershell
python -m script.step1_prepare_dic --config dic_uy10_config
python -m script.step2_forward_calibrated --config dic_uy10_config
python -m script.step3_inverse_dic --config dic_uy10_config
python -m script.step4_compare_results --config dic_uy10_config
```

每组内部的双分量RMS采用自身权重，不能直接跨组当作同一个指标。跨组除查看各自分量误差，还应在同一观测权重和刚体配准准则下，重评保存的物理U，并比较E(x)、二维场、分区均值。280N只作固定方案预测展示，不用于选择权重、γ或主ν。

## 核验及计算状态

14组准备数组与等权重基线逐值相同，几何、材料位置、载荷及H一致；权重向量仅横向项乘10。四个ν下的伴随方向有限差分最大相对误差约4.78e-7；独立重建加权刚体最小二乘并手算数据目标一致，增加刚体运动后的残差变化约4.42e-14 mm。默认(1,1)及无效系数拒绝检查已执行。记录在`results/dic_full/uy10/verification/weight_checks.json`。

四步已完成，50点扫描中40点按求解器条件停止，10个极小γ达到1500次迭代上限并排除。γ=8.286427729e-9的首次线搜索异常造成拐点支撑缺失；`--resume`只重启该候选的L-BFGS历史，保留原点及原选参表，用剩余1267次迭代/11534次函数预算求解。该候选累计236次迭代、525次函数计算后按函数下降停止，未改变原1500/12000总预算或FTOL/GTOL。恢复后按同一曲率规则自动选γ=8.286427729e-9，等权重基线为3.906939937e-9。

四个ν最终均按函数下降条件停止，梯度∞范数约5.04e-10—9.92e-10，均未达到GTOL=1e-12。全部50点ρ/η、8个最终位移和曲率选择已独立重算一致；所有最终模量均为有限正值。恢复执行源码哈希另记于`scan_recovery`，核验详情在`verification/final_checks.json`。

## 结果与解释

为统一参考，以下两个物理位移U均以相同的等权重W、相同的三个刚体模式重新评价，主ν=0.26，误差单位μm：

| 平台 | 等权重ux | 十倍横向ux | 等权重uy | 十倍横向uy |
| --- | ---: | ---: | ---: | ---: |
| 180N识别 | 0.873 | 1.336 | 1.456 | 1.376 |
| 280N留出预测 | 2.003 | 2.419 | 3.425 | 3.308 |

横向RMSE分别降低约5.5%和3.4%，轴向RMSE分别增大约53.1%和20.7%。因此本次十倍权重只有限改善横向响应，并未同时改善两分量。不能据此认定其模量更准确，或轴向不含模量信息。

100/90/80/70/60/50/40%区新均值约2453.5/2478.8/2368.1/2115.3/1757.7/1354.7/1109.4 MPa；100%区相对标定从+15.5%降至+2.2%，但80%/70%仍偏高约28.6%/23.8%，40%区从约−1.3%变为−9.9%。二维场最大节点改变量约355.9 MPa，变化不是各区一致向标定靠近。

两组各自选γ，结果同时包含权重与选参变化。在同一γ=3.906939937e-9的两份已停止扫描场中，E场节点RMS差约165.2 MPa，说明变化不全由选γ差异产生；该对照仍不是唯一性或材料真值验证。
