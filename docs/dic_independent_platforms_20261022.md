# 180N、280N分别独立反演：粗细网格与380N图件汇总

180N和280N分别使用本平台的DIC位移独立选择γ并识别自由二维E(x,y)。本平台位移回代、独立标定正演和跨载荷响应分别展示；当前主线不再将280N称为未使用的留出验证数据。

## 计算矩阵与数据身份

| 网格 | 单元数 | 独立E参数 | 180N识别结果 | 280N识别结果 |
| --- | ---: | ---: | --- | --- |
| 粗 | 121×19 | 2440 | `results/dic_full/coarse/` | `results/dic_full/h1_280N_independent_coarse_20261022/` |
| 细 | 367×64 | 23920 | `results/dic_full/` | `results/dic_full/h1_280N_independent_20261022/` |

两种网格均保留23,920个实际DIC测点。几何、方向、力、截面、权重和材料分区沿用全域七区定义，实际域105.995085×18.484156 mm；不补足缺失端，不将七段重新等分。180N的259—273帧对应实际力119.776179 N，280N的436—450帧对应219.735451 N；参考为初始未加载图，力已扣除60.1 N偏置。

`GEOMETRY_REFERENCE_PLATFORM='180N'`固定共同参考网格，不随识别平台切换。准备数组与原同网格结果逐项比较，确保只改变参与识别的平台。原180N求解场、γ、停止状态和元数据保留；本次只重绘其派生图。

## 独立识别协议

H1目标仍为`0.5*r.T@W_area@r + 0.5*gamma*integral(|grad E|^2)`，分量系数为(1,1)，不设置参考模量或噪声归一化。各y行模量独立。每个平台仅用自身位移计算均匀初值，然后按本平台通过停止条件的场作递减γ延续。

各平台分别在ν=0.26下扫描50个γ，范围1e-12—1e-4，只用自身L-curve最大有效正曲率选参。未通过的点排除；无有效拐点时停止并保存诊断。选定各自γ后，ν=0.24/0.26/0.28/0.33从该平台所选场分别计算，最多1500次迭代、12000次函数计算，FTOL=1e-30、GTOL=1e-12。函数下降停止和GTOL通过分别记录。

另一平台DIC及独立标定不进入该平台的模量目标、均匀初值或γ选择。将识别模量用于另一载荷，仅在已保存的两个平移与一个微小转动规则下对比位移，称为跨载荷对照。两平台都参与各自识别后，这项对照不能代替新的未使用观测验证。

## 粗网格结果

280N的50点扫描中43点按求解器条件停止，选γ=1.757510624854793e-8；原180N为3.906939937054621e-9。280N四个最终ν均按函数下降停止，最终梯度∞范数约9.94e-10—2.07e-9，均未达到GTOL=1e-12。不同载荷下原始位移失配的尺度不同，γ数值变化不单独代表材料变化。

主ν=0.26下，各自识别场的位移RMSE如下，单位μm：

| 识别E的数据 | 180N轴向 | 180N横向 | 280N轴向 | 280N横向 |
| --- | ---: | ---: | ---: | ---: |
| 180N DIC | 0.873 | 1.456 | 2.003 | 3.425 |
| 280N DIC | 1.204 | 1.461 | 1.874 | 3.398 |

各行与自身识别平台对应的列为本平台回代，另一平台为跨载荷对照。两平台分别拟合后，对本平台误差的改善不再作为未使用数据的预测精度。

相同粗网格区域统计下，180N和280N识别场的七区平均绝对标定差异分别为14.9966%和13.0722%；280N场最大的正差异仍为26.5409%，且七个标定平台未被逐一恢复。不能仅根据平均标定差异较小就认定材料测量更准确。

粗细网格各自独立选择γ。本轮同一平台在两种网格上得到相同γ，但离散、优化停止和原生区域积分口径仍不同，不能仅由场差较小宣称有限元或反演网格收敛。

`h1_280N_independent_coarse_20261022/verification/final_checks.json`独立重算了全部50个扫描点的残差/正则范数、曲率选参及四个ν的8个位移响应；各所选场均为正，保存指标可复现。原180N数值文件的274项联合哈希检查涵盖粗细两组，未被本次重绘改变。

## 细网格结果

细网格280N四步计算与出图已完成。50点扫描中38点按求解器条件停止，12点达到1500次迭代上限并从选参中排除，包含6个较强γ点及最弱6点；各点的实际预算、停止信息与初始化来源保存在`selection.csv`。独立选得γ=1.757510624854793e-8，曲率约1.752162。γ与粗网格相同，但扫描场、初始场和求解记录均在本细网格独立生成。

四个最终ν均按函数下降停止，迭代次数分别为349、1、363、440；梯度∞范数约1.07e-9—2.19e-9，均未达到GTOL=1e-12。主ν=0.26下E范围为1296.998—2689.004 MPa。各自识别场的位移RMSE如下，单位μm，保留三位小数：

| 识别E的数据 | 180N轴向 | 180N横向 | 280N轴向 | 280N横向 |
| --- | ---: | ---: | ---: | ---: |
| 180N DIC | 0.873 | 1.456 | 2.003 | 3.425 |
| 280N DIC | 1.204 | 1.461 | 1.874 | 3.398 |

细网格自身的区域统计下，180N和280N识别场的七区平均绝对标定差异分别为14.9515%和13.0481%；280N场最大的正差异为26.5973%。两平台场仍呈连续变化，未逐一恢复七个标定平台。这些数值用于同一细网格内的平台对照，不将与粗网格原生区域积分结果的差异解释为网格收益。

## 运行与复现

本轮两组数值计算均设置`OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=OMP_NUM_THREADS=1`；Python与NumPy/SciPy版本、冻结输入哈希及数值内核哈希另存各组`verification/execution_environment.json`。

在`dic_case_config.py`设置识别平台、网格及新的RUN_NAME后，分别执行原四步，不增加总batch：

```powershell
python -m script.step1_prepare_dic
python -m script.step2_forward_calibrated
python -m script.step3_inverse_dic
python -m script.step4_compare_results
```

已有组重新出图时，各步骤显式指定该组`01_prepared`及`--plot-only`。已保存场重绘继续核对准备和上游身份、网格、正演/观测与刚体内核，并检查原始残差指标；未调用的历史优化器与正则器无需被当前源码替代。新正反演仍核对全部内核。原始数值文件哈希保存在细网格280N组的`verification/original_numerical_hashes.json`中。

包含380N的总览使用显式来源参数重新生成；这是读取保存场的后处理，不替代四步数值入口：

```python
from pathlib import Path
from lib.dic_platform_comparison import write_independent_comparison

base = Path('results/dic_full')
runs = {
    'coarse': {'180N': base/'coarse', '280N': base/'h1_280N_independent_coarse_20261022'},
    'fine': {'180N': base, '280N': base/'h1_280N_independent_20261022'},
}
write_independent_comparison(runs, base/'independent_platforms_20261022',
                             load380_root=base/'load380_20261022')
```

本次两套280N独立计算的实际完成状态以各组`03_inverse/run_metadata.json`及`selection.csv`为准。优化停止、材料标定一致性和实验物理验证分别评价；材料位置精度、内部侧边自由近似及跨批标定转移仍保留原限制。

准备与实现检查见细网格280N组的`verification/implementation_checks.json`：两组新旧准备数组逐值一致；识别列表和均匀初值均仅含280N；三步长方向差分最大相对误差为粗网格4.37e-7、细网格1.78e-6。新计算仍拒绝历史内核不一致，历史场重绘仍拒绝观测内核不一致。该检查不改变原物理配准状态。
