# 固定局部两区／三区的380N精确TV反演

两组50点扫描、所选γ下四个ν求解及四步输出已完成。精确TV使平台更明显，但ν=0.26下分区均值的平均绝对标定差异由H1的6.682398%／5.151708%变为7.050296%／5.443845%，没有改善总体标定符合度。三区最差区域偏差有所降低，但50%／40%合成近似同一平台，不能称恢复三层。所有八个最终场均通过独立复算的一阶条件；弱γ的数值异常另列，不改为收敛。

本项将前次固定的60%—50%两区与60%—50%—40%三区改用不平滑的精确TV，分别重新进行50点L-curve选参。两组区域不按TV结果重新选择，独立标定不进入目标、初值或γ选择。既有局部H1场及其选γ记录保留。

结果入口为[局部精确TV与H1对照](../results/dic_full/subset380_tv_comparison_20261025/index.html)。前次区域筛选、物理定位、数据配对和H1结果见[局部H1报告](dic_subset380_results_20261025.md)。

## 方法与控制条件

精确TV目标为`0.5*r.T@W_area@r + gamma*integral(sqrt(E_x**2+E_y**2))`。自由二维节点Q4模量、原Q4位移试函数／测试函数、2×2 Gauss积分及原正演／伴随内核保持一致，不绑定不同y行，不引入分层或界面先验；没有Huber阈值、平滑ε、E_REF或人为噪声归一化。

两区仍为37×19单元、760个独立E参数、7215个DIC点，域31.7696438691×18.48415643525 mm；三区仍为49×19单元、1000个独立E参数、9555个DIC点，域42.1669818609×18.48415643525 mm。实际制造坐标与40%端部缺失均沿用前次记录。三平台全部冻结数组与各自H1准备数组逐项相同，记录为各组`input_identity.json`。仅380N本组局部DIC用于识别，180N／280N仍是已检查过数据的跨载荷对照。

380N净力仍假定319.9 N，非同步实测；真实承载宽20 mm、厚3.2 mm，牵引F/(20t)及ROI端力F×GEO_H/20不变。物理配准未独立闭合，截取端均布牵引与内部横向自由仍为近似。前次已依据材料符合度事后选区，本项符合度不能重新作为独立验证。

配置为`dic_subset2_380n_tv_config.py`与`dic_subset3_380n_tv_config.py`，分别保存到`results/dic_full/load380_subset2_60_50_exact_tv_20261025/`与`load380_subset3_60_50_40_exact_tv_20261025/`。不覆盖前次H1或已有全域TV计算。

## 求解与选参协议

采用既有非线性原始—对偶法。50个γ预设为1e−10—1e−2，仅由局部380N、ν=0.26的L-curve选择；纵坐标是TV本身，不是其平方根。H1与TV的γ单位不同，不按数值相等比较。均匀初值只由本组局部DIC拟合，扫描按递减γ从已通过点延续。

每个γ及最终ν最多12000次FE评估／12000步，保持原严格判据：log坐标驻点残差≤`1e-9+1e-3*max(data_gradient_inf,dual_gradient_inf)`，Fenchel间隙绝对值≤`1e-9+1e-4*gamma*TV`，对偶幅值超界≤`1e-12*gamma`。原始—对偶法直接取分裂梯度为GE，约束残差恒为零，不作为额外独立收敛证据。H1的函数下降／GTOL不能替代TV的一阶条件。零TV常量场通过时仍不进入对数曲率；失败点保留并排除。无有效拐点则停止，不用标定或手指定γ补选。

先导仅检验数值步长：两组各在γ=1e−7，从自身DIC均匀初值分别用τ=2e7、1e8、2e8，各600FE，共1800FE／组，未读取材料误差或跨载荷指标。τ=2e8时600FE后的驻点比两区11.70、三区2.76，均优于另外两档，且保持正模量；但两组600FE均未同时通过全部条件。正式扫描固定τ=2e8、谱耦合0.9，谱起始随机种子173。它只是数值步长，不缩放目标，不改变证据阈值。先导场未作为正式扫描初值；轨迹与额外成本保存在`pilot/`，协议另存`protocol.json`。

若选参成功，各ν=0.24/0.26/0.28/0.33从同一本组所选场及对偶场出发，固定γ；不根据标定或另一平台选择ν。完整失败记录和实际计算量按保存文件报告，不宣称相同计算成本。

## 已执行核验

- 两组全部准备数组与相应H1逐值相同，三平台力、坐标、标定、覆盖和独立标定正演指标相同。
- 实际局部网格的梯度算子／面积加权转置检验绝对误差分别1.78e−15、4.44e−16。
- 100个候选的通过／预算／数值异常处置均已审查。86个有保存场的扫描点及8个最终场重新正演／伴随，驻点、间隙、对偶条件与保存标记相符；其中扫描的3个预算失败保持失败。14个无返回场的点只核验异常记录、来源和排除状态，不能称为完成了它们的数值证据复算。
- 8个最终ν场的24组平台预测与误差重新计算一致；最终一阶驻点及间隙比均≤1。原始—对偶分裂残差恒零按其定义保留。
- 共同物理积分2点／3点Gauss统计差异低于1e−8个百分点。独立三刚体投影实现重现两方法及标定正演的同点RMSE。
- 已检查宽度曲线、二维模量、位移与残差的实际渲染，并核对导航链接和PNG／SVG输出。

逐点证据位于各运行`verification/scan_audit.csv`与`verification/summary.json`；其中`scan_reproduced=false`明确表示存在无返回场，并非所有50点都有场可复算，`scan_outcomes_audited=true`表示各候选处置均已审查。正式比较与共同积分检查位于汇总页的CSV／JSON。

## 比较口径与复现
