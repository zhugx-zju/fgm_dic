# 局部H1直接沿用380N全域γ的受控诊断

直接沿用全域γ没有恢复原全域识别场的材料符合度。ν=0.26下，两区平均绝对标定差异由局部γ的6.68%变为6.94%，三区由5.15%变为6.57%；同域原全域场分别为1.66%、2.18%。结果不支持“仅因重新选γ不同而变差”的解释；仍不能据此排除其他参数、边界或数据组合的影响。

结果入口为[全域γ迁移诊断](../results/dic_full/subset380_gamma_transfer_20261025/index.html)。原局部[H1](dic_subset380_results_20261025.md)和[精确TV](dic_subset380_tv_results_20261025.md)均保留，本项不替换原L-curve结果。

## 系数来源与比较设计

380N、原H1、121×19全域网格的保存结果`results/dic_full/load380_20261022/h1/03_inverse/run_metadata.json`确实选得γ=3.7275937203149377e−8。两区原γ=2.6826957952797275e−9，三区原γ=8.28642772854686e−9；直接迁移分别增强系数约13.895倍、4.498倍。

380N全域精确TV当时没有有效选定γ：粗网格缺曲率峰邻点支撑，细网格缺有效非零TV点。此次只迁移同平台、同H1定义的有效系数，不把H1系数放入TV目标，也不跨用180N的TV系数。

两区、三区分别读取各自原`01_prepared`冻结输入，复用原FE／伴随内核；自由二维节点E、网格、原始DIC、面积与分量权重、制造位置、力、刚体模式和边界近似均保持本组原定义。每组仅在ν=0.26做两个试验：

1. 原局部γ，从仅本组局部380N DIC拟合的均匀E初值开始。
2. 原全域γ，从完全相同的均匀E初值开始。

每个试验仍1500迭代／12000函数评估上限，FTOL=1e−30、GTOL=1e−12。四个实际求解分别用了148／331／219／277次FE函数评估，共975次；另计初始化、正演、核验与代价诊断。没有重扫γ、扩展ν范围或用全域E作初值。局部γ从共同初值的控制用于区分系数变化与原扫描延续初值的影响。

诊断保存在两组原`03_inverse/global_gamma_diagnostic_20261025/`，子目录`local_gamma_same_initial`及`global_gamma_same_initial`分别保存完整场、预测、轨迹、配置和来源哈希。它是指定系数的诊断，不是一次新的L-curve选参，不覆盖原四步输出。

## 为什么相同γ仍得不到原全域场

“全域反演后截取一部分场”和“先截取数据、重新建立局部反问题”不等价。固定γ只控制一个标量，并未恢复被移除的观测、外侧材料耦合及截面条件。

**数据敏感度随观测跨度改变。** 一个可独立核查的极简情况是均匀杆、固定应力σ、模量E，仅消去刚体平移：轴向位移为`u=σ(x−L/2)/E`。对均匀log(E)扰动，导数为`−u`，因此数据项沿该方向的Gauss–Newton曲率为`H*σ²*L³/(12*E²)`。固定宽度、面应力、同一E和ν时，二维横向收缩还贡献与L成正比的一项；不能把总体信息变化简化为测点数比例。

在实际冻结测点及面积权重上，取相同的均匀E=1500 MPa、ν=0.26、380N假定净力，仅作该均匀方向的解析检查，得到全域曲率20.900264 mm⁴，两区0.585573 mm⁴、三区1.346884 mm⁴，即全域的2.802%与6.444%。两组局部FE正演及同一刚体投影复现了解析值。这是均匀方向、均匀牵引极限模型下的敏感度检查，不是完整二维逆问题的信息谱、真实材料不确定度或实测置信区间。

**正则作用的区域和端部也改变。** H1项是`(γ/2)∫Ω|∇E|²`，其一阶变分含体项`−γΔE`及边界项`γ∂nE`。新截取边界若不指定E或梯度，原全域场在内部截面处的梯度耦合不再保留；常规自然边界会促使局部端部更平。数值系数相同，正则泛函及边界支撑也不是原全域问题。

**力学截面条件也不等价。** 当前局部截面重新施加均布轴向牵引、零剪切，内部横向仍为自由边界近似；全域解内部截面的牵引分布并不保证满足这一局部假设。原全域的几何／材料耦合和截面信息没有随一个γ传入局部模型。本项没有建立边界等效，也没有将材料偏差唯一归因于边界。

**同γ下，局部目标确实偏好另一种场。** 在求解完成后，把原全域E按原物理坐标采样到相同局部Q4节点，仅作代价评价，不用于初始化。全域γ下，两区该采样场的局部目标约0.006724，而新局部识别场为0.003490；三区约0.008370→0.005206。采样场的log坐标梯度∞范数约1.3e−3，而新场约5.0e−10／7.0e−10。标定更接近的全域场并不是当前局部目标的驻点。这支持“局部反问题本身已改变”的判断；Q4采样及现有边界／材料模型限制保留，不能据此证明哪个物理模型正确。

本次结果不支持“把原全域系数直接带回即可解决”的具体假设，不能证明所有其他γ均无用。继续用标定差异逐点挑γ会把事后评价变成调参；若进一步定位原因，应固定规则开展受控边界等效与观测截取比较。

## 核验、限制与复现

四个试验均按函数下降条件停止，未达到严格GTOL；未将其改称严格一阶收敛。全部目标值、残差范数、正则范数和梯度均用新正演／伴随重新计算一致；共同积分2点／3点Gauss统计差异低于1e−8个百分点。均匀解析敏感度与局部FE结果一致，渲染后的宽度曲线与二维模量图已检查，PNG／SVG同时保存。

380N仍使用319.9 N假定净力，非同步实测；材料定位、内部横向自由及截取边界等效未独立验证。区域由既有标定符合度事后选定，当前符合度不能作为独立验证。`independent`标定的原组内SD、样本数、批次及跨批转移限制不变。

从根目录分别运行两个局部诊断，再只读取保存场生成对照：

```powershell
python -u -X utf8 -B -m lib.dic_subset_gamma_transfer --case subset2
python -u -X utf8 -B -m lib.dic_subset_gamma_transfer --case subset3
python -u -X utf8 -B -m lib.dic_subset_gamma_transfer --report-only
```

已有诊断拒绝覆盖；重算应使用新的诊断编号。`--report-only`不重新优化，只重建派生表格、图件和事后代价评价。各局部`verification.json`保存独立目标／梯度核验；汇总`verification.json`保存场哈希、共同积分、解析／FE敏感度和系数比。完整分区、位移、停止状态和代价表均随汇总页保存。
