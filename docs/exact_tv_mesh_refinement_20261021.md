# 固定观测下的Q4反演网格加密对照

本合成阶梯算例中，网格加密确实改善了精确TV：固定独立选参规则和同一观测，两个新噪声样本的误差由12×4的6.26%—6.30%降至48×16的3.65%—4.08%，过渡明显变窄。梯度平方正则加密收益较小，平滑场仍以梯度平方正则更好。本轮未运行真实DIC。

## 问题与范围

本对照检验连续Q4模量采用未平滑TV正则时，增加反演单元数是否改善阶梯界面恢复。比较12×4、24×8、48×16三档网格，节点模量数分别为65、225、833；所有y行参数仍独立。与梯度平方正则并列比较，保持观测、噪声、载荷、初值规则、目标及选参方法一致。

网格细化同时改变位移离散和模量离散，不能把全部净收益单独归因于模量空间。没有修改测试函数、采用SUPG或bubble-PG，没有把真界面或分区模量加入反演。

本轮属于30×8 mm合成算例，不使用实验DIC或独立标定模量，不替代当前全域实验的物理验证。基础实现及上一轮证据见[未平滑TV验证](exact_tv_validation_20261021.md)。

## 冻结条件

真值正演固定为48×16网格，833个节点观测位置固定。平滑场、斜界面阶梯场及0.2 μm独立高斯位移噪声沿用上一轮定义；种子20261022用于识别选参，20261023、20261024用于固定γ后的重复检验。不同网格读取相同冻结观测数组，不随反演网格增加测点或重新生成噪声。

两种方法均保持\(E_h=\sum_iN_iE_i\)、\(E_i=\exp(m_i)>0\)，位移插值与测试函数均为标准Q4形函数\(N_i\)。目标分别为

\[
J_{H1}=\tfrac12r^TW_A r+\tfrac\gamma2\int(E_x^2+E_y^2)dA,
\qquad
J_{TV}=\tfrac12r^TW_A r+\gamma\int\sqrt{E_x^2+E_y^2}dA.
\]

没有Huber阈值、TV平滑ε、E_REF、噪声归一化或层状约束。厚3.2 mm、真实承载宽20 mm、ν=0.26、实测平台型力119.77617870327234 N；传入8 mm宽截取域内核的端力为F×8/20。原面积权重、等分量权重和刚体配准保持一致。

每个数据样本先在12×4网格由位移拟合一个均匀初始E，然后将同一标量用于三档网格全部节点。12×4冻结观测、权重及初值与旧记录逐项相同；旧选中场重新评价的目标差不超过1.70e-21，模量相对误差差为0。

## 选参与求解精度

每种真值、每种正则、每档网格分别扫描50个γ，共12组。H1范围1e-14—1e-7，TV范围1e-12—1e-6。使用既有L-curve内点曲率规则，只有通过停止检查的点可参加选参；TV数值常数场排除于对数曲率计算。真值误差不用于选γ或初值。

初始48×16试算在300次外迭代后未通过约束残差，正式扫描前将三档网格TV外迭代上限统一提高为1200；目标评估预算仍统一为12000次，原一阶检查阈值不变，不以目标下降替代收敛。原试算状态和预算修改依据保存在协议中。

旧12×4中已经按一阶条件停止的点可复用：仅提高停止前不会触及的外迭代上限，不改变这些轨迹。旧预算失败点按新上限重算。每组独立选γ后，再固定该γ对两个新噪声样本计算。

在24×8和48×16上检查了位移失配离散伴随的方向有限差分，相对误差最低分别约4.00e-9、1.12e-8。另将固定γ的TV驻点、约束及间隙容差统一收紧10倍，检验主要网格趋势是否受停止精度影响；该诊断不替换原场或改变选参。

三档收紧容差的计算均通过一阶检查，相对原场的面积加权RMS变化分别约0.071、0.109、0.180 MPa；固定γ阶梯误差仍约6.340%、4.973%、4.253%。主网格趋势保持。该检查消耗3916、6923、10458次目标评估。

## 共同评价与辅助诊断

主要误差仍为833个固定观测位置的面积加权模量相对RMS，与上一轮口径一致。另在共同96×32网格的高斯点计算模量误差，检查改进是否只发生在观测节点。

固定粗网格γ的12个场又在192×64网格高斯点评价；相对96×32积分，模量相对误差最大差约0.0271个百分点，未改变阶梯场随网格改善的方向。统计网格不参与反演或选参。

阶梯中线y=4 mm的20%—80%过渡宽度，定义为模量从2200下降至1600 MPa的距离。只有两个水平各有唯一交点时才报告宽度，否则保留额外交点信息并记为不可分辨，不挑选有利交点。

为了分离加密与重新选γ的作用，补充从全部扫描中提取12×4所选γ对应的各档合格场。该规则只读取粗网格L-curve结果，不按真值选择候选；补充诊断在24×8结果后、48×16最终选参前声明。它不新增优化、不替代主要的各档独立选参结果。

另将已知真值直接作连续Q4空间的最佳L²投影。阶梯场在公共细积分点上的最佳逼近误差为5.215%、3.637%、2.567%；平滑场为0.2269%、0.05435%、0.01305%。这些投影只评价空间表达能力，不是位移反演结果，不进入初值或选参，也不包含噪声、力学敏感性和正则的限制。各投影节点模量均为正。

在固定γ的TV阶梯场上，公共细积分总误差约为6.402%、5.070%、4.400%。利用最佳L²投影的正交性，可将误差平方分成空间表达误差平方与到最佳投影的差异平方；后一分量约为3.713%、3.532%、3.574%。直接计算的平方恒等式误差小于6e-17。三档中剩余差异近似稳定，与表达误差下降一起解释了收益递减；它混合正则、观测与求解等因素，不是噪声下限估计，也不保证继续细化时保持不变。

结果支持精确TV在本斜界面阶梯算例中受益于网格加密，不支持无限加密或对未知分布一概优于H1。当前正式实验网格的物理单元尺寸也不能用这里的单元数量直接替换。

## 机制与适用边界

对单位界面长度、模量反差ΔE、过渡宽度w的单调线性斜坡，梯度平方项的代价为\(\gamma\Delta E^2/(2w)\)，TV代价为\(\gamma|\Delta E|\)。前者在缩窄过渡时增大，后者不随w变化。因此加密可以释放TV原先受限的界面表达，但不会强制其找到真实锐界面。数据敏感性、噪声、γ及局部求解仍共同决定恢复宽度。

固定γ时，平滑场的TV误差随网格加密由4.614%变为4.761%、5.009%。这个反例说明增加单元数并不普遍改善模量恢复，也不能自动消除TV对平台的偏好。反演参数增多而测点固定时，增加的自由度不代表增加了实验信息。

最高反演网格与固定真值正演网格相同，但真值在高斯点解析突变，反演模量仍为连续Q4，两者并不相同。固定正演网格保证本轮输入一致，尚未独立证明真值正演网格收敛；观察到的加密收益不能全部当作连续物理问题的渐近收敛率。

本轮未验证实测DIC噪声相关性、实际106 mm域、ν不确定性或内部侧边界等效。耗时在并行计算负载下记录，不能据此作严格跨组效率排名；目标评估次数另存。

## 实现与复现

`lib/exact_tv_mesh_study.py`提供冻结数据、单组扫描及重复检验；`lib/exact_tv_mesh_report.py`只做保存场的插值、统计、表达误差投影和出图，不重新反演。`lib/exact_tv_study.py`的评价函数改为读取真实观测坐标，消除原先将观测网格固定推定为反演网格四倍的假设；原12×4结果的评价数值保持一致。正式四步入口、默认实验配置与力学/伴随内核没有改动。

本机结果位于`results/dic_full/exact_tv_mesh_20261021/`，由`index.html`进入。保留冻结NPZ、每点场、停止证据与历史、γ曲线、逐样本CSV、辅助诊断及PNG/SVG。

从仓库根目录，使用未存在的输出根目录，设置三个BLAS/OMP线程环境变量为1后，分别执行：

```powershell
python -m lib.exact_tv_mesh_study prepare --root results/dic_full/exact_tv_mesh_replication
python -m lib.exact_tv_mesh_study scan --root results/dic_full/exact_tv_mesh_replication --nx 24 --kind step --method exact_tv
python -m lib.exact_tv_mesh_study validate --root results/dic_full/exact_tv_mesh_replication --nx 24 --kind step --method exact_tv
python -m lib.exact_tv_mesh_report --root results/dic_full/exact_tv_mesh_replication
```

扫描和重复检验需分别覆盖三档`--nx`、两种`--kind`及两种`--method`，共12组，出图阶段检查全部扫描状态。准备阶段依赖已有上一轮本机结果以核验共同数据身份；完成准备后，各组计算使用新目录中的冻结数据。
