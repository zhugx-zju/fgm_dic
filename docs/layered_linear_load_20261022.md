# 大分层试样的线性工作载荷估算（2026-10-22）

建议下一轮实验暂将**净拉力控制在270 N以内**；若第3次试验的60.1 N初始偏置仍适用，对应试验机示值约330 N。250 N净拉力可作为更低一级的工作平台。这个建议来自独立均匀试样局部线性段的转移估算及人为预留裕度，**不是已验证的大试样线弹性极限，也不是屈服或安全承载能力**。

既有线性段上端给出的最小等效载荷为342.69 N净拉力，控制区为40%填充区。约400 N机器示值已接近这个参考上端，不宜直接作为具有充分线性裕度的工作平台。当前380 N示值若按既有假设扣除60.1 N，为319.9 N净拉力；尚低于参考上端，但仅剩约6.7%的名义载荷裕度。380 N的同步实测平台力仍缺失。

## 模型与数据口径

采用完整制造平行段：长150 mm，宽20 mm，厚3.2 mm；40%和100%端区各35 mm，其余五区各16 mm。该几何与当前约106 mm的DIC观测域不同。这里计算整件试样的轴向净拉力，不使用ROI宽度或ROI端力。

主标定沿用`mixed_infill_20261017`的`independent`口径：1013批40/50/60/90/100%，1016批70/80%，共34根。此处的`independent`仍是同填充率优先共窗的原方法，不是`individual_optimal`逐根重新选段。未重新选择模量或用分层试样位移调整标定。

对于等外截面积的轴向串联分区，远离界面和肩部时，各区轴向合力均为F，名义应力均为

\[
A=20\times3.2=64\ \mathrm{mm^2},\qquad
\sigma_i\simeq F/A,\qquad
\varepsilon_i\simeq F/(AE_i).
\]

将各区既有局部线性段上端记为σᵢ,upper，有

\[
F_{\mathrm{window}}=A\min_i\sigma_{i,\mathrm{upper}}
=64\times5.35454199=342.690687\ \mathrm N.
\]

如果另给定的是线性应变范围，则先按σᵢ,upper=Eᵢεᵢ,upper换算再取最小值。不能只由模量排序推断线性极限；本次40%区控制是因为其实际线性段应力上端最低。这里的应力和模量均按外轮廓截面定义，不能再将64 mm²乘以填充率，否则重复扣除孔隙效应。增大串联长度会增大伸长，不会在此一维近似下按长度比例降低进入非线性的载荷。

## 原曲线核验与适用边界

本次重新读取34根试样原始工作簿，沿用每根初始10点力中位数扣除偏置和原加载数据块选择，复现全部既有E。分别用SciPy回归和`E=(dF/d引伸计伸长)×标距/截面积`独立核对，最大相对差8.9×10⁻¹⁶。`fit_results.csv`内的力范围是含各自初始偏置的原始示值，不能直接按面积比转移到大试样。

对于5根40%试样，固定原下端2.141817 MPa，仅改变上端作诊断。净力270/319.9/342.69 N对应窗口均为5/5通过既有局部线性条件：R²≥0.995、前后半段斜率差≤5%、应变非递减步比例≥90%、点数≥60。270 N时半段斜率差最大3.14%，319.9 N时最大3.93%，342.69 N时最大4.42%。

继续以0.1 MPa间隔扩展，40-1/2/3/4/5首次失败的上端分别对应364.8/371.2/454.4/416.0/377.6 N，均由半段斜率差超出5%触发；这些点的R²仍约0.99975—0.99979。384/448/512 N上端分别仅2/1/0根通过。**因此只看高R²会漏掉逐渐弯曲；首次失败位置依赖窗口下端、网格和准则，不能称为测得的屈服载荷。**

尤其需要保留以下限制：

- 七个原标定应力窗口没有共同交集：最大下端8.855 MPa大于最小上端5.355 MPa。因此343 N只利用上端作必要范围筛查，不能证明所有区域在0—343 N都服从表中同一个常数E。
- 在统一2.141817—4.21875 MPa区间，即上端270 N净拉力，逐组通过局部条件的数量为40%:5/5、50%:4/5、60%:5/5、70%:2/5、80%:2/5、90%:2/4、100%:4/5。这不是全区通过。失败可能含引伸计回退、信号质量和应力依赖，不能全归因为材料非线性。降低载荷本身并不能解决这一证据缺口。
- 同一统一窗口下，50%局部表观E比原高应力段E高约9.6%—11.0%，90%高约12.6%—13.1%。这些仅是诊断斜率，不替换原标定；它们说明工作应力与标定应力不匹配可能影响分层试样的正演比较。
- 1013—1016的60%桥接在共同窗口下仍有约12.85%模量差，不能认为两批完全可互换。新批统一尺寸也不含逐根尺寸变异。
- 串联模型忽略层间过渡、局部打印缺陷、各向异性、肩部应力集中和装夹偏心。完整大试样的实际比例响应、卸载恢复性及保载蠕变尚未由本计算验证。单调加载的局部直线不能证明可恢复弹性。

下一步应在同步净力配对下，先以250 N和270 N附近的分级加载检查各区DIC应变与净力的比例关系，比较相同保载延迟，随后卸载并检查残余应变和重复性。判据应先确定再评价。若270 N以内已有系统斜率变化或保载漂移，应下调工作载荷；如果这些检查尚未完成，应将270 N标注为暂定试验上限，而非已证实的线性上限。
