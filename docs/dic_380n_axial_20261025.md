# 380N：轴向模量E(x)约束与原自由二维H1对照

只检验沿宽度均匀的材料假设能否改善已有380N反演，不替换自由二维主模型。结果为：独立选γ后标定／趋势平均差异略降，最差区域仍约17.4%，双分量位移拟合变差；固定原二维γ时两种模型的宽度均值几乎相同，未显示轴向约束本身能消除主要模量偏差。

## 定义与受控条件

新增配置`dic_380n_axial_config.py`，独立结果`results/dic_full/h1_380N_axial_20261025/`。仅计算380N、ν=0.26，采用原121×19位移有限元和全部23920个DIC测点。将E(x,y)约束为E(x)，每个轴向节点一个未知模量，各y行严格共用，共122个未知量，原模型为2440个。E沿x仍为连续分段线性，不强制为直线、单调曲线或七个常值层。

映射E=P exp(a)，原节点对数梯度对y行求和，即dJ/da=Pᵀ dJ/dlogE，不能取平均。复用原二维正演、观测、刚体配准、面积权重和伴随内核。正则保持`gamma/2 * integral_Omega |grad E|^2 = gamma/2 * H * integral (dE/dx)^2 dx`，不删除宽度H，不引入参考模量或噪声归一化。已知分层界面和独立标定不进入反演、初值或选γ。

原50点1e-12—1e-4范围和每点1500迭代／12000次函数预算保持。只用380N作均匀初始化、L-curve选参，最终γ=5.42867543932386e-8。另在原二维γ=3.7275937203149377e-8作一个预先声明的单点诊断，初始场为轴向L-curve所选场；不是用标定补选γ。

## 同条件结果

区域统计将Q4单元按同一实际制造界面精确裁切；所有模型采用相同物理积分。原四步区域CSV采用原生高斯点归属，局部百分比与本表有小量差异，例如原二维80%区域17.3651%在精确切分下为17.4466%。该统计口径变化不是新算法收益，原CSV未改写。趋势比较仍仅在x=[7.74727501947,103.74727501947] mm内，不外推。

固定γ对照表明，仅绑定y行后，区域均值和趋势误差几乎不变；独立选γ的轻微变化主要伴随更强平滑。当前证据不支持“横向自由参数导致了中部模量偏高”作为主要解释，也未达到相对辅助趋势全域10%以内。不能由这项对照确定剩余偏差来自材料、DIC、载荷还是边界模型。

## 数值核验与停止状态

- 新准备的380N坐标、位移、测点权重及网格ID与原冻结数组逐位相同。原已保存二维场以当前内核重新正演，预测最大差异为0 mm，两个分量RMSE完全复现。历史准备的mesh/fem/inverse源码摘要与当前既有代码不同，因此重新准备本组，不绕过历史输入的内核保护。
- 8×3小网格、真实380N观测下，三个γ的方向差分核验通过，最优步长相对差异均小于1e-9。二维H1积分与含H的一维解析积分差异约1.7e-15；均匀拉伸解析位移最大残差约1.5e-15 mm。小型无噪声端到端恢复相对RMS约6.98e-8。
- 原扫描47/50点按求解器条件停止。三个线搜索异常点仅在原剩余迭代／函数预算内重启，其中两点恢复，最终49/50。γ=1.389495494373136e-11仍ABNORMAL，已排除，原试算和恢复场均保留，没有新增γ或追加每点总预算。
- 原扫描15005次FE评价，含恢复累计15215次；最终主ν另22次，共同γ单点另237次。数值核验、均匀初值及独立正演另计，不把上述计数当作端到端总工时或效率证明。
- 全部50点的范数、缩减梯度、y行一致性、预算及L-curve选择独立复核；最终场与共同γ诊断也重新计算目标和梯度。所有扫描点和最终轴向场均未达到原GTOL=1e-12，最终按函数下降停止。约束模型梯度是122维轴向对数坐标梯度，不能与原2440维梯度直接按大小排名。
- 区域结果由宽度均值逐段积分和独立裁切Q4单元面积积分交叉核对；趋势积分8阶／16阶核对；PNG／SVG同图状态保存并检查了渲染结果。

## 复现与入口

分别执行原四步，不使用总batch：

```powershell
$env:OMP_NUM_THREADS='1'
$env:OPENBLAS_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
python -B -m script.step1_prepare_dic --config dic_380n_axial_config
python -B -m script.step2_forward_calibrated --config dic_380n_axial_config
python -B -m script.step3_inverse_dic --config dic_380n_axial_config
# 仅当原扫描线搜索失败且仍有预算时：
python -B -m script.step3_inverse_dic --config dic_380n_axial_config --resume
python -B -m script.step4_compare_results --config dic_380n_axial_config
# 独立的一次共同γ诊断，之后的命令仅作保存场比较：
python -B -m lib.dic_380n_axial_comparison --fixed-gamma
python -B -m lib.dic_380n_axial_comparison
```

新计算须更换RUN_NAME及相应比较目录；上述入口会拒绝覆盖已有数值目录。原四步已有云图可用`--plot-only`重绘。比较模块默认只读已有数值，重绘自己的汇总图和表格，不更新旧模型保存场。

浏览[一维／二维比较页](../results/dic_full/h1_380N_axial_20261025/comparison/index.html)、[本组四步](../results/dic_full/h1_380N_axial_20261025/结果总览.html)。汇总及核验快照见[dic_380n_axial_20261025.json](dic_380n_axial_20261025.json)，完整局部场与核验记录留在独立结果目录。
