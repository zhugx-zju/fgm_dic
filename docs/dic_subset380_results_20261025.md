# 380N连续两区／三区局部DIC反演

两组局部反演及四步输出均已完成。缩小选域后，380N位移拟合略有改善，但与独立标定的分区平均模量差异总体增大。本结果不支持“选择原来误差小的区域，局部重新识别后会更准确”。

结果入口为[局部反演对照页](../results/dic_full/subset380_comparison_20261025/index.html)，根目录“打开结果.html”也链接该页。页面链接两组四步结果、三个位移场、分量残差、二维模量、宽度曲线、四个ν和全部数值记录。

## 选区与固定条件

选区来源为原380N、H1、ν=0.26的`results/dic_full/load380_20261022/h1/03_inverse/nu_0.26/regional_modulus_comparison.csv`。指标是分区平均模量相对`independent`标定均值的绝对百分差。原表排序为60%（0.302635%）、40%（3.163902%）、50%（3.328473%）、100%（4.065066%）、90%（12.123797%）、70%（13.890446%）、80%（17.365079%）。

对所有连续两区／三区按区域等权平均绝对差异排序，分别选出60%—50%与60%—50%—40%。不将分离的区域拼接成连续域。排名、全部相邻候选、源文件哈希分别保存于对照页的`selection_ranking.csv`和各运行的`preflight_verification.json`。

这是按既有材料符合度事后选区的探索性对照。标定未进入新的反演目标、均匀初值或γ选择，但已参与区域选择，因此新区域的标定符合度不能再当作独立验证。

从原始平台数据按制造坐标截取完整DIC行，不插值、不缩放坐标或位移；共同几何取180N参考坐标，继承原始标线定位。三区中的40%端仍缺5.752190 mm，不能称三层各取得完整16 mm。两区边界余量来自保留实测点行，未补点到名义界面。

识别仅使用380N自身的618—632帧平均位移，180N／280N只作已检查过数据的跨载荷对照。380N仍沿用假定净力319.9 N，并非同步实测；截面宽20 mm、厚3.2 mm，牵引F/(20t)，ROI端力F×GEO_H/20。三个刚体规范与刚体残差配准不变。新截取端采用均布牵引，内部横向自由仍为显式近似，未建立严格子域边界等效。

两组均使用原面积加权H1目标、等分量权重、无E_REF或噪声归一化；50个γ为1e−12—1e−4，在ν=0.26只按本组局部DIC选参，随后固定本组γ计算ν=0.24/0.26/0.28/0.33。每点仍1500迭代／12000函数评估上限，FTOL=1e−30、GTOL=1e−12。没有追加扫描或用标定补选γ。新计算采用当前共用内核，原七区基线读取历史保存场，不重新认证历史内核或重新求解七区场。

## 同条件模量对照

下表均在ν=0.26，按两种Q4网格节点与材料界面的共同分段进行物理面积积分，正值表示高于标定。原七区识别场也只统计该局部域的同一物理区域。

| 局部算例 | 材料区 | 原七区场限制到同域的差异 | 局部重新反演差异 |
| --- | --- | ---: | ---: |
| 两区 | 60% | +0.074874% | −4.949469% |
| 两区 | 50% | −3.246565% | −8.415327% |
| 三区 | 60% | +0.074874% | −7.374968% |
| 三区 | 50% | −3.292524% | −5.080439% |
| 三区 | 40% | +3.179428% | +2.999717% |

分区平均模量的平均绝对差异：两区由1.660719%增至6.682398%；三区由2.182276%增至5.151708%。三区40%仅略有降低，60%与50%均恶化。原七区来源表的0.302635%等数字使用原生Gauss分区，且统计范围与当前裁剪可能不同，不能和共同积分值混用。两组50%区域末端覆盖不同，原七区场的该区统计也相应不同。

局部反演的宽度均值仍为平滑变化，没有恢复两／三段清晰常值平台。灰带为独立标定试样间SD，不是反演置信区间；二维空间离散另存于区域统计与原四步结果。局部偏差落在某些SD范围内，不能直接认定材料等效。

## 同点位移对照

原七区预测先限制到每组完全相同的DIC点，再按该组面积权重独立拟合相同的三个刚体模式。所有下列RMSE均为380N、ν=0.26，单位μm，未比较全域与局部域的不同统计支持。

| 算例 | 材料场／正演域 | ux RMSE | uy RMSE |
| --- | --- | ---: | ---: |
| 两区 | 原七区识别场全域响应，限制到局部点 | 1.634744 | 2.800249 |
| 两区 | 局部识别场局部响应 | 1.254838 | 2.536873 |
| 两区 | 独立标定局部正演 | 2.287436 | 2.959755 |

位移残差降低与模量标定偏差增大同时发生。该结果表明拟合改善不能单独代表材料识别改善。缩短观测跨度、重新选γ、截取端的边界近似及材料／观测模型不一致都可能影响局部识别；本次同时改变域与相应选参，尚不能将偏差归因于其中某一个因素。

## 停止证据与核验

两组均取得有效L-curve拐点，未将失败点纳入选参。两区46/50、三区43/50满足原求解器停止条件，均由函数下降停止。两区另有1点异常线搜索、3点达迭代上限；三区另有1点异常线搜索、6点达迭代上限，全部保留原失败记录，未追加恢复。每组四个最终ν均按函数下降停止，未达GTOL；`computed`只表示原四步计算完成，不表示严格一阶驻点或实验物理验证通过。

已执行以下核验，记录保存在各运行的`preflight_verification.json`、`verification/scan_audit.csv`、`verification/summary.json`及汇总的`verification.json`：

- 三平台原始参考坐标、位移和grid ID与原保存数据的对应裁剪逐值相同；仅平移局部FEM坐标原点。重新测得的点面积相对差异低于3.5e−11，属间距浮点计算差异，未人为缩放权重。
- 两组实际网格的均匀拉伸解析解最大位移误差分别4.40e−15与1.95e−14 mm。
- 固定种子20261025，6×4小网格log坐标伴随方向导数与三档中心差分一致；最佳相对差异分别5.32e−7、2.06e−8。
- 100个扫描场的残差范数、正则范数、保存梯度与选γ结果均通过新FE／伴随重算；8个最终ν场的范数、梯度和24组跨平台位移预测及误差均复现。未把未达到GTOL的场改记为GTOL通过。
- 独立实现的同点刚体投影重现原局部位移指标；共同分段2点与3点Gauss积分的分区平均模量差异低于1e−8个百分点。
- 已检查渲染后的共同坐标模量图、二维场和位移分量对照；图件同时保存PNG／SVG。局部图保留分层标定及SD，不用选出的两／三组重新拟合原七组辅助趋势。

## 复现

从项目根目录对两份配置分别按顺序执行原四步，各命令独立运行：

```powershell
python -X utf8 -B -m script.step1_prepare_dic --config dic_subset2_380n_config
python -u -X utf8 -B -m script.step2_forward_calibrated --config dic_subset2_380n_config
python -u -X utf8 -B -m script.step3_inverse_dic --config dic_subset2_380n_config
python -u -X utf8 -B -m script.step4_compare_results --config dic_subset2_380n_config
```

三区使用`dic_subset3_380n_config`替换配置名。已有结果不会覆盖；若重新求解，应更换运行名。后续步骤也可显式读取原`01_prepared`冻结配置，内核及上游身份仍须一致。第2—4步日志、各γ场、初值来源、冻结配置和软件环境随各组保存。

```powershell
python -u -X utf8 -B -m lib.dic_380n_verify subset2 --root results/dic_full/load380_subset2_60_50_20261025
python -u -X utf8 -B -m lib.dic_380n_verify subset3 --root results/dic_full/load380_subset3_60_50_40_20261025
python -u -X utf8 -B -m lib.dic_subset_comparison
```

本次检验未建立新区域的独立材料真实性、未知界面识别或二维可辨识性证据。后续若研究局部域偏差来源，应先固定选区与选参规则，以少量受控边界对照区分截取边界和观测信息损失，不能继续依据标定误差反复挑选有利结果。
