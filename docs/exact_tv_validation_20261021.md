# 未平滑TV的自由二维模量反演验证

本次小规模合成对照中，未平滑TV对未知斜界面的阶梯场有稳定改善：固定L-curve选出的权重、更换两个噪声样本后，模量面积加权相对RMS由梯度平方正则的8.15%—8.24%降至6.26%—6.30%，降低约23%。平滑场误差则由2.43%—2.56%升至4.55%—4.60%。这支持将TV视为偏好平坦区域的候选正则，尚不支持作为未知材料分布的通用替换。

未通过预先声明的合成筛选条件，没有进行真实DIC反演，也没有修改正式配置、既有正演/伴随或已有实验结果。这里的百分数不是当前106 mm实验域或七区实验DIC的误差。

## 两种方法的实际定义

两种方法均采用原Q4位移插值与测试函数，均为标准形函数\(N_i\)。模量保持连续Q4插值\(E_h=\sum_i N_i E_i\)，每个节点模量独立，\(E_i=\exp(m_i)>0\)，不绑定不同y行。没有采用SUPG、bubble-PG、单元常数模量或已知分层参数化。

原梯度平方正则目标为

\[
J_{H1}(E)=\tfrac12r^TW_A r+
\tfrac\gamma2\int_\Omega(E_x^2+E_y^2)\,dA.
\]

新增未平滑TV目标为

\[
J_{TV}(E)=\tfrac12r^TW_A r+
\gamma\int_\Omega\sqrt{E_x^2+E_y^2}\,dA.
\]

TV系数取\(\gamma\)，不是\(\gamma/2\)。它没有Huber阈值，也没有根号内的平滑ε。积分采用现有2×2高斯点离散；“未平滑”不意味着Q4梯度模长的高斯积分对连续积分严格精确。两种γ的单位不同：本目标中H1为mm⁴/MPa²，TV为mm³/MPa，不能直接比较数值大小。

位移残差沿用原面积权重、等分量权重与加权刚体配准。没有E_REF、噪声尺度归一化、独立标定先验或真值初值。

## 分裂求解与合格条件

令\(G\)为节点模量到高斯点物理梯度的矩阵，\(a_q\)为高斯点面积权重。ADMM引入\(z=GE\)，材料子问题为

\[
\min_m f(\exp m)+\frac\rho2\sum_q a_q
\left|(G\exp m)_q-z_q+b_q\right|^2.
\]

材料子问题使用现有正演、观测与精确离散伴随，以L-BFGS-B求解。另一子问题逐高斯点作向量收缩

\[
z_q=\max\!\left(1-\frac{\gamma/\rho}{|v_q|},0\right)v_q,
\qquad v_q=(GE)_q+b_q,
\]

零向量直接返回零。更新\(b\leftarrow b+GE-z\)，对偶场\(p=\rho b\)。初始\(\rho=\gamma\min(h_x,h_y)/\overline E_0\)，仅为数值罚参数；每10步按归一化残差比作2倍调整并保持p不变，不更改原目标，不读取真值误差。

只有以下检查同时通过才标记`kkt_converged`：

- log(E)驻点残差\(\|\operatorname{diag}(E)(\nabla_E f+G^TAp)\|_\infty\)，容差为\(10^{-9}+10^{-3}\max(\|\operatorname{diag}(E)\nabla_Ef\|_\infty,\|\operatorname{diag}(E)G^TAp\|_\infty)\)。
- 面积加权约束残差RMS，容差为\(10^{-6}+10^{-4}\max(\operatorname{RMS}_A(GE),\operatorname{RMS}_A(z))\) MPa/mm。
- 对偶可行性\(|p_q|\le\gamma\)，允许浮点相对误差\(10^{-12}\)。
- Fenchel间隙\(\sum_q a_q(\gamma|(GE)_q|-p_q\cdot(GE)_q)\)，绝对值容差为\(10^{-9}+10^{-4}\gamma TV(E)\)。

保存的是原目标\(f(E)+\gamma TV(E)\)，不以增广目标或不满足约束的\(TV(z)\)替代。内层目标下降、内层求解器success均不单独作为外层成功依据。正问题引入的非线性意味着这些只是近似局部一阶条件，不是全局最优证明。分裂与残差检查参照[Boyd等ADMM综述](https://stanford.edu/~boyd/papers/admm_distr_stats.html)，其凸问题全局收敛结论不直接移用于这里。

## 对照条件与选参

合成域30×8 mm，反演12×4个Q4单元、65个独立节点模量；正演48×16个单元，833个细网格节点作为观测位置。两种方法共用同一观测算子、面积权重、均匀位移拟合初值及每点12000次目标评估预算。TV最多300个外迭代、每次150个内迭代；H1最多2000个迭代。SciPy的线搜索预算并非硬截断，实际评估次数逐点另存。

固定ν=0.26、厚3.2 mm、真实承载宽20 mm；180N平台型载荷取119.77617870327234 N，传入截取域内核的端力为\(F\times8/20\)。不涉及实验DIC坐标的物理验证。

三种真值分别为：均匀1800 MPa；平滑二维场
\(1800[1+0.2\cos(2\pi x/30)+0.1\cos(\pi y/8)]\) MPa；以及斜界面\(x+0.6y=13.5\) mm两侧2400/1400 MPa。界面坐标、分区数和模量数值只用于生成数据及评价，不进入反演。正演在高斯点使用解析真值，避免将同一粗网格场作为正反问题共同真值。

独立同分布高斯位移噪声标准差为0.0002 mm（0.2 μm），属于人为设定，不是实测DIC噪声估计。种子20261022用于选参；20261023、20261024用于固定权重后的重复验证。实现核验另用20261021及314159。

平滑场、阶梯场各自扫描50个γ：H1为1e-14—1e-7，TV为1e-12—1e-6。横坐标均为\(\|W_A^{1/2}r\|\)，纵坐标分别为\(\sqrt{\int|\nabla E|^2}\)和\(TV(E)\)。使用现有L-curve内点曲率选择器，不按真值误差补选。TV的梯度RMS不超过1e-5 MPa/mm时视为数值常数场，不把其接近零的TV用于对数曲率计算。均匀场直接使用各方法在阶梯场选出的γ，不单独寻找可能退化的常数场L-curve拐点。

固定γ的12次噪声重复计算均通过各自停止检查。TV在均匀场的误差为0.0087%—0.0309%、节点模量标准差约6—8×10⁻⁶ MPa，未出现可分辨伪结构；H1分别为0.283%—0.449%及6.02—9.75 MPa。后者还说明同一权重跨不同材料形态使用可能保留不同程度的噪声。

选中点TV目标评估次数约为H1的64—65倍。本次小网格上的实现效率不足以据此直接推断全域实验计算可承受；更不能只报告平台更平而省略代价。

## 核验与筛选判定

已执行：原位移失配伴随的方向有限差分（相对误差最低约4.58e-10）；增广子问题方向有限差分（1.10e-8）；面积加权G/Gᵀ关系（绝对差1.82e-12）；仿射场TV解析值与常数场零TV；向量收缩的对偶/Fenchel条件；均匀弹性牵引解析解（最大位移差1.04e-16 mm）；三类场端到端计算。实现核验使用临时算例，保留诊断数值，不保留测试源码。

最终代码又重算四个选中点，模量场与保存场逐项最大差均为0，停止检查均通过。绘图只读取保存观测算子和场，不重新求解；PNG与SVG从同一图状态导出并检查了渲染图。

在任何拐点选出前声明了筛选条件：两个非均匀场均能选参，噪声重复均通过停止条件；每个噪声样本阶梯误差不超过H1的80%，平滑误差不超过H1的120%；两种方法均匀场标准差均不超过9 MPa。这些是本次谨慎推进规则，不是一般理论阈值。

阶梯误差比为0.7677/0.7646，通过；平滑误差比为1.8007/1.8738，未通过。TV本身通过均匀场伪结构检查，联合均匀条件的失败来自一个H1噪声样本，不能算作TV缺陷。最终不进入真实DIC，不进行真值调参或事后修改规则。

机制上，TV能减弱扩大界面过渡区来降低梯度平方代价的倾向，但单调斜坡与阶梯可以具有相同的连续TV，不能仅凭正则形式保证找回真实锐界面。连续Q4的有限网格表达也仍限制过渡宽度。本结果只支持在当前噪声、模量反差与小网格上改善阶梯平台；尚未验证当前实验域、细网格、实测噪声相关性、ν不确定性及边界模型误差。实验问题仍不能被视为已解决。

## 实现与本机结果入口

算法位于`fgm_asm/exact_tv.py`，隔离合成流程为`lib/exact_tv_study.py`，固定权重评价和读盘出图为`lib/exact_tv_report.py`。正式四步入口、`dic_case_config.py`及默认梯度平方正则均未改动。正演、观测和伴随沿用基础提交`afca95f`的实现。

本机结果目录为`results/dic_full/exact_tv_20261021/`，入口`index.html`；包括扫描协议、事先声明的筛选规则、每点场与残差历史、观察数据与H、逐次误差CSV、判定JSON、运行日志、解析/梯度检查，以及PNG/SVG。扫描源文件哈希记录在协议中；最终代码复算检查另存`final_code_reproduction_check.json`。数值结果目录遵循已有Git忽略规则。

复现时使用未存在的输出目录，先设置`OMP_NUM_THREADS=OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=1`，再分别执行：

```powershell
python -m lib.exact_tv_study scan --output results/dic_full/exact_tv_replication/selection_pilot
python -m lib.exact_tv_report evaluate --root results/dic_full/exact_tv_replication
python -m lib.exact_tv_report render --root results/dic_full/exact_tv_replication
```

`render`只读保存结果，可单独重复执行。环境为Python 3.13、NumPy 2.4.0、SciPy 1.17.1，具体版本和种子保存在协议中。
