# 标线、制造方向与DIC输入修正后的四步计算

**历史记录：** 本页数值为原+Y递增输入，四步已归档于`results/dic/history/plusY/`。当前主流程已改为沿+Y递减，见[方向统一更新](material_direction_update_20261020.md)；下文原分区趋势及统计不作为当前结果。

## 当前结论

主配置和全部四步已按确认后的标线、方向及数据版本重算。独立正演的轴向伸长仍偏大约17.58%（180N）和13.74%（280N）。反演改善轴向拟合，但横向仍不一致；在确认的填充率递增方向上，反演E总体下降，与独立标定的上升趋势相反。不能继续用旧方向下的分区统计描述本组材料已与标定一致。

## 几何事实、数据和确定的映射

已确认73 mm对应高填充率端、85 mm对应低填充率端；region两端对应横线；填充率沿原始+Y递增。数据采用软件独立毫米标定，位置和位移尺度保持1。名义试样总长220 mm，因此标线制造坐标为−25/+37 mm，中点+6 mm。

主输入为`180N_2/region`阶段259—273及`280N_2/region`阶段436—450，分别15帧、14,484点。当前域61.497353591×19.435484393 mm，点距约0.290081857 mm，70×20 Q4单元、1491个独立模量节点。原始X/Y按变形后坐标处理，恢复X₀=X−DX、Y₀=Y−DY。

当前坐标和位移方向为`x=Y₀+bₓ、y=−X₀+bᵧ、ux=DY、uy=−DX`，b≈(52.2561744463,12.1005574490) mm。平移只作用于位置。制造坐标为`x_manufacture=x_FEM−24.748676795`，区域覆盖[−24.748676795,36.748676795] mm，五区界面为0.748677/16.748677/32.748677/48.748677 mm；各区覆盖长0.748677/16/16/16/12.748677 mm。

独立导出跨度与约62 mm标线推算间距相差0.502646409 mm。采用中点配准保留该差异，两端差约+0.251323/−0.251323 mm，不缩放数据使两端强行吻合。名义总长、近似端距和横向位置仍限制配准精度，故保留`coordinates_verified=false`；已确认的端别和轴向不再视为未知。

## 核验和范围

新方向下均匀牵引解析最大误差约4.86×10⁻¹⁴ mm，刚体加入后残差保持；小网格伴随方向差分最小相对偏差约1.68×10⁻⁹。新分区独立正演70×20→140×40→280×80的最后一级差异低于轴向0.008 μm、横向0.004 μm；这不证明自由反演网格已收敛。

全部50点由保存E重新正演及Q4梯度积分核算ρ/η，曲率重算一致。最终三个ν、两平台共六组预测重新求解后与保存数组一致；三点规范、坐标/位移旋转及共同居中显示残差均已检查。原几何236个数值和配置文件保持不变。

`all_region`已取得两个平台相同阶段，共26,585点，跨度117.836497×18.484156 mm，但其网格与region不同。已保存覆盖及邻近采样核对，最近空间点不当作严格同一材料点；本轮主计算仍使用已确认横线位置的region。未完成大区的独立制造位置验证或80/150 mm完整分区扩域。

当前结果仍是条件性模型比较。标线推算与毫米跨度的差异、内部侧边近似、完整试样边界等效及误差预算仍需独立证据。原ν=0.33及其他参数诊断仍按旧输入解释；本轮新ν=0.33结果单独保存于`results/dic/geometry_fix/nu_0.33/`。
