# 顺序多工况嵌入L-curve扫描

[最终交付报告](report_final/report.md) · [L-curve与曲率图](report_final/l_curves.png) · [选定系数下的阶段曲线](report_final/selected_profiles.png)

每个γ内完整执行工况1→2→3的初值传递。每个γ都重置为同一工况1 DIC均匀初值；不跨γ延续。每阶段只优化当前工况的残差和H1正则，γ在同一顺序链中保持不变。

50个γ全部尝试，范围1e-12–1e-4，共130个已执行阶段；39条完整有效链、11个无效γ。10个小γ在第1阶段达到1500次迭代上限，另一个γ在第3阶段线搜索异常。失败点不进入拐点选择。每阶段原总预算1500迭代/12000评价，预算内的异常恢复均记录，不扩大预算。

主曲线用同一个最终场E3(γ)回代三个工况，取总面积加权残差范数ρ和该场H1范数η，选得γ=3.5564803062231287e-7。末工况残差曲线作为不同口径的对照，选得1.6768329368110066e-7。主曲线是顺序端点诊断，E3没有最小化三工况总目标，不能把它称为同时联合目标的标准解路径。

主曲线选定场的第1/2/3次轴向位移相对误差为17.338%/2.988%/1.852%，双分量为22.680%/4.082%/2.683%。对单调标定趋势线、分层阶梯线的平均绝对相对差异为12.301%/12.529%，均在制造坐标[−48,48] mm上评价。标定不参与优化、初值或选γ。

数值核验包括逐元素初值传递、逐阶段残差/正则范数回放、同一最终场总残差的两种独立计算、冻结输入哈希核对。同γ=1.2648552168552956e-9下，与此前独立固定γ顺序试验的最终二维模量场相对差异为0.00000511%，见fixed_gamma_crosscheck.json。

目录说明：scan/保留各γ的阶段记录、数值场和日志；report_final/为最终图表与选点数据。report/是保留在本机的首次绘图草稿，数值结果相同，版面已由report_final替代。原四步结果、前次联合/顺序试算及日常配置均未覆盖。
