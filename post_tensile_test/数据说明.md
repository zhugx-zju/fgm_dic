# 当前拉伸资料

当前项目只分析1023目录中的本次打印试样，不进行不同批次填充率结果比较。旧日期的拉伸分析输出及本次重复首轮输出已移除，活动结果只保留modulus_20261026_28_final。

2026-10-26按用户指定的当前打印试样，从40%–100%七组、每组4根拉伸工作簿及28根尺寸记录表重新计算等效杨氏模量。结果保存在[标定报告](1023/analysis_results/modulus_20261026_28_final/analysis_report.md)与[参数汇总](1023/analysis_results/modulus_20261026_28_final/group_summary.csv)，逐组图表在各填充率目录下的同名运行目录。原始工作簿、制造资料及当前最终标定结果均保留原字节；旧分析脚本仅保留为来源，运行入口为lib.tensile_calibration。

默认线性条件下27根有效，50-4的变形通道峰前存在回退且无合格窗口，因此50%均值使用3根，其他组各4根。批次标签1023按用户提供目录记录，未将目录标签当作独立的日期核验。拟合条件、窗口敏感性、单位解释及独立回归核验见新结果中的analysis_report.md。

当前四步DIC计算仍缺逐帧DIC CSV、同步净力及材料位置资料，配置说明见../docs/input_setup.md。本次没有启动该四步计算。
