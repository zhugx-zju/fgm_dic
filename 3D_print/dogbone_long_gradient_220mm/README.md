# 220 mm 一维分区狗骨拉伸试样

运行 `python 3D_print/gen_long_gradient_dogbone_specimen.py` 重新生成 STL。生成脚本使用项目的 `stl_builders.py`；尺寸单位均为 mm，拉伸方向为 `x`。

| 参数 | 数值 |
| --- | ---: |
| 全长 × 最大宽度 × 厚度 | 220 × 40 × 3.2 |
| 平行段长度 × 宽度 | 150 × 20 |
| 每端直夹持段长度 | 25 |
| 每端平滑过渡段长度 | 10 |
| 平行段范围 | `x = -75…75`, `y = -10…10` |

试样肩部采用两端斜率、曲率均连续的五次插值轮廓。该几何为自定义研究试样，不应标注为标准拉伸试样。25 mm 直夹持长度与 10 mm 缩颈过渡都需要用实际夹具、切片预览和试拉验证，尤其应检查肩部是否出现过早破坏。

`dogbone_220x40x20x3p2.stl` 为试样实体。`infill_regions_7x1/modifier_X01.stl` 至 `modifier_X07.stl` 为七个切片 modifier，不是独立打印件。平行段内七区长度依次为 **35/16/16/16/16/16/35 mm**。X01、X07 分别延伸到试样左端和右端，使对应肩部与夹持端延续相邻平行段的填充率。中间 5 区覆盖 20 mm 平行段全宽；两个端区的平面轮廓与狗棒外轮廓一致，包含 20 mm 宽平行段、平滑肩部和 40 mm 宽夹持端。modifier 仅在 `z` 方向分别超出试样上下表面 0.1 mm，以提高切片软件布尔相交的稳定性，不应作为额外实体打印。

| Modifier | x 范围 (mm) | 填充率 |
| --- | ---: | ---: |
| X01 | -110 至 -40 | 40% |
| X02 | -40 至 -24 | 50% |
| X03 | -24 至 -8 | 60% |
| X04 | -8 至 8 | 70% |
| X05 | 8 至 24 | 80% |
| X06 | 24 至 40 | 90% |
| X07 | 40 至 110 | 100% |

实验标线距高填充率外端73 mm、低填充率外端85 mm，制造坐标ξ分别为+37/−25 mm。region采用独立毫米标定，实际跨度61.497354 mm；沿制造坐标递增覆盖约−24.748677至+36.748677 mm，不缩放为名义62 mm。当前FEM x沿原始+Y、与制造ξ相反，关系为`ξ=36.748676795−x`；从左至右为90/80/70/60/50%，长度12.748677/16/16/16/0.748677 mm。制造STL与modifier坐标保持原定义，DIC/算法中的方向转换不改变打印模型。

示意图从当前配置`dic_case_config.py`所指向的`CASE_OUTPUT/01_prepared/run_metadata.json`（本轮为`results/dic_full/`）读取标线及ROI位置，避免继续使用旧75 mm端距和居中70 mm范围。截取域均布牵引近似仍需独立核验。

所有 STL 使用同一个坐标原点；导入切片软件时应保持原位叠合，并逐层检查整个试样均被对应 modifier 覆盖。尤其需要确认 X01 的 40% 夹持端不会被夹具压溃或产生滑移，X07 的 100% 区域在切片预览中实际采用何种实体填充路径。建议额外打印反向赋值样件（同一几何，把七区密度倒序），以辨别梯度效应与左右夹持差异。

运行 `python 3D_print/plot_long_gradient_dogbone_specimen.py` 可生成同目录的 PNG、SVG和PDF分区示意图。

七个区依次设置为 40、50、60、70、80、90、100% 填充率。所有其他切片参数应在整批实验中固定。切片后逐层预览，确认每个 modifier 只更改目标区域的填充率、没有增加实体材料或改变墙层等参数。DIC 与反演时记录实际分区坐标和夹持端的打印设置。
