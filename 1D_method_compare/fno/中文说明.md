## 核心设计

### 1. 问题设置（fem1d.py）
- **杆轴向问题**：长度L，截面积A，左端固支u(0)=0，右端受力F
- **有限元**：线性单元，单元内E线性插值
- **刚度组装**：`K(E) = Σ_e ∫ B^T E A B dx`，采用2点高斯积分
- **正演求解**：`K*u = f`，消元法处理边界条件
- **残差计算**：`r = K(E_pred)*u_obs - f`，用于物理损失

### 2. 数据生成（data_gen.py）
- **随机E(x)场生成**：
  - KL展开法：`logE(x) = Σ √λ_k ξ_k φ_k(x)`，低频随机场
  - 分段常数法：`logE(x)` 在多个区间内为常数
- **FEM正演**：对每个随机E(x)和随机F，求解u(x)
- **数据存储**：
  - 输入：u (n_node,), x/L (n_node,), F (1,)
  - 标签：logE_true (n_node,)
- **默认配置**：
  - 训练集：1000样本
  - 验证集：200样本
  - 测试集：200样本
  - 节点数：101 (n_node)

### 3. 数据集（dataset.py）
- **FNODataset类**：
  - 输入归一化：u和F标准化，x/L已在[0,1]
  - 输出归一化：logE标准化（用于监督损失）
  - 数据格式：输入(B,3,N)=[u,x/L,F]，输出(B,1,N)=logE
- **元数据**：保留原始u和F用于物理损失计算
- **统计量**：训练集计算，验证/测试集复用

### 4. FNO模型（model.py）
- **架构**：使用`neuralop.models.FNO`
  - 输入通道：3 (u, x/L, F)
  - 输出通道：1 (logE)
  - 傅里叶模式：16
  - 隐藏维度：64
  - 层数：4
- **输出**：logE无约束（-∞到+∞）
- **推理**：E = exp(clamp(logE, -20, 20))保证严格为正

### 5. 训练（train.py）
- **损失函数**：
  ```
  L = λ_sup * L_sup + λ_phys * L_phys + λ_smooth * L_smooth
  ```

  - **监督损失** (L_sup)：`||logE_pred - logE_true||²`
    - 在归一化的logE上计算
    - 需要真值标签

  - **物理损失** (L_phys)：`||K(E_pred)*u - f||² / ||f||²`
    - 将预测的E代入FEM平衡方程
    - 计算残差，只在自由度上（排除固定边界）
    - 归一化以保证尺度不变性

  - **平滑损失** (L_smooth)：`||∂logE/∂x||²`
    - 有限差分计算导数
    - 正则化，防止解过于剧烈变化

- **优化器**：AdamW，lr=1e-3，weight_decay=1e-5
- **学习率调度**：余弦退火，100个epoch
- **默认权重**：λ_sup=1.0, λ_phys=1.0, λ_smooth=0.01

### 6. 评估（eval.py）
- **监督指标**（需要真值）：
  - E相对L2误差：`||E_pred - E_true|| / ||E_true||`
  - logE相对L2误差
  - 点态MAE、MAPE

- **物理一致性指标**（无需真值）：
  - FEM残差：`||K(E_pred)*u - f|| / ||f||`
  - 验证预测的E是否能解释观测的u

- **可视化**：
  - 多个样本的E预测对比
  - 误差分布直方图
  - 最佳/最差案例
  - 物理残差分布

## 技术细节

### 1. 节点值 vs 单元值
- **当前实现**：E(x)为节点值，单元内线性插值
- **单元刚度**：`k_e = ∫ B^T E(ξ) A B dx`，E(ξ)通过形函数插值
- **对齐方式**：网络输出logE为节点值（与FEM网格对齐）

### 2. 边界条件处理
- **正演**：消元法，直接去掉u(0)对应的行列
- **物理损失**：只在自由度上计算残差（u[1:]）
- **避免误差**：不把固定边界的误差引入损失

### 3. 数值稳定性
- **logE范围**：训练时无约束，推理时clamp到[-20,20]
- **原因**：exp(20)≈5e8，足够大；exp(-20)≈2e-9，足够小
- **避免**：exp(logE)溢出或下溢

### 4. 批处理中的FEM组装
- **当前实现**：循环遍历batch，逐样本组装K和计算残差
- **优化空间**：可以用批矩阵或稀疏张量加速
- **权衡**：简单实现 vs 计算速度

## 常见问题

**Q: 为什么网络输出logE而不是E？**
A: logE在(-∞,+∞)，网络容易学习；E=exp(logE)自动保证正性，无需额外约束。

**Q: 物理损失为什么要归一化？**
A: 不同样本的||f||可能差异很大，归一化让损失尺度一致，训练更稳定。

**Q: 能否不用真值标签训练？**
A: 可以！设置λ_sup=0，纯用物理损失，但需要更多样本和更长训练时间。

**Q: 如何处理测量噪声？**
A: 在生成数据时给u加噪声，同时增大λ_smooth进行正则化。

**Q: 训练不收敛怎么办？**
A: 检查：(1)数据归一化；(2)降低学习率；(3)调整损失权重；(4)增加网络深度/宽度。
