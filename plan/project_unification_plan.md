# 项目统一与代码迁移方案

## 目标与约定

以 `dogbone_parallel_section_adjoint_plan.tex` 为科学目标，将原 ASM-Python 与 post_DIC 的重复算法合并为根目录的一套 `fgm_asm`。沿用现有 `fgm_asm/`、`lib/`、`script/`、`tests/`、`config.py`、`results/` 分类，不另起一套 src/package 风格。Python 模块采用现有 snake_case、显式配置、NumPy/SciPy、Q4 平面应力、L-BFGS-B 和伴随梯度。

三条流程共用正演、观测映射和反演：

1. 合成位移 → 二维节点模量反演，检验算法；保留不同正演网格、缺测、噪声和刚体扰动的测试。
2. 独立分区标定模量 → 正演 → DIC 测点位移比较，检验材料标定与矩形等效模型。
3. 实验 DIC → 二维节点模量反演 → 与独立标定比较，并预测留出的载荷级。

二维节点场是主线。七区参数模型是低维对照，不能取代二维反演。独立模量不能同时作为强先验和独立验证真值。多个成比例载荷提高信噪比，不自动增加空间可辨识性。

## 目录与迁移

- `fgm_asm/`：从 ASM-Python 保留网格、材料、双端牵引、正演、梯度、三类正则和已有测试；吸收 post_DIC 的真实测点 Q4 观测算子。增加统一的多载荷观测接口和刚体配准。
- `lib/`：合并 DIC 读取、网格方向、参考坐标、平台汇总、实验模量读取与结果比较；保留原有有用的纯数据处理函数。
- `script/`：保留合成研究入口；增加统一研究入口与实验数据检查入口。旧的位移控制反演不作为现有实验入口。
- `config.py`：保留原合成算例；实验和统一流程采用独立 Python 配置，避免 demo 的模量、载荷和正则尺度误入实验。
- `tests/`：迁移现有数值测试，增加真实测点、刚体消除、多载荷伴随梯度、平台导入及端到端烟雾测试。
- `docs/`：保留原算法说明、记录迁移映射和历史入口状态。
- `post_tensile_test/`、`3D_print/`、`plan/`：保留现有数据及文档位置。既有结果不覆盖。新计算写入独立 `results/<case>/`。
- `1D_method_compare/`：独立方法对照，仍由根 Git 管理，不混入二维默认流程。

先在 Git 保存原有代码快照；重复代码移除后可由历史找回。原位移控制与 CASE 研究留存于历史，不伪装成双端载荷的兼容实现。原始大型数据、缓存和批量计算结果保留在磁盘，Git 追踪代码、配置、说明及必要的小型标定/时间配对表。

## 力学与数据接口

- 坐标、位移 mm，力 N，模量 MPa；模型长度 110、宽 20、厚 3.2 mm，拉伸沿 FEM x。
- 两端等大反向均布牵引，q = F/(w*t)，侧边自由，只约束三个刚体自由度；不将截取域一端夹紧。
- 统一观测包含载荷、测点坐标、双分量位移、面积/噪声权重、稀疏 H、参考态和来源。合成与实验走相同的数据目标。
- 数据项为 1/2 min_c (Hu + Rc - d)^T W (Hu + Rc - d)。R 只包含两个平移和一个微小转动；伴随右端使用配准后的残差，不能用一般仿射去趋势删除真实应变。
- 主未知量 m = log E；H1、affine_detrended、Huber TGV 保留。实验尺度由显式 E_ref 控制，不能直接使用 demo 的 1 MPa 尺度。
- 平台 CSV 的重复 row/col 先检查一致性再去重；X_ref=X-DX，Y_ref=Y-DY。坐标及位移应用同一个轴变换。平台帧标准差用于诊断，不能默认 15 帧独立而将噪声除以 sqrt(15)。

## 第 3 次实验的固定事实与未决问题

- DIC 相对最初未加载图；试验机初始约 60.1 N 是夹具自重偏置。实际拉力是平台读数减初始读数，机台位移与变形通道不用。
- 180 N 目录帧 259—273，实际拉力约 119.77618 N；280 N 目录帧 436—450，约 219.73545 N。精确来源保留在原 timing 分析记录。
- 80 N 平台帧 82—96 可另行导出；只有两个平台完整场相减后才使用对应增量力。
- 默认用 180 N 识别、280 N 留作预测检验；若用它选参，应另留最终验证，不能继续称独立测试。
- 导出数值坐标跨度约 122.79 × 37.07，与用户确认的 20 mm 宽平行段存在待核实的尺度/坐标定义差异。禁止自动将 37.07 缩成 20，也禁止默认居中来认定七区位置。实验配置需记录已核验的坐标变换和区域物理定位；缺少时可做读取质检和模型准备，但不输出正式实验反演结论。
- 独立模量来自 mixed_infill_20261017 的 independent 方法，七组约 1232—2400 MPa，保留批次、样本数与标准差。不是精确空间真值。
- 完整狗骨与矩形域的边界近似比较属于后续物理验证；不能用同一矩形模型的合成自洽测试替代。

## 实施顺序与验收

1. 保存 Git 及当前代码快照，完成根目录迁移，记录文件映射。
2. 合并公共内核及真实测点接口；旧合成测试应继续通过。
3. 梯度有限差分：真实测点 + 刚体配准 + 多载荷 + 各正则；均匀材料解析解检查载荷和厚度。
4. 合成烟雾计算经过同一个入口完成正演、观测、反演及结果保存；不覆盖旧结果。
5. 实验导入、标定正演、DIC 比较、实验反演及留出载荷预测接入统一流程。坐标未核实时明确阻止正式求解，不造结果。
6. 更新 README、运行命令、配置来源、迁移状态、实测/推断/未测事项；最后检查根 Git 变更与数据保留情况。

测试通过只说明代码与所测模型自洽。真实模量可信性、边界近似、泊松比敏感性和跨试样重复性需要实验与独立正演证据。
