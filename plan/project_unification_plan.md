# 项目统一架构与交接方案

## 目标和实际几何

采用自由二维节点模量 E(x,y) 反演实际一维 E(x)。合成数据验证算法，实验数据验证可行性；独立实测模量用于正演与 DIC 比较。保留原 `fgm_asm/`、`lib/`、`script/`、`tests/` 和大写 Python 配置的风格。

用户确认：总长 220 mm，两标线距左右最外端各 75 mm，DIC 域中央 70×20 mm，厚 3.2 mm。观测五区 50/60/70/80/90%，长度 11/16/16/16/11 mm；FEM x 为 0—70，界面 11/27/43/59 mm。打印试样仍为七区，不改 STL。

## 模块与数据流

| 模块 | 职责 |
| --- | --- |
| `fgm_asm` | Q4 平面应力、双端均布牵引、材料、测点 H、刚体投影、多载荷伴随、正则与优化器 |
| `lib/experiment_data.py` | CSV、重复点、参考坐标、平台统计、载荷配对、分区标定选择、坐标变换 |
| `lib/research_workflows.py` | 合成、质检、独立正演、DIC 比较、反演及留出预测 |
| `lib/research_reporting.py` | 配置/环境/哈希、结果保存、位移和模量比较、宽度统计 |
| `script/run_synthetic.py` | 统一合成入口，一维真值、二维反演 |
| `script/run_experiment.py` | `inspect/model/forward/inverse` 四种模式 |
| `synthetic_config.py` / `experiment_config.py` | 当前 70 mm 配置 |
| `config.py` 与原验证脚本 | 历史 110 mm 算法研究复现 |

三条流程共用 `ObservationCase`，包含载荷、测点、双分量位移、面积/噪声权重、稀疏 H 和来源。数据项 `0.5 min_c (Hu+Rc-d)^T W(Hu+Rc-d)`；R 仅含两平移和一微小转动。配准残差构造伴随右端，不消除真实拉伸应变。

反演未知量为每个节点独立的 m=log(E)。默认 35×10 单元、396 个模量未知量。五区及横向一致性不进入参数绑定。输出二维场、宽度均值 E(x)、横向空间标准差及区域面积加权均值；空间离散程度不是统计置信区间。

1. 独立细网格一维真值 → 测点采样、噪声、刚体扰动 → 二维反演 → 留出载荷预测 → 二维场/一维剖面比较。
2. 独立实测五组模量 → 对齐界面的细网格正演 → 同一 DIC 测点 → 两分量位移及残差比较。
3. 180N DIC → 二维反演 → 280N 预测 → 与独立标定比较。280N 若用于选参，需另留最终验证。

## 数据约定与待核验事项

- DIC 相对最初未加载图。初始约 60.1 N 是夹具重量，实际拉力为平台读数减初始读数。不使用机台位移/变形通道。
- 180N 帧 259—273，实际约 119.77618 N；280N 帧 436—450，约 219.73545 N。精确来源保留在实验时间配对记录。
- 每组 15 帧、13,845 个共同有效点，每帧 213 个一致重复行先核对再去重。参考坐标 X−DX、Y−DY，不改原 CSV。
- 时间标准差不除以 √15。噪声下限与正则参数尚未独立选定；80N 帧 82—96 可补导出，完整位移场作差后才用增量力。
- 标定保留七组原记录，当前取 `independent` 方法的 50%—90% 五组，保留批次、样本数、标准差，不作反演强先验。

ROI 已确认 70×20 mm，但导出跨度约 122.79×37.07。必须核验原始 DIC 标定/导出定义、统一尺度、轴向和标线定位。坐标与位移应用同一矩阵，禁止独立缩放两轴匹配尺寸。`DIC_COORDINATES_VERIFIED=False` 时允许质检与独立正演，阻止正式 DIC 比较和反演。

两端 ±F/(w·t)、侧边自由，只去除三刚体自由度。截取面距肩部 40 mm、距相邻分区界面 11 mm，均布牵引仍为近似。完整狗骨/矩形模型配对、泊松比、空间相关噪声、正则选择、跨批标定转移与试样重复性仍需独立验证。成比例载荷不自动增加空间可辨识性。
