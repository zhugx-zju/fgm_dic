# 梯度材料反演的验证主线

目的：检验连续空间模量反演算法在可制造分层试样上的实验可行性。默认采用自由二维H1，已知界面分层和TV作为辅助对照，不以恢复七层常值取代梯度材料表征目标。

1. 输入核验：坐标、位移、毫米尺度、参考图、力配对、真实截面和材料位置逐项保留证据。当前1023输入按docs/input_setup.md补齐。
2. 独立标定→分层正演→DIC：使用各组实测均值及其批次、样本数和离散，不调模量降低该项误差。保留边界等效及标定应力窗口转移的限制。
3. DIC→自由二维模量→标定：初值、选γ只用识别数据；比较二维场、宽度均值、横向离散和分区均值。趋势线只作辅助参照，不视为连续真值。
4. 识别模量→正演回代：报告轴向、横向整体相对误差与局部残差；参与识别的数据是回代拟合检查。最终独立验证须使用未参与模型和参数选择的新观测。
5. 仿真检查：同观测、同预算和同选参规则，比较突变分层及连续可表示真值；真值仅用于生成和最终评价。无噪声同模型恢复不单独证明实验DIC准确或不准确。

完成标准是形成带条件与不确定性的证据链，可以是通过、未通过或证据不足。优化停止、位移拟合、模量参照一致性及物理模型验证分别评价。不自动启动大扫描或扩展研究范围。
